# 开放评审与多轮任务

预览入口：http://localhost:8182/。首页仍按“选择模型 → 选择题库 → 开始”操作。新增题库为 **实用场景 · 开放评审**（12 题）和 **实用场景 · 多轮任务**（6 项，每项 3 轮）。

## 选择赛制和裁判

| 赛道 | 作答方式 | 时间预算 | 评分单位 |
| --- | --- | --- | --- |
| 短题竞速 | 保持原有问答和评分规则 | 每题 60 秒 | 每道题 |
| 开放评审 | 阅读材料，提交完整答卷 | 每题 3 分钟 | 每道开放题 |
| 多轮任务 | 阅读公共材料，按 2–5 轮要求连续修订 | 每轮 3 分钟，每个模型整项累计 10 分钟 | 整项任务，与轮数无关 |

选择新赛道题库后，阵容面板会显示正式裁判和时间预算。默认选可连接的 Codex，也可选择已登录的 Claude 或已配置的 API 评分模型。开赛前会做真实连接检查；检查失败不会调用参赛模型。

正式评分与解说使用独立会话。每份答卷只携带冻结的材料、评分条件、该模型各轮要求和回答；不携带解说聊天、用户追问、其他选手的答卷或成绩。更换解说不改变裁判。自定义 API 裁判的地址和模型标识也会冻结，补评时若配置被改动会提示恢复；密钥不写入战绩。

## 编辑题目

在题库编辑器新建题库时选择赛制。已有题库的赛制固定，旧题库按短题规则运行。

- 开放题和多轮任务可省略参考答案。参考答案只是示例，正式评审按评分维度、权重与得分条件进行。
- 默认开放维度为正确性 35%、依据 25%、完整性 25%、表达清晰度 15%；多轮维度为目标完成 40%、约束保持 25%、修订质量 20%、依据与核对 15%。支持增加、删除、修改维度，也可为单题覆盖默认标准；总权重必须为 100%。
- 多轮任务把始终有效的背景写在公共材料中，每轮填写新增材料、约束变化和交付要求。支持增加、删除、排序和逐轮预览；预览用占位说明标出模型未来的历史回答。
- 保存继续使用自动备份和版本冲突保护，可打包导出 `.ququ.json`。编辑不改变已经开赛的材料或评分标准。

## 观看、暂停和补评

每个模型的下一轮携带它自己的完整既有回答。公共材料、旧要求、新要求均保留，不静默裁剪；上下文超过接口容量会显示实际错误。所有仍在参赛的模型完成当前轮或退出后才推进下一轮，中途不向模型反馈成绩。

模型窗口的“轮次 / 历史回答”可查看任一轮要求、公开推理和答案。主动选择历史轮次后会停止跟随新轮次。刷新、重连、回放都能恢复完整内容；即使时间轴文件缺失，完整战绩仍可恢复已保存的逐轮答卷。

暂停在轮次之间生效；终止取消在途请求并保存已完成轮次。累计调用失败 3 次或作答超时会退赛。任务累计用时包含模型请求、重试和退避，排队、等待其他模型和正式评分不消耗作答预算。首版仅使用文本模型接口，不提供自主联网、文件操作或代码执行。

任务完成后，裁判逐份评阅匿名答卷，分项给出 0–10 分、理由和可点击的轮次原文证据。程序检查分项完整性、分数范围和引用真实性，并按权重计算质量分。综合竞技分继续采用质量 70%、速度 15%、Token 效率 10%、缓存 5%；长任务汇总各轮耗时和用量，缺失用量保留为未知。

评分失败时答卷显示“待评分”，点击 **仅重试失败评分** 可补评。成功答卷不会重复调用裁判。待评分未完成时不宣布冠军、不更新生涯积分。补评使用战绩内保存的冻结标准，并按比赛标识防止重复结算。服务重启后，可从战报档案打开该场回放，再重试失败评分。

模型战绩页提供三个赛道入口，分别保存成绩与 Elo。短题旧战绩和旧回放继续使用原有规则。

## 合成题目核对说明

新增材料均标明为合成情境，仅依据给定材料可完成。评分条件允许合理方案和明确说明未知；对于冲突约束，正确识别无法同时满足并说明最小调整也属于完成任务。

| 题目 | 核对重点 |
| --- | --- |
| OP-01 / OP-02 | 发票应付 880 元、暂缓 80 元；按最新工单状态去重，不能把重复快照当新工单 |
| OP-03 / OP-04 | 资源占用和先后关系均明确；加资源后 7 天可缩至 6 天；取消外观项可在 8 天交付 |
| OP-05 / OP-06 | 9,500 元预算保留 500 元备用；现金总额缺口 200 元，分期不能消除总缺口 |
| OP-07 / OP-08 | 总体成功率 56% / 34% 与标准化 40% / 50% 区分；加权延迟约 316.67 ms，日均值不能当总均值，P95 不可推算 |
| OP-09 / OP-10 | 注册边界要求可验证；80 字摘要与完整保留不限长实体名可能冲突，不能凭空声称可满足 |
| OP-11 / OP-12 | 复盘证据不足以直接认定因果；客服指标定义变化后不能直接比较 |
| MT-01 | 理论库存 110 → 更正后 108 → 可销售 80，预留与隔离互不重叠 |
| MT-02 | 保留资源日历与前置关系，需求删改后追加安全任务，最终最早 9 天 |
| MT-03 | 三轮最低方案逐步变化；最终至少 6,650 元，7,000 元预算只余 350 元，距必留 500 元还差 150 元，需明确指出不可行 |
| MT-04 | 失败率随去重、更正而变化：5% → 4% → 5%，分层口径单列 |
| MT-05 | 候补、容量缩减与已有预约保留同时生效，需明确新增和存量的不同处理 |
| MT-06 | 90% 关联缓存、剩余 10% 未知；受控复现实验 120/1,000 → 0，不能扩大到未经验证的全体因果 |

上述核对是题目条件与计算检查，不代表一次模型评分就能证明裁判对所有合理答案始终一致。可继续人工编辑评分标准。
