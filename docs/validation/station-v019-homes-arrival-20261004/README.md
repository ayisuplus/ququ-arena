## 居民圆弧失败与修正

首轮[相位97报告](player-residents-97/residents.json)保留：Claude在前往固定目的地的第7段停滞，未穿透家具或失去支承。失败时位置接近外缘250m圆弧，按时间与环速重建的[邻近调查](resident-diagnosis.json)定位到随迁座椅；角度是近似复现，不把非凸MeshCollider的ClosestPoint距离当作精确碰撞距离。

随后用居民半径0.35m胶囊在R3的68–92°、每0.1°扫描原250m圆弧，[241点对照](bench-trial.json)复现12个阻挡点，分别命中两张座椅。将座椅从首轮位置向内移4m后，阻挡为0，且与建筑无大于0.02m穿透。原厅与共享楼均无需再搬，原居民路径保持。

[修正回执](bench-correction.json)记录两张座椅净外移4m；`installed.json`保存首轮9对象均外移8m的记录，最终姿态须叠加该修正。保存后再次扫描241点通过，重新构建`build_edbd46880337`，后续运行必须绑定修正版。首轮图像、构建摘要、通过和失败报告均保留，不以修正版覆盖失败历史。修正版两相位各274项共享楼／旧厅路线和各66项居民完整往返通过，原停滞段已走通。
