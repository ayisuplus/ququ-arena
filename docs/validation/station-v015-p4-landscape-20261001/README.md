# v015 P4：环街铺装与景观光照基础

2026-10-01。按当前目标优先搭建景观，斗蛐蛐核心玩法暂不接入。候选为 `Assets/Station/Scenes/Candidates/BlackHoleStationThreeRingBuildingsV015.unity`。本轮是铺装、环街识别和建筑阴面层次的第一步，建筑外壳与组团前庭仍需继续细化。

## 实际改变

- 七块原甲板使用新的珍珠白瓷面与4m细板缝；固定换乘带使用浅白瓷面。只复制渲染网格以补UV，原顶点、三角面、法线、包围盒和碰撞网格保留。
- R1外侧、R2内外侧加入浅蓝环街；R3内外侧加入浅绿环街；四条细银边表达两条固定带的交界。五条环街随所属环运动，银边保持固定。九条铺装均无碰撞体，不增加跨环台阶。
- 恢复运动建筑的环境光探针取样，提高冷色环境填充，并加入弱的无阴影地面反射补光；主方向光调整高度。后处理曝光、Bloom及全局质量设置未改。
- 原建筑、家具、房间和交互身份保留。14个原Behaviour仍停用，包括真实赛事连接、赛事驱动和完整世界存档；此次没有接入核心玩法。
