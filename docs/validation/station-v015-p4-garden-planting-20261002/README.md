# v015 P4：玻璃生态园种植层次

2026-10-02，基于 `0190b795` 的整站复核继续施工。当前场景为 `Assets/Station/Scenes/Candidates/BlackHoleStationThreeRingBuildingsV015.unity`。此次处理玻璃罩内的种植密度和层次，核心玩法及完整世界存档继续暂缓。

## 实装

- 保留四个原花床、四棵原树、48株原观叶植物、六株功能作物及中央照料舱。
- 在照料舱北、南两侧增加四个低矮胶囊形花床，每侧两组。新花床约10.35×6m，沿用已有瓷白边缘、银色嵌条、土壤及原花床网格。
- 新花床各有两棵较高的树，原花床各补两棵树，共新增16棵；高树使用原Pachira C/D变体，缩放到原尺寸的1.65–1.8倍，原床补植使用1.25–1.35倍。新增220株Anthurium观叶植物，以较高的内排和较低的边缘填补裸土。全园装饰树共20棵、低植物共268株，不含六株功能作物。
- 新增对象统一归 `V015 layered conservatory planting`，隶属R3生态园组，随外环运动。原对象的身份、位置和序列化内容未改，仅在生态园父对象的子列表追加一项；没有新增运行时玩法组件。
- 地被按新床/原床补植两套模板共享，每套两级LOD，共4份新网格。树木复用原网格、贴图、材质和LOD。最初16份地被网格共60,702,382字节，最终4份为15,175,597字节，减少约75%的原生网格资产文件体积；不把此数字当作帧率或显存实测提升。
