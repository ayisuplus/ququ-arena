# 灰闷观感诊断

用户指出蓝色仍灰、整个画面蒙灰、缺少概念图的闪亮质感。本轮只诊断这一问题，未继续东侧扩建，未将检查当作视觉修复完成。

在当前候选场景取研究馆、咖啡入口两处固定机位，分别渲染现状及关闭后处理版本。1600×900，Unity Editor 离屏渲染，不是独立 Player。诊断结束场景 isDirty=false，未保存场景、材质或光照更改。最终脚本只操作临时相机。

## 已确认

- 雾关闭、HDR开启；两个机位有效曝光0、对比12、饱和度8、白色滤镜、Neutral色调映射。因此没有证据把整体灰感归因于雾开关或负饱和度滤镜。
- 咖啡厅关闭后处理后，大面积顶棚和墙地面过曝泛白；研究馆关闭后处理后，大块屋顶依然灰暗。单纯关闭后处理不能达到目标。
- 当前局部确有明确蓝色，例如研究台基色 #176FD3；但画面中大面积屋顶、铺地缺乏足够的明暗和材质层次。部分旧软包基色仍为 #426B91。不是所有表面都已完成材质升级。

## 视觉判断与修正方向

对比项目现有 concept-v003-cool.png，目标图的质感来自深窗、明亮室内、清晰边缘高光及建筑体块之间的对比。实机咖啡厅的大面积亮面经色调压缩后层次弱，研究馆主要顶面缺少光照变化；蓝色点缀占比小，不能抵消整体平淡。光照与材质层次是下一项应局部重做的重点，而不是再提高全局曝光或饱和度。

下一次施工应先选一个固定第一人称机位，降低咖啡厅过强的漫反射照明，保留局部灯具与金属高光，明确瓷白、蓝釉、深窗和织物的区别，重新烘焙后对比。该修正尚未实施；未宣称找到唯一根因或整站已达效果图质量。

一次临时材质副本/环境反射关闭实验出现物体缺失，结果无效，不用于推断反射是根因；副本已销毁、原引用恢复，最终重新执行的诊断不修改材质。CLI首次5秒超时后脚本实际结束，最终简化脚本执行成功。
