## 诊断与修改

北、东翼原有4m地砖的顶面约为y=0.005m，后来添加的前庭饰面顶面约为y=0.013m，覆盖了原分缝。南、西翼的石灰石饰面也是连续平面。为现有11块前庭、房间地面和入口过渡面补充4m尺度、14mm名义宽度的细缝，沿既有表面排布，不新增承重甲板或碰撞。

15处吊顶与入口顶棚补1.2m间距的细分缝，保留原屋檐、灯带和净空；包括北侧三块候舱顶棚、咖啡四块圆角吊顶、西侧廊顶及研究亭、温室顶棚、四个核心接口与东侧休息亭。咖啡厅旧六块方形吊顶仍与后来的圆角吊顶重叠，因此停用旧Renderer，保留对象和其他组件。

南侧温室8根、西侧入口6根现有圆柱改用既有珍珠白材质，与北、东翼一致；窗框及玻璃保持原样。对象清单、稳定ID、原材质和表面边界见 `install.json`。

首轮普通窄面在远处出现点状闪烁，因此改为单个URP表面调制Shader，按屏幕导数平滑边缘、18—65m逐渐淡出。几何宽度留出滤波空间，实际可见缝宽仍为12/14mm；关闭深度写入和投影，沿现有表面着色，不参与GI。26个合并网格共1,816顶点、908三角形，使用一个共享材质；这只是新增几何统计，不代表实测帧率收益。
