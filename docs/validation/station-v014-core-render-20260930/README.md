# v014 核心正交截图诊断

此前四翼入口截图中，中央核心边缘出现三角形缺口。原因是临时正交相机距离太近，近裁面穿过高位顶棚／横梁；并非这些构件的网格损坏。本轮修正截图机位，不修改生产场景、材质或玩家相机。

## 对照与结果

`production/black-hole-station/v014/core-render/diagnose.cs` 保持北侧观察方向、35m 正交半高与画幅，在一次诊断中依次记录以下状态，并在 finally 中恢复渲染器与材质、销毁临时相机和资源：

| 对照 | 结果 |
| --- | --- |
| 原机位 (-32,30,110)，看向 (0,2,154) | 出现裁切 |
| 关闭相机阴影 | 裁切仍在 |
| 暂停透明物件渲染 | 裁切仍在 |
| 不透明 Lit 改临时 Unlit | 裁切仍在 |
| 改透视投影 | 未见同类缺口，但构图改变，不能单独据此归因 |
| 相机沿视轴后退300m，保持正交方向与画幅 | 顶棚及横梁完整，缺口消失 |

初始远裁面缩短曾未解决问题；本轮后退相机同时避免近面穿入几何。`survey.json` 保留该区域网格与材质来源。
