## 到达视线

[原生射线定位](arrival-survey.json)表明，科研固定到达机位中的上方遮挡来自独立的`V015 public research and reading courts/Research folded linking canopy`。它不属于旧科研馆的入口顶棚，不能根据名字相近拆错对象。四条上部射线命中其119.28–124.38°范围。

对同一组四个机位比较原连续折檐、单开口和双开口。采用**124–128°单开口**：在R2半径145–153m范围打开一段，中线弧长约10.40m；保留115–124°及128–159°屋面、原0.24m厚度、全部五组支柱和分叉支承。移除段位于122°与130°支柱之间，没有留下空悬柱头；新断面闭合。底下地面与步行线不变。旧馆折顶、旧入口顶棚、原门和楼层保持。

固定眼点可透过新开口看见更多科研上层，原遮檐仍占画面上方，不能称为整段完全开敞。原路线前庭眼点在施工前已可见高低翼，本批不把其既有通透性归功于开口。院内路线眼点及新增28m高俯视用于核对组团关系，俯视不代替玩家人视。

双开口增加116–120°缺口，会把前端切成过短屋檐和孤立的支柱顶盖，故不采用；[双开口鸟瞰](trial-two-openings/research-context.png)保留。单/双试装阶段只临时切换渲染网格，未改碰撞或刷新反射，恢复后场景不脏；正式安装同步替换MeshFilter和MeshCollider，八处R2反射已重烘焙。记录见[安装](canopy-installation.json)与[反射](reflections.json)。

造型继续使用项目已有折檐轮廓和白色材料，空间取舍沿用[主方案真实参考](../../黑洞空间站升级方案/施工方案_v019_街区秩序与立体层次.md#2-真实参考与方案取舍)的前后层次与空隙组织，没有新增外部资产或生成消费。

## 阅读亮点来源与处理

[亮点位置射线](floor-ray.json)先经过约0.245m外的`Reading glass`，再落到2.981m外的`Reading paving`。对同机位临时关闭各自高光/环境反射进行诊断：第二轮地坪关闭对照仍保留亮点，玻璃关闭对照消除亮点。因此本处亮点归因于玻璃反射，而非直接把地坪改暗。

仅给新阅读楼`Reading glass`一个Renderer换派生材质，平滑度由0.94降至0.72。玻璃的颜色、透明度、Shader、关键字及反射开关保持，地面材质和照明保持。亮点变成低强度宽反光，仍保留环境反射和窗内外可见性；没有把诊断用“关闭反射”状态安装到场景。详见[材质安装](glass-installation.json)。

首轮`diagnostic-floor-off`出现其它表面未正常绘制，原因未证实，该张不作为材质因果证据；未改参数重复第二轮后画面正常。首轮异常图保留，结论依第二轮及正式安装后画面。原生诊断图是固定反射状态；运行时反射效果另由可见Player复核。

## 尚未关闭

此次修正的是一个到达视线局部和一个确定的玻璃亮点，不能据此关闭完整R2街区。大面积浅色甲板、墙地顶材质联合审阅、咖啡与阅读/科研的整组区分仍需连同主街样段继续；R3六户与共享楼陈设/反射/防护、短住观景组、公园/港区和全站P5仍在目标范围内。

阅读六视图中立面层次、窗外视线和蓝色地坪可辨；墙顶仍较简化，窗台与室内局部亮斑未全部消除。科研近景与咖啡玻璃也仍有局部强反射，保留为联合材质审阅项。上述图像复核不等于用户视觉认可。下一批转向R3六户与共享生活楼的完整组团关系，R2余项继续在执行清单跟踪。
