## 本批施工

原蓝色玻璃组包含四片曲面窗及一整个封闭蓝色内衬，直接调透明度会使内顶/地面也变透明。本批保留原四片窗的位置和形状，移除那块玻璃内衬；两组前后窗之间补0.10m厚实体地面、内顶和端墙。玻璃和白色内衬分为两个材质槽，共四个渲染对象、四种材质。

初次透视预览暴露了原曲壳内侧尖片。随后按现有窗轮廓裁清两处腔体，保留窗外曲壳、框、棕色饰条、位置和原碰撞。13,478个受保护表面顶点到修改后曲壳的最大距离为0；曲壳闭合/有效、外尺寸一致。曲壳实体体积287.141→258.533m³，这只是网格计算，不是建筑工程证明。

GLB40,576面，Unity混合引用40,238面；原独立碰撞4,000面。宽×深×高25.517×21.996×14.614m，地块及R2归属不变。四片原窗640面，新实体内衬2,592面。GLB仍为建模材质，当前透明效果来自Unity派生冰蓝玻璃。

房间空置，原碰撞/入口继续封闭，未增加家具、室内交通、功能或存档身份。曲壳外侧局部折痕、窗顶和背部衔接仍需精修，不能把本批腔体清理写成全部曲壳美术完成。
