## 确认的事实

- 活跃场景为 BlackHoleStationEcologicalGardenV014；编辑器非播放、无未保存场景变更。
- RenderSettings.fog=false、URP HDR开启。有效全局后期中曝光0、对比12、饱和度+8、色彩过滤白色、Bloom强度0.04。没有全局减饱和度或灰色色彩过滤。

- 现有蓝色不仅一种：步道IceBluePromenade为#91B9E6；软包PowderBlueFabric为#3279C4、光滑度0.26；部分旧竞技场软包为#426B91。不同用途不能一律改成高光塑料。

## 视觉判断与下一步验收方向

对照当前引擎截图与已存档concept-v003-cool.png：概念图依靠深色窗面、阴影、亮金属边缘与局部蓝白灯光构成层次；目前大厅大面积顶面、地面和设施亮度接近，色块之外缺少清晰的反光形状。此为画面观察，不是已完成的灯光因果分离实验。

因此不能用全局加曝光、加Bloom或关闭后期宣称修复。后续先在一个完整可步行机位做有明确暗部、彩色中间调与有限高光的样板，分别验证玻璃、金属、釉面与布料表现。保持蓝色清晰，同时白面保留细节、亮点不覆盖大面积画面；需与当前同机位比较，并由用户确认视觉方向后扩展。
