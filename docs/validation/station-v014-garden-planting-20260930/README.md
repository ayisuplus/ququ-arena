# v014 外圈种植层次、植物细节层级与共享网格

2026-09-30，接续天边黑洞方案。原外圈的八组种植池呈现为巨大深灰平面，123株低植物十分稀疏；32棵树均使用164,268三角面的原模型。本轮处理这些相互关联的近景与资源问题，继续复用原树木和叶片资产，不新增Meshy消费。

## 实装

- 种植池内布置1,958株低植物，前排较矮、后排增加高度与密度，分为32片。按四向布局重复种植节奏，保留原跨甲板路线5m净宽，树根周围留空。新植物无碰撞，原种植池边界、步道和座位不变。
- 每棵树有三级LOD：近处保留原164,268面模型，中景32,853面、远景19,846面。初版直接用简化树近看会损失枝干细节，因此恢复原模型作为近景。原对象、源FBX与材质保留。
- 低植物单株派生三级为2,093、756、289面，组合为共享网格。初版32片分别生成网格导致构建包膨胀到1,115,152,339字节，已弃用。最终复用7种形状、21份LOD网格，保留32个地被LOD组；这避免为每一片重复保存顶点，未新增运行时脚本。
- 土壤改用[Poly Haven Brown Mud Leaves 01](https://polyhaven.com/a/brown_mud_leaves_01)，作者Rob Tuytel，官方标明CC0，1.3m物理宽度。实际查看供应商预览后下载2K原始Diffuse与OpenGL Normal，尺寸及MD5核验通过，原始文件和来源SHA256保留；项目派生URP材质只用于八处种植表面，未改供应商文件。
- 九组光照贴图和46个自定义反射探针已更新，天边银白黑洞保持不变。

## 复现与未完成项

制作目录：`production/black-hole-station/v014/garden-planting/`。从9c7eb562基线依次运行 `build_lods.py`、`layout.py`，复制五个当前FBX至项目目录，再通过原生API执行 `install.cs`、`preserve_near_trees.cs`、`share_patches.cs`。下载并核验土壤后运行 `soil.cs`，等待光照结束，再执行反射烘焙并等待complete。最后运行截图、审计、存档隔离下的通行验证和构建核验。安装脚本有明确基线要求，不能对已安装场景重复执行。

本轮改善了种植池的占位感，并限制重复几何存储；植物造型本身仍沿用已有资产，远处空间密度和建筑近景质感仍需继续统一。技术通过、已查看的静态画面和最终用户认可分开记录；不把本节点当作整站美术完成。
