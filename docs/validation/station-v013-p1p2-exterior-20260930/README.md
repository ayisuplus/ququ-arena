# v013 公共平台与西侧赛事亭

基线 `75558b2`。本节点把咖啡厅和观景廊窗外的两组裸露平台、旧玻璃亭架整理成与室内同一套银白建筑语言。范围是既有东南公共平台和南侧观景平台；未扩建世界尺寸。
