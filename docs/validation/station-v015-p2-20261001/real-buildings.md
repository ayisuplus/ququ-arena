本轮把原建筑、屋檐、家具、座位锚点、生态园及固定船坞放入三环，不再使用18个白盒代替建筑。**这是空间迁移候选，P2尚未全部完成，P3–P5尚未完成。** 原建筑外壳保留，不能将此候选视为概念效果图的美术实现。

## 落位与保留

- 从完整 `BlackHoleStationEcologicalGardenV014` 场景另存候选。14,664个源对象全部留在候选，原场景保留；通过源GlobalObjectId与新场景ID映射追踪。5个需要跨归属拆分的Prefab实例在候选解包，原Prefab及供应商资产未改。
- 三环仍为25/84/92/176/184/254m径向分界、508m主圆盘。R1新铺装从36m开始，避免覆盖既有赛场，并给两处入口升降台留孔。固定北侧抵达扇区外增加330–470m的窄船坞地面，不增加第四个环。
- 原18个包络对应的建筑整组迁入，补入赛场/上层看台、公共入口、观景节点、船坞货运、附属休息厅和状态台。旧屋檐与入口标识随目的建筑迁移。
- 两处原低于甲板3m的观景区抬到地面；原14m高的东北观景节点以原地面为基准下移到外环。旧坡道、升降和上层出口的完整衔接继续检查，不能视为已经通行验收。
- 40个分散座位各自与家具成组迁移，避开外环四条横向主街和生态园。其余建筑内部座位保持尺寸和相对位置，共148个原座位身份保留。
- 旧固定连廊、旧方形甲板等保留在候选的停用历史组；旧场景仍可回退。新候选尚不能替代旧版完整世界。
- 新候选解除旧烘焙光照数据关联，原LightingData恢复；灯光、反射及外观需要为旋转建筑重做。没有用原静态烘焙结果充当迁移后光照验证。

测试同时修正了停滞检测：按与动态目标的距离判断进展，不能把角色随圆环运动误算成向目标前进。碰撞检查对所有真实非触发碰撞体生效，不再只检查命名为Envelope的白盒。
