# R3共享楼柱梁交接与天花修正

2026-10-04｜施工前基线 `7bd38686`｜接续[上一批材料诊断](../station-v019-homes-materials-20261004/README.md)。

19根中层窗柱的顶面从8.32m收至8.04m，与白色梁底交接；同步19个碰撞盒。共享楼190个朝下三角面分配独立低光泽天花材料，外立面继续使用原瓷面。楼高、平面位置、楼梯、露台、家具、住户和互动身份保持。原网格和材料保留，Unity原生创建两份派生网格、一份派生材料。

## 原因与实际修正

前批同机位隔离图已经证明：关闭阴影不能消除板边暗斑，隐藏绿色构件则能消除；原`gallery_wall`把绿色窗柱和白色横梁同时建在8.04–8.32m范围，深度同为0.3m。

本批用Blender 5.1.0复现原绿色网格，57,348个顶点与原制作数据最大误差为0，再仅缩短19根窗柱；没有统一缩放建筑。天花低光泽参数为Smoothness=0.08、ClearCoatMask=0，仅分配给共享楼瓷面网格中高于2.9m的朝下表面；白色外墙和横梁正面保持原材质。灯光、曝光、玻璃、石材楼面和木材没有随之修改。

首次原生安装在查找碰撞体时遇到重名：两段前墙的柱编号分别从0开始。该次在创建资产和修改场景之前失败；改为名称＋原中心＋原尺寸联合匹配后安装成功，失败回执保留。
