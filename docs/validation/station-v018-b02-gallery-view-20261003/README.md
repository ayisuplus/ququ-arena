## 几何与保存

[保存性核对](preservation.json)以本轮前场景字节为基线，证明完整场景仅有渲染网格和MeshCollider两处引用变化。77个窗面样本中，旧实心面遮挡从49个降到0个；77个样本仍由原玻璃碰撞封闭，窗不会变成可穿出的洞。原透明子网格索引和全部72个原顶点保持；只处理8个相交三角形，派生网格104顶点、40三角形、2材质子网格。窗洞外的面积守恒误差为`5.82e-11`网格局部面积单位。

旧派生网格、v016/v017场景以及本轮前已有dirty字体均按[基线哈希](baseline-hashes.json)保留。原生取景曾触发TMP字体动态缓存写回，已从与本轮起始哈希相符的备份恢复，[字体记录](font-restoration.json)保留实际哈希；该文件不纳入提交。构建钩子的六个文件另有原字节备份与恢复脚本。

## 失败阶段

`rejected-v001/`保留首次派生网格的画面、构建和运行记录。切换索引格式后没有恢复两个子网格，导致材质分组丢失；局部窗面射线与路线虽然通过，却不能证明窗洞外的面仍然完整，因此该版被否决。最终制作脚本显式恢复子网格数量，检查索引数量和窗洞外面积守恒，随后重新构建与验证。该失败版不作为当前完成证据。
