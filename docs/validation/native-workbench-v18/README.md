高级协议、原始记录和规则保留可搜索的 JSON 阅读/编辑器。没有 WebView；日常入口不打开浏览器。
没有新增数据库、评分体系或实验执行检查点。工程/多阶段/扩展开发在保存退出时中止并保留已产生结果。

系统文件选择器由随包的 `NativeDialogs/QuQuFileDialog.exe` 显示，源码为 `arena/scripts/windows-file-dialog.cs`，使用 Windows 自带 .NET Framework / WinForms，不要求安装 Node 或 PowerShell 脚本。该助手也处理 Windows Player 的退出保障：仅在配置已保存、后台关闭或脱离已确认后启动，正常退出不干预，8 秒后仍残留的本游戏进程才结束。它不终止后台，且不在 Unity Editor 中生效。手动验证暴露的原生收尾卡顿保留在 `interactive08`–`interactive13` 的日志中，不将它们作为正常退出成功的证据。

## 数据、提交与维护边界

- 提交号在费用相关操作前写入持久收据，同 ID 并发请求只执行一次；换请求体拒绝。超时后 Unity 查询收据，不自动重发启动。
- 比赛答案、轮次、评分和时间轴按安全点保存。下一次恢复只执行未完成部分；模型故障和退出状态保留。
- 后台接管、脱离及关闭验证启动凭证，只监听 127.0.0.1。显式外部开发服务不被游戏关闭。
- 退出等待执行器中止、结果落盘和资源清理，再释放锁。失败时保留锁与服务，允许重试。

- **网页默认关闭尚未启用**：按计划必须等全部功能对照验收完成。后台已支持 `--disable-web` 和 `--maintenance-web`，开发网页兼容行为保留；游戏日常导航已移除网页入口。
