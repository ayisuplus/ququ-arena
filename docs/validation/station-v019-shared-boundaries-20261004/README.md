# R3合住三户入口与共享庭院边界

2026-10-04｜施工基线 `6dd758ce`｜承接[v019整改v006](../../黑洞空间站升级方案/v019/三项问题整改执行清单_v006.md)。

本批完成Gemini／GLM／Kimi合住建筑的内外入口过渡，并在旧厅—共享楼之间设置一处两人停留位置。三户房间、原墙体／碰撞、居民身份与路径保持；未增加建筑高度或调整全局照明。本批是R3边界和局部材料施工，不代表完整街区或整站验收。

## 布局与材料归属

沿用v006已实际查看的[Habitat 67官方照片](https://www.safdiearchitects.com/projects/habitat-67)中入口过渡、组团公共空间与局部开口的组织方法。家具复用项目既有 `SereneSpacesV013/LoungeDivider.fbx` 与 `WindowBanquette.fbx`，来源见[原生成脚本](../../../production/black-hole-station/v013/p1p2-spaces/build_spaces.py)。本批没有新增下载、Meshy调用或采购。

| 对象 | 已保存处理 | 保留边界 |
| --- | --- | --- |
| 合住外入口 | 两片原型低屏风，既有铺装内裁出约6.35×9.6m的暖石色门前场 | 原2.8m主门、檐柱和外部甲板保持，屏风位于入口两侧 |
| 三户入口隔墙 | 六片深青入口墙、六片白瓷侧墙、三片橡木背墙；15份派生网格补米制UV | 原墙位置、形状、厚度和碰撞保持 |
| 合住室内地面 | 一份贴合内墙的饰面，公共厅用青绿大板，三户室内及门前用暖石色 | 原R3甲板继续承重，无新增地面碰撞；不越过外墙 |
