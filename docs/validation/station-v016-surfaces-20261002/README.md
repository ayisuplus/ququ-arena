# v016 四栋建筑局部反射

2026-10-02，施工基线`e74f3569`。四栋新增建筑各增加一个局部反射区，沿用原刷新器，原26区保留。**本次接通真实环境反射；四馆窗面仍为不透明外壳，透明玻璃、内部空间及最终视觉未完成。**

## 改动与原因

- 原四栋虽已设置金属度/光滑度，却没有独立局部反射区。新采样点位于前庭侧4m高处，影响范围覆盖本栋；B03入口位于局部+X，其余位于+Z。128像素HDR初始立方贴图保存于`Assets/Station/Textures/ReflectionsV016`，运行仍逐区分帧刷新。
- 原26区加新4区共30区，沿用每次捕捉完成后0.5秒间隔；完整刷新周期相应增加，尚未进行目标机性能验收。没有增加Meshy消费，没有改曝光、光源、材质颜色、几何、碰撞或管线配置。
- 初始屋顶采样的窗面缺少环境层次，因此试验前庭侧位置。发现Unity的`ReflectionProbe.center`按世界轴偏移，不能直接填建筑局部偏移：B04左侧两个窗组漏采样。[失败报告](runtime-editor-offset-failed.json)保留。源探针改存世界偏移，四个新增探针各附带`StationReflectionVolume`保存局部向量并随动，源探针与运行克隆均生效；原刷新器代码保持原样。初版刷新器缓存方案在关闭/转环/复启时失败，记录于[复启失败](reenable-editor-cache-failed.json)，最终方案同时修复了初始反射在刷新器关闭期间的跟随。
