## 建筑与来源

- 在原研究亭外围设置四片折面白色屋顶、14×4m中央天窗、上部连续高窗和18根细白立面柱；入口廊采用较低的折脊顶并伸入主屋面搭接，地面不新增支柱。
- 原房间中心(-171,0,15)，24×20m可用室内与东侧4m门洞保留。屋檐28×24m，模型最高8.4m；入口廊复用原6根柱并补上端衔接。
- 原始参考是实际查看的[ZHA KAPSARC官方摄影](https://www.zha.com/projects/architecture/king-abdullah-petroleum-studies-and-research-center)，采用折面白色外壳、深窗洞与入口连接关系。模型按本站实测尺寸原创，没有复制其平面或引入第三方照片/模型。
- Game Development Studio规范包0.1.0保留为首稿；0.1.1增加4cm玻璃实体厚度和屋顶搭接。最终模型15个网格、1,408三角面、12个碰撞网格。Blender源、GLB/FBX、规范包、许可与项目vendor回执均保留。0.1.1包验证及导入字节验证通过，Meshy消费为0。

## 材质与灯光

- 新ResearchCoatedWhite复用北厅瓷白清漆；新ResearchBlueEnamel用于原研究台外壳，#176FD3、金属度0、光滑度0.70、清漆0.75。三个资料墙边框复用BrightSilver，形成蓝色主体、银色边缘和深色屏幕的区别。
- 五块原研究馆窗玻璃与新高窗、天窗采用独立ResearchClerestoryGlass；开启镜面高光，使用Specular工作流、SpecColor(0.06,0.07,0.085)、透明度0.065、光滑度0.96、背面剔除。没有全场替换蓝玻璃。
- 初次双面玻璃试装产生大面积白色背面反射。通过原生引擎对照发现，关闭背面渲染能保留内侧窗面的通透；高窗随后改成实体薄玻璃，避免单片玻璃只能从一侧观看。最终保留较轻的室内反射与天边景观。
- 三盏研究厅原烘焙面灯2.4→0.9，两盏入口廊面灯2→1.2；无新增实时灯。研究馆与入口廊两处反射探针128→256、强度0.6→1，范围扩至新屋顶。光照完成重烘焙，54个反射更新。
- 主光、全局曝光、后期、天空和其他区块共享材质参数未改。本次蓝色釉面和金属边缘已出现明确局部反光，但大面积顶面受光、陈设细节和全站美术仍未完成。
