- 一层：两处窗边双人软座、两张木桌，以及一处双扶手椅会客角；上层：两处相向双人软座与中央木桌。合计四组长软座、两张扶手椅、四张桌子、10个新稳定座位ID。原六户和原座位不改。

- 复用项目已有 WindowBanquette、RoundCafeTable 与 SoftChair 模型和现有派生材质；沿用原比例，不拉伸凑空间。模型及座位位置见[家具记录](furniture.json)，本次新增Meshy消费为0。
- 初轮原生图暴露地坪仍为纯底色。检查原 Homes warm stone 确认它没有BaseMap及NormalMap，不能称为已有完整石材PBR。最终给五块楼层饰面所在的单个Renderer换独立派生材质，复用已入库[Poly Haven Marble 01 / CC0](../../../production/black-hole-station/vendor/polyhaven-marble-01/README.md)，本轮实际查看原始基色纹理后选用。1.5m重复、法线0.16、平滑度贴图乘数0.34；米制平面UV最大误差0，几何与物理地面保持。见[材质记录](material-v002.json)。

形体组织继续采用已批准方案的退台和共享通廊原则；本轮在内置浏览器重新实际查看[Habitat 67官方总体照片](https://www.safdiearchitects.com/projects/habitat-67)，核对高低体块及空隙关系，不将其照片当作游戏资产，也不把它当作室内材料证据。
