# v24：左右升降平台、中央菱形与掌击间距

2026-09-22。本轮按用户参考图重排场地，并修复第二次预览中左右升降台与旧地屏环线的交叠。后端模型调用、胜负判定、计分、存档和事件队列没有修改。

## 最终布局

- 两个圆形升降井同处 Z = 0，中心 X = ±4.50 m；竞技场孔洞、展馆顶棚孔洞、导轨、移动平台和乘舱路线共用轴线。
- 开口半径 1.48 m，平台外沿半径 1.44 m，顶部嵌边最外半径 1.76 m。平台升到顶层后与地屏齐平。
- 中央菱形半对角线 2.50 m，白瓷／银色边框高 5.5 cm。菱形内继续使用原有胜利地屏。
- 删除会穿过升降台的旧 5.9／6.18／6.35 m 地屏环线，只保留 6.48 m 的外围标记。外围线与升降台外沿留出 0.22 m；菱形包围边界与升降台留出至少 0.24 m。
- 冠军的环形高亮改为沿同一外围轨道流动，不再在 5.15 m 左右径向摆动穿过升降圈。保留胜利扩散、选手配色、名称与标识。
- 标准角色在相同缩放下增加 0.40 × 缩放值米的站位间距；等比例 Q 版增加 0.10 × 缩放值米，大小差异较大时保留可触达间距。脚底标记同步缩小，避免两圈相交。
- 掌击通过腰部转动和适度前倾带动肩臂，脚下根节点不移动。仅保留独立的升降入场走位，不增加战斗走近动作。
- 自动取景立即同步镜头变换，修复切换角色后同一帧保存视角可能与内部取景参数不一致的问题。

## 渲染兼容处理

初次 D3D12 场馆检查已通过功能项目，但进程退出码为 `0xC0000005`，不能记为完整验收成功。Windows 事件将故障位置记为 `D3D12Core.dll`；`exit-smoke/exit.json` 与 `exit-v23-baseline/exit.json` 表明普通关闭时，新旧版本都能复现。后台和数据锁在崩溃前已正常清理。

同一 v24 程序显式使用 Direct3D 11 后正常退出，见 `exit-d3d11/exit.json`。因此 v24 的构建脚本将发行版默认 API 调整为 D3D11，仍编入 D3D12；Editor 原配置在构建后恢复。没有升级 Unity、替换驱动或删除显卡缓存，也未宣称已定位显卡／引擎内部根因。最终 Windows 回归使用发行版默认 API，无额外强制参数，并检查进程退出码。

此前的 D3D12 记录与被拒绝的重叠预览保留，便于对比；不把早期功能报告的 `passed` 当作最终退出成功证据。
