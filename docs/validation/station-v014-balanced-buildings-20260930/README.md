# v014 南北双侧公共楼续建

按“多修房子，少种树”继续。北侧西面新增09候舱阅览楼，南侧东面新增10共享工作楼，与上一轮07、08号楼组成南北各两栋的布局。复用完整楼体、外立面和陈设，新增两栋、八间房、二十个可用座位；公共楼累计六栋、24间房、60座。本轮零新增树木、零新增Meshy任务及消费。

单栋主体32×26m，檐口35.6×29.6m，最高约6.46m；家具保持原尺寸。沿用银白壳体、缎面金属、灰米色座椅、圆角檐口和楼号牌，没有新增沿路玻璃围栏。参考既有Norm Architects / Chancery House窗边软包与安静公共空间，本轮实际查看 `docs/黑洞空间站升级方案/v013/references/norm-chancery-36.jpg`；只作设计参考，没有将照片作为游戏纹理。

新建筑是公共空间；没有新增私人住处归属、入住登记、预订、办公软件或居民逻辑。原模型住处和身份保留，静态墙面信息不冒充新业务系统。原05号楼的共享模型、材质、家具和座位能力整体复用，独立重写新座位稳定ID，楼号分别改为09、10。

## 接路与技术验证

- 安装前对两个地块按38×32m、Y=0.4–6.6m检测，未发现既有碰撞体或MeshRenderer包围盒占用。见 [地块检查](site-survey.json)。
- 原拟北侧直连线碰到既有候舱玻璃；向前移动后又碰到赛事信息台。最终采用Z=136.5m的既有通道，绕开两者，保留旧构件和功能。两个失败点及修正证据见 [路线修正](route-corrections.json)。
- 南侧原公共甲板直线穿过新增建筑地块，QA路线改为沿楼前Z=-137m绕行，再进入花园原节点；并增加新楼双向穿厅和各房间路径。旧居民路线与游戏行为未改。图中细线是已测通行轨迹，未新增实体廊道或铺装。
- Editor Play连续CharacterController.Move验证97条命名路线、1203段、约13.93km；包括六栋楼穿厅、房间、书桌接近路径、南北翼接入和原环路。每条路线开头显式放置，路线内部连续移动，居民交通隔离；不等于真人键鼠。
- 78项交互通过：六栋楼60座、原外环16座、档案台开关和研究资料墙。座位使用、起身、位置与相机恢复均核对；实际临时存档按哈希恢复。
- 六栋楼90点屋顶检查通过，净空约3.9m；0缺失脚本，831个参与GI的建筑Renderer有有效光照图，重烘焙10组光照图和52个自定义反射探针。
- 相对 `9f05f5da`，原31767个场景ID全部保留，13576个原Transform、碰撞与行为组件块不变。原四翼、居民住处和业务引用保留。[保留核验](preservation.json)。
- 新Win64构建成功，0错误、1条原有RuntimePipelineConfig警告；2518项构建输入与当前源文件哈希一致。约783.5MB，未启动独立Player。
