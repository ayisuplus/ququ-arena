## 本轮改变

- 新阅读组沿原研修对象包局部 X 向内退让14m，根位置为 `(-14,0,0)`。0/3.6/7.2m三个楼层与11.9m总高保留，未采用压低顶层的试案；实际径向包络约106.65–130.78m，留在R2内。
- 西端由整面白墙改为三层连续侧窗，保留白色窗台、窗楣、端柱和木质侧屏；水平墨蓝窗带与后退上层继续区别科研竖向立面。东端保留实体。
- 原研修馆六块窗台墙改用同组墨蓝材料，原室内地面改为蓝瓷；仅更换七处明确的材料引用。旧曲面屋顶、入口、碰撞与室内功能没有移动。
- 原馆后门与迁位新楼前庭通过两块无碰撞铺装连接；铺装跟随R2，不改变原物理甲板。12个阅读座位的ID、组件及局部位置保持。
- 六张新增圆桌改用尺寸与实体对应的盒碰撞。原先胶囊高度小于直径，Unity实际形状会向下伸入共享地板；本轮消除该实际穿透，未改其他街区桌子。
- 新楼与原研修馆各重烘一张反射贴图，旧贴图保留。继续使用既有合法家具、材料及已查看的真实建筑参考（方案第2节）；新增Meshy消费0。

## 观景退让及被否决方案

精查发现原位置的阅读楼会遮住公园原眼点的赛场中心：1°相对相位取样9–12°受挡，取样端点区间按R2/R3实际相反转速换算约1.40分钟。此数值只表示离散取样跨度，不是连续可见率。侧窗本身没有解除中心遮挡；顶高11.1m与10.9m的数值试案仍有中心命中，均未实装。

随后实际原生试移X=-6/-10/-14m。前两项仍有中心受挡；采用-14m后，常住、短住、公园、固定抵达四个原眼点的360个1°取样中，均无新增阅读楼对赛场中心射线的命中；每点最多仍有1/5边缘射线受挡。不是所有眼点、任意角度或整站观景的穷尽证明，也不消除旧建筑本来的遮挡。

最终实体的219个不透明碰撞近似盒另做7眼点、每点5184组独立双环5°扫描：黑洞方向全部无新增命中；赛场方向科研/咖啡/阅读0，常住/短住/公园最多1/5。固定抵达5°粗网格为0，1°细扫可见1/5，因此不宣称该方向完全无遮挡。[细扫](windows-offset-14.json)、[最终原生输入](inputs-final-offset-14.json)、[双环初筛](sweep-final-offset-14.json)、[三组同机位对照](view-phases-v001/cameras.json)。对照仅隐藏新阅读组，原建筑和当前旧馆饰面在两图中均保留。

**导出修正：** `inputs-reading-v004.json`及`reading-windows-after.json`错误排除了名字含window的实体窗台/窗楣，不作为结论依据。导出器已改为只排除具体玻璃/窗格；v005及所有offset、final输入包含这些实体。错误记录保留。移位前后的有效比较见`reading-windows-after-corrected.json`与`windows-offset-14.json`。
