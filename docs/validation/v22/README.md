## 性能与证据边界

[性能表](windows-02/performance.md)含 12 组配置、CPU / GPU 帧耗时、绘制次数、三角形数及按进程采集的专用显存。展馆六人和比赛事件并行，平均 58.26–59.63 FPS，P95 约 16.67 ms；每组 8 秒且包含前一张截图读回的边界帧。独立 18 秒 4K 观战回归为 59.985 FPS。

本机为 RTX 5090。Q 版在该固定场景下减少约 300 MiB 专用显存；4K 场景三角形峰值约 150 万 → 89 万。显存来自 Windows GPU Process Memory 的对应 PID；Unity 的 `graphicsDriverAllocatedBytes` 在本机返回 0，视为不可用。限帧样本不能推算低端硬件收益。

完整 `windows-02`、两项原有回归完成后，仅增加了工作人员席位高度适配及对应检查；最终编译重新通过全部编辑器检查，并运行 `booth-followup` 和普通启动／重启。漫游、比赛、模型、着色器和交通资产没有随席位修复改变。对应编译和脚本哈希见 `delivery-integrity.json`、`source-scripts.json`；先前编译记录保留为 `build-before-booth-fix.json`。

运输跳过使用自动实机检查调用同一 Esc 处理入口。原生操作工具的一次测量显示两次操作间隔 10.2 秒，超过约 5 秒行程，因此实体 Esc 的该次结果只计作抵达后的返回，不冒充运输中人工跳过证据。

真实付费模型 API 执行不属于本次视觉回归；固定响应与历史事件只验证展示和结算逻辑。没有宣称在低端硬件完成性能验收。
