专用显存使用 Windows GPU Process Memory / Dedicated Usage 按本次游戏 PID 采集，按对应截图后的 8 秒窗口配对；每组 4–5 个样本。原始证据为 windows-gpu-memory.jsonl。Unity 的 graphicsDriverAllocatedBytes 在本机返回 0，视为不可用，不能理解为显存占用为零。

本机 GPU 为 RTX 5090。Q 版在此次固定镜头下减少约 300 MiB 专用显存，4K 的场景绘制三角形峰值由约 150 万降至约 89 万；场馆与其他场景资产也计入统计。角色位置和比赛动画会带来变化，不能用这些样本推算所有硬件的提升比例。

黑洞停用已验证渲染对象与更新组件退出；本机在限帧状态，FPS 差异不能衡量较弱显卡的收益。
