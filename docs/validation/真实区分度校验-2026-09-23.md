## 一句话结论

**证据强烈支持「题库对当前付费模型整体偏易」，而不是「模型变强」。** 本轮实测的 7 个罐里，**4 个对 3 只不同强度的付费模型完全零分差（天花板）**；出现分差的罐（truth-lie、dyck-bracket）经逐题复核，**分差主要来自「输出格式不合规」与「60 秒单题超时」，几乎不是推理能力差异**。

附带推翻了 T-004 的两处结论：
1. **T-004 判 syllogism「✅ 有效（5 模型分差 1.00）」——那 1.00 分差是伪信号**：占位最大的 0.00 来自一家模型 20 题**全部返回空答案**被判 0（该场工具版本尚无「空答案即弃权」守卫）。剔除伪信号后真实分差仅 0.20，而本轮 3 只付费模型 ×3 次重复全部 100%。
2. **T-004 把 truth-lie 归为「偏易」是对的，但归因错**：它不是「模型答得对」，而是**裁判把「戊是老实人」判成错（正解要求只输出「老实人」）**——这是格式判罚，不是推理失败。

**「模型是否随时间变强」本轮仍不足以定论**：3 只付费模型都属当前一代，缺失「同一题库上的历史弱模型基线」，无法做时间序列归因。我们只能说：**对当前这一代（含其中较弱的一只），题库偏易**。

## 三、核心新增发现：exact 裁判把「格式不合规」当成了「答错」

这是本轮最重要的发现，直接决定「罐弱 vs 模型强」怎么归因。

### 3.1 truth-lie：MiMo-Flash 的 9 个「错」里 7 个是纯格式

题面明确要求「只输出「老实人」或「骗子」，不多一个字」。MiMo-Flash 的实际作答：

| 题 | 题面要求（target） | MiMo-Flash 实答 | 判定 |
|---|---|---|---|
| TL-chain-3-01 | `老实人` | `丙是老实人` | **内容对，格式错** |
| TL-chain-4-02 | `老实人` | `丁 是 老实人` | **内容对，格式错** |
| TL-chain-4-03 | `老实人` | `丁是老实人。` | **内容对，格式错** |
| TL-chain-5-01 | `老实人` | `戊是老实人` | **内容对，格式错** |
| TL-chain-5-04 | `老实人` | `戊是老实人。` | **内容对，格式错** |
| TL-chain-5-06 | `骗子` | `戊 是骗子` | **内容对，格式错** |
| TL-chain-5-07 | `骗子` | `戊是骗子` | **内容对，格式错** |
| TL-chain-5-03 | `老实人` | `骗子` | ❗**真错** |
| TL-chain-5-10 | `骗子` | `戊` | ∅ 只回了人名（不完整） |

用「去主语前缀后匹配」的宽松口径重算（`normalize` + 剥离 `甲/乙/丙/丁/戊` 前缀）：

| 罐 | 模型 | 严格分（引擎记录） | 宽松分（去格式） | 纯格式失败 |
|---|---|---|---|---|
| truth-lie | DeepSeek-Flash | 100.0% | 100.0% | 0 |
| truth-lie | **MiMo-Flash** | **65.4%** | **92.3%** | 7/9 |
| truth-lie | MiMo-Pro | 96.2% | 100.0% | 1/1 |
| logical-deduction | MiMo-Flash | 95.0% | 100.0% | 1/1 |

> 即：**truth-lie 区分的不是推理，是「肯不肯只吐两个字」**。格式纠正后，连最弱的 MiMo-Flash 也到 92.3%（唯一真错 1 题）。

### 3.2 dyck-bracket：分差被超时与「泄漏/多余字符」污染

- MiMo 两只均触发 **60s 单题超时 → 退赛**（MiMo-Flash 于 DK-08、MiMo-Pro 于 DK-04）；且超时前平均延迟已达 6.9–9.3s，属**慢 + 长思考**，不是网络限流。
- 未超时的失败也多为**格式**：如 `)][])</think>)][]`（含泄漏的 `</think>` 标签）、`}))`（多一个 `}`）、`>}`（多一个 `>`）；真正「顺序/括号类型错」的清白错题很少。
- **DeepSeek-Flash 23/24（95.8%）**才是干净基线；MiMo 的 50%/66.7% 里混着超时与格式，**不足以作为推理差异证据**。

> 结论：dyck-bracket **不是纯天花板，但当前也测不出干净的推理区分度**——需要先解决「超时」与「格式」两层噪声。

## 四、syllogism 人工复核结论（T-004 遗留问题）

**问题**：T-004 说 syllogism「有效」但方向反常（2.6B ≥ 120B、一家全 0），疑含 exact 裁判格式合规问题——**是否格式问题导致的假 0？**

**复核（读原始 `answer` 文本）——是，且很彻底**：

1. 那家 0.00 的模型（`dots-studio/dots-3-note-preview`）在该场 **20 题 answer 全为空字符串**，`error` 字段为空，延迟仅 ~1s。当时的工具版本（3.8.0）**尚无「空答案即弃权」守卫**（该守卫后来才进 `runner.ts`）→ 空答被当「答错」记 0 分。
   → **它贡献的 0.00 是 100% 基础设施伪信号，不是推理失败。**
2. 另一家 0.80 的 120B 模型，20 题里**也有 2 题空答**（伪信号），另有 2 题是**真错**（把有效式 SY-VA-02/03 判成「否」）。
3. 剔除全部空答伪信号后，该场真实模型分差仅：liquid 20/20、dots3 20/20、nemotron-120B 18/20、nemotron-3.5 16/20 → **真实分差 = 0.20，而非 T-004 写的 1.00**。而且**真错集中在「有效式」上**（模型过度否定合法三段论）——方向确实反常。
4. **本轮 3 只付费模型 ×3 次重复 = 180 条全 100%**，syllogism 的「有效」**未复现**。

**判定**：T-004 的「syllogism ✅ 有效」应被**撤销/降级**。它当年能「看见区分度」，一半靠空答伪信号，一半靠较弱的历史模型在有效式上翻车；**对当前付费模型它是天花板**。

## 五、可执行结论

### 5.1 该重做多少罐 / 加难度档 / 还是 `mine --invent`？

**优先级排序（按性价比）：**

1. **【最高杠杆·先做】修「exact 裁判 = 格式判罚」的结构性缺陷。**
   本轮分差的绝大部分来自「多吐了几个字」，而不是推理。若不改，`analyze`/`mine` 会把**格式不合规**当成**推理弱项**，后续所有「区分度/送分题/翻车题」结论都会被系统性污染。建议二选一或并用：
   - 罐侧：把「只输出 X」这类硬格式题的裁判从 `exact` 换成 `contains`（关键词归一化），或给 `exact` 加「去主语前缀 + 去标点」的等价答案集；
   - 口径侧：报告与 `mine` 显式分离「格式合规率」与「语义正确率」两个维度。
   （**属题库/裁判口径改动，非本轮代码任务，交主理人排期。**）

2. **【加难度档，不换皮】对确认为天花板的罐加更难同族题**：syllogism、stroop-test、navigate、shuffle-track、logical-deduction、truth-lie（格式纠正后）。方向：更长推理链、更多干扰项、对抗性反例——**不是改文案**。

3. **【暂缓 `mine --invent`】**：现在有 588 条新真实观测可喂 miner，但挖出的「翻车题」**多数是格式失败**（见 §三）。在 §5.1(1) 修好前 `--invent`，会造出「针对格式错误」的罐，浪费额度。**顺序：先修裁判口径 → 再 mine → 再 invent。**

4. **【补测量锚点】**：要回答「模型是否随时间变强」，必须有**同一题库上的弱模型基线**。本轮 3 只都是当代付费模型，无梯度下限。建议后续引入一只**稳定不 429 的弱模型**（当前免费档不可靠，需另找付费小模型或本地模型）作锚点，在同一协议下重跑 syllogism/truth-lie。

### 5.2 对题库总量的一句话

原先 T-004 判「2 有效 / 7 偏易 / 0 偏难 / 66 未验证」。本轮把 4 个未验证罐（stroop-test 之外的 navigate/shuffle-track/logical-deduction）**推进为「偏易」**，并把 syllogism 从「有效」**降级为「偏易」**。**偏易罐名单显著变长，有效罐更稀缺**。趋势明确：**对当前模型，题库需要整体加难。**

## 六、未验证与边界（诚实清单）

1. **「模型变强」未被证实也未被证伪**：本轮模型集合全是当代付费模型，缺「历史弱模型基线」，无法做时间序列归因。仅能下结论「**对当前一代偏易**」。
2. **逐题区分度 r 只在 syllogism 可用**（9 观测/题）；其余 6 罐为 3 观测/题，低于 `MIN_REAL_OBS=8`，`analyze` 标「样本不足」是正确行为——这些罐的判定基于**模型分差**，不是 r。
3. **dyck-bracket 的 MiMo 分差不可采信为推理差异**：含 60s 超时退赛（MiMo-Flash 19/24、MiMo-Pro 8/24）与 `</think>` 泄漏等格式噪声；`--limit` 未用于该罐（全 24 题）。
4. **3 个抽检罐用 `--limit 20`**（navigate/shuffle-track/logical-deduction 原题量 24–26），截取的是前 20 题，可能存在题序偏置；结论仅对这 20 题成立。
5. **`analyze` 的「罐体验证」行不分协议**，会聚合历史（含伪信号）→ 对本轮「新数据」的读数有误导（syllogism 的 ✅ 即此坑）。这是**报告口径观察，未改代码**。
6. **CLI 无 `--tier`**：「official」是靠「CLI 不传 freeOnly」实现的隐式正式档，非显式选择；显式档位只在 HTTP 赛事入口。若日后 CLI 默认行为改变，本轮数据的档位语义需重核。
7. **本机 Node v22.22.2 ≠ 宣称的 ≥24**：本轮全跑通，但环境与文档不符，标记待主理人确认。
