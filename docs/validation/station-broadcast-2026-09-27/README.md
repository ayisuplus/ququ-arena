# P3 东侧公共客厅赛场转播核查（2026-09-27）

## 概念与范围

依据 [施工方案 v006 的 LOC-09](../../黑洞空间站升级方案/施工方案_v006.md) 和 [空间站总览 v003](../../黑洞空间站升级方案/08_概念图/IMG-001_空间站总览_v003.png)：转播屏位于东侧公共客厅吧台上方，面向共享座位；保留南侧分段观景窗、客厅至居住走廊的通道。屏幕框架与材质复用场景已有赛题屏，不引入另一套视觉样式。

本轮仅完成客厅内的赛场画面与赛事状态展示。`ArenaStationLiveMatch` 从现有赛事快照提取状态、选手和题号，`StationLoungeBroadcast` 把同一环台的近景摄像机输出到 960 × 540 屏幕；距离客厅超过 30 m 时关闭该摄像机。客厅组件不处理答题、计分或结算。

## 验证

- Unity 6000.3.24f1，已保存的 `BlackHoleStationLive.unity`，脚本同步导入及编译完成，`failed=false`、`errors=[]`。
- 重新从磁盘加载场景后，转播物体位于 `(78, 0.95, 67)`、缩放 `0.4`，场景仅有一个竞技区赛题板；转播屏无碰撞体，也没有悬空支柱。
- Editor Play：远离客厅的玩家位置 `(104, 0.1, 35)` 时转播摄像机关闭；共享座位附近 `(80, 0.1, 58)` 时开启。使用**仅存在于本次 Play 会话内**的赛事快照，屏幕显示 `duel-1`、左右两名样本选手和第 1 题，并从同一竞技场画面看到两名斗士。
- 在场景保存后的步行探针中，沿客厅主路 `z=62` 从 `x=69` 到 `x=94` 的 125 个 0.2 m 步长没有阻挡；南侧窗仍有围护，中央井没有新增遮挡碰撞。
- 截图均为 1600 × 900 的 Unity Editor Game 视图：[待赛画面](lounge-idle.png)、[座位方向的赛事画面](table-view.png)。

## 尚未验收

赛事画面使用内存夹具验证呈现链，尚未用真实后端正在进行的比赛或 Windows Player 验证。额外摄像机的实际 Player 性能、客厅音频、完整家具与植栽、黑洞窗外景观以及 P3 环台主视角都仍需后续制作和核查；本轮不宣称 P3 完成。
