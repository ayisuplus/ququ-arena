# v014 四翼迁移与连续甲板首轮实装

2026-09-30。依据[当前施工方案](../../黑洞空间站升级方案/施工方案_v014.md)，从原 v013 原生复制为 `Assets/Station/Scenes/BlackHoleStationFourWingsV014.unity`，在独立场景施工。

**已有可走的整体布局，尚未完成整站美术与最终验收。** 本阶段不把铺满地面等同于完成空间利用。

![Unity 首轮总览](layout/overview.png)

## 实装内容

- 四区的承载平台收拢到北 `(0,154)`、东 `(154,0)`、南 `(0,-154)`、西 `(-154,0)`，整组复用建筑、家具、门、座位、科研内容与声源，保持原比例和稳定身份。
- 北侧候舱厅移至 `(0,270)`，停泊舱移至 `(0,309)`；延长原高位连接桥至约141m，避免与北翼抵达大厅重叠。高位桥连续实走仍待专门验收。
- Blender 制作直径672m连续甲板，新增约296,363㎡承托面；四条12m斜向主街接外环，中央核心与50m贯通井保留。下层坡道入口有明确让位，不用平板直接封堵。
- 旧跨区长廊在候选场景停用；拆除旧北／东绕行窗墙、外环内侧48块玻璃及对应内侧收边。建筑门窗、外缘与必要高差防护保留。
- 更新四名外出居民的路线、两台货运的检查位置、访客出生点及分区声源。另两名共享起居居民沿用原路线。[原生落位与当前路线](as-built.json)记录实际状态。
- [导览与状态牌](wayfinding.json)同步新方位；通用状态牌去掉写死的旧四角方位，旧场景仍可显示原有功能状态。

## 仍需继续

1. 整理散落的旧休息湾与残余构件，统一四翼前厅、基座与屋檐，补公共区实际使用内容；目前大面积甲板仍显空旷。
2. 完成新北轴、高位桥、全部下层入口的往返和净空验证，以及迁址后的跨重启存档恢复。
3. 重烘焙光照、灯光探针与反射。当前截图已清除旧位置烘焙映射，未代表最终银白柔光效果；旧定制反射图仍需更新。
4. 正常眼高与坐姿逐处审查黑洞视野、材料和陈设。当前正交总览不显示完整黑洞，不能代替第一人称观景验收。
5. 新候选构建、可执行范围内的独立运行、真人键鼠与30分钟性能分别验收。此前独立 Player 启动的自动审批拒绝仍未获解除，不通过换启动方法重试。
