# v015 P2：井口与站体外边界防护候选

2026-10-01，基线 `201d45f5`。在真实建筑候选中加入两组连续防护，保留原对象与场景。本轮验证**赛场停靠状态下的步行边界**，赛事运板开口、升降联动和其它高位/升降孔防护仍待施工。

## 施工内容与归属

- 站体外边界：沿主圆盘、固定抵达前庭、船坞延伸甲板的合并外轮廓闭合，共1028段。主盘半径254m，港区前庭外缘330m，船坞延伸外缘470m；转折点沿原甲板边界连接。
- 整组外边界固定在现有固定设施根节点。主圆盘与港区相接的45°范围没有横向围挡，也不新增第四条主环甲板。R3建筑最大包络半径约247.59m，防护在254m边缘；后续建筑调整仍需重查扫掠。
- 井口防护：中心线半径25.16m，共256段，随原升降赛场对象运动，归R1；Collider内缘最小半径25.09999m。保留50m中央开口及贯通轴线。
- 防护碰撞高度1.25m，帽顶1.28m。复用项目已有蓝色建筑玻璃、瓷白与亮银材质，仅新增对应几何；没有复制更多建筑或引入外部包。复用的是现有材质，当前光照与外观尚未视觉验收。
- 两组各有玻璃面、底座和帽顶，共六个模型资产、两个连续MeshCollider。[构造记录](construction.json)保存完整外围折线和模型来源；[原生施工脚本](../../../production/black-hole-station/v015/p2/create-edge-protection.cs)通过Unity创建/保存对象及资产。

## 验证结果

[施工前调查](before.json)的72个井口径向样本、63个主盘外缘样本均没有连续防护。场景原有97个名称含guard/rail的碰撞体，其中观景坡道已有部分栏杆；不能只凭远景截图判断它们全部缺失。

[原生静态审计](static-audit.json) **11,805项通过**：

- 每段中点、每个接头均检查脚下地面，并在0.35/0.9/1.15m三个高度检查真实Collider阻挡。
- 核对固定外围与随赛场移动的井口归属。
- 四条运动/固定地面交界全周检查，及港区连接口89个方向检查，新增防护均不横断这些通路。
- 保留中央50m开口及向下贯通轴线。

真实角色探针使用原CharacterController和正常环速。12处井口、11处主盘外缘、7处固定港区/船坞边界分别持续向外行走，检查实际到达栏杆、被阻挡、未掉落及所属地面；随后沿井口和半径252m的外环步道各走完整一圈。各边缘压力测试之间重置起点，两个圆周分别连续走完，未声称它们是一条全站连续行程。
