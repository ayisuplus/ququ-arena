## 真实范围

![实测样段](measured-sample-plan.png)

- 阅读馆06与活动馆08的相向入口，由各自现有门楣中心及原生人视共同确认；[坐标记录](sample-geometry.json)保留测量来源。图上灰框是屋面保守包络，不是墙线或新建筑。

- 街道试样采用334–351°，中心线约28.5m。该范围沿现有前庭两端确定；同时观察原门、连檐、两侧甲板与活动馆屋顶。只划材料试样，不将整个阅读街区缩减成这段前庭；新阅读楼及B02关系仍按主方案复核。

## 真实材质来源与方法

实际查看已入库的[Poly Haven Marble 01](../../../production/black-hole-station/vendor/polyhaven-marble-01/README.md)基色，以及项目`StuccoV019/model_albedo.png`的细颗粒白色表面。后者来源沿用[联合材料施工记录](../station-v019-material-joint-20261004/README.md)。没有下载、生成或采购新资产。

每版四机位复制玩家Camera及URP AdditionalCameraData，锁定65°视野和1800×1200输出；场景灯光、曝光、碰撞、入口和身份保持。临时派生材质与网格仅存在于内存，`finally`恢复原引用并销毁临时对象。街面仅把选定扇区三角形分到另一材质槽，不新增、抬升或挖除地面；屋面v002只试验UV和切线。没有将这些Editor图写成正常Player证据。

## v001：不采用

[参数与机位](trial-v001.json)。街面、前庭与接入步道复用石材基色并乘蓝/青色，甲板和活动馆屋顶使用细颗粒涂层。

![v001原生鸟瞰](trial-v001/joint-overview.png)

实际问题：米黄色石材乘青色后仍偏黄绿，过密小块纹理削弱科幻大板尺度；活动馆屋顶出现明显拉伸条纹。调查显示该屋面原UV范围只有U约-0.04625至0.04625、V约0.00065至0.00617，不能直接用米制材质倍率。甲板试样又失去原大板分缝，整体衔接不成立。本版保留为拒绝候选。

## v002：修正色相与纹理尺度，仍需继续
