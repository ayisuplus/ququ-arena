# v26 双舱实机验证

2026-09-23 完成。入口：项目根目录 `Start-Game.cmd` / `Start-Game-v26.cmd`；程序为 `QuQuArena3D/BuildV26/QuQuArena3D.exe`。完整 v25 与用户配置保留。

## 结果与范围

- 空中解说舱扩大至 15.6×11m，位于赛场上方；中央 10×7m 透明玻璃下方是真实场景，无第二相机或录像贴图。底部按钮切换解说席与玻璃观赛，Esc 从玻璃返回席位，再返回赛场。
- 独立 240×135 像素小屏显示真实呈现阶段、双方配色、生命值、掌击、结算与胜者。8Hz 有变化才上传，不增加后端或模型调用；离开后停止更新。
- 裁判舱独立在右侧，拥有自己的状态屏。开赛／赛后提供简短文字提示。当前后端无独立犯规事件，因此未把答错、连接失败或补评标记成犯规；本轮不新增语音播报。
- 现有赛场题目大屏未编辑。解说入口标记放在外侧 HUD 边缘，避免覆盖题目。文件校验见 [preservation-after.json](preservation-after.json)。
- 新上层电梯与水平走廊沿真实路线接驳。四次完整乘舱约 5.4 秒（包括测试额外等待 0.3 秒）；跳过、静态切换和返回镜头检查通过。

## 验证证据

[最终 Windows 记录](facilities-03/booths.json) 与 [生命周期记录](facilities-03/lifecycle.json) 均通过，运行时错误为零。自带 Node，PATH 不含系统 Node；使用独立数据目录和既有本地 mock 对局记录驱动真实 Unity 播放队列，没有付费模型调用。此证据是实际发行版渲染和固定对局回放，不是新一轮真实付费模型比赛。

验证双方掌击、8 次回合结算、开赛和终局共 2 次公告；重复事件及重连没有重放攻击或重复公告，评分没有从提前收到的快照泄漏。检查动作关闭、非当前舱室效果关闭、镜头 FOV 保留与相机恢复。

[几何检查](circulation.json) 包含当前启用的实际建筑网格与运行时看台：9 段水平路线和门口无缺口／阻挡，上层升降井无结构碰撞，玻璃下方 99 条射线无不透明遮挡。主站到原展馆升降台的一处细缝由 5cm 球探测确认支撑并单独记录。原展馆竖向行程不是本次新增井道检查范围。

[Windows 构建](build.json) 成功，0 错误；保留原有 `ArenaVenue.light` 隐藏继承成员警告。D3D11 默认。源文件与实际构建项目核对记录见 [source-staging.json](source-staging.json)。

验收保留早期记录：`facilities-01` 发现替换选手时重设舱内 FOV，随后修正；`facilities-02` 功能全过，但发现入口标记遮题和性能采样包含同步截图编码停顿；`facilities-03` 已移动标记，正常帧率采样在截图后等待 0.3 秒，保留原始失败与原始计时数据。

## 性能

本机 RTX 5090，应用上限 60 FPS，每视角记录 3 秒，截图后等待 0.3 秒以排除 PNG 编码的测试停顿。15 组正常运行平均值为 59.98–60.00 FPS，P95 约 16.67ms。详细 CPU/GPU、绘制数和三角面计数在最终 JSON。此为本机短时实测，不等同于其他配置或长时间压力测试。
