# 原生扩展验收

本轮验证实际 pi 0.85.1 加载器、ExtensionRunner、pi-agent-core 循环、Docker 工作区、Sites 中转队列与数据持久化。模型上游使用明确的合成 HTTP SSE 响应，不消耗用户模型额度；这些验证不构成模型能力提升的证据。

- `regression.log`：379 项已有与新增测试全部通过（随后的小修另见 targeted 日志）。
- `targeted.log`：原生包校验、工具注册、参数、写入拦截、实际 Agent 循环、取消、跨试验状态隔离和旧 Harness 行为。
- `final-native.log`：最终 8 项原生扩展测试通过；同时覆盖动态注册、工具启停、关闭错误和配置版本去重。
- `browser-checks.json` 与截图：桌面新建、编辑、导出/导入、目录与单文件加载检查、配对运行、刷新恢复、离线记录，以及模型行厂商/渠道/连接状态。

原来的真实模型实验与负结果仍保留在相邻 `harness` 目录，本轮不改写它们。
