## 发现与修复过程

- `editor-first/` 与 `editor-diagnostic/` 保留最初446项检查中的三处失败：看台下坡、螺旋坡道顶部上行与下行失去地面归属。诊断记录显示中心射线命中坡道侧面（normalY=0.236），或有效地面比0.5m射线多出0.002–0.040m；胶囊边缘仍有承托。
- 地面检测修复后，`editor-fixed/`、`player-phase0/`、`player-phase97/`的原局部路线各446项通过。这些是历史中间结果，不代替最终主路接入测试。
- 将看台起点延伸到原入口时，第一次选到门面内的位置（77,0），去程从门体内离开、返程被关闭门阻挡。`editor-complete/`及两份`player-complete-*`保留该失败；[原门状态](core-gate-before.json)证实组件未启用。[停止记录](blocked-run-stop.json)记录停止失败的自有Player。
- 随后将起点改为门外公共步道（81,0），启用并适配原门，用真实开门/关门流程进出，未绕过门。最终结果使用`*-gate*`目录。
