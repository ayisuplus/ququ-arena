# 音乐与角色动作 v03 · 2026-09-18

默认音乐换成用户试听选择的《月下咖啡馆》。MiniMax Music 3 在已运行的本机 ComfyUI 8189 生成约 120 秒器乐原曲，经节拍检测、四拍交叠和固定增益处理，游戏循环长 101.564 秒，44.1 kHz 双声道；峰值约 -2.54 dBFS。保留完整原曲、两首候选、工作流、执行图及生成历史。试听选择代表用户选择了方向，不代表代理完成了逐秒听觉审查。

六款模型预设各增加前进、后退、闪避和三种攻击，共 36 个角色专用动作片段。ChatGPT 用连拳、上勾拳与踢击，Claude 用较克制的直拳与闪避，DeepSeek 用拳脚组合，Gemini 用施法动作和星光弹，GLM 用踢击，Kimi 用掌击和直拳。保留原有待机、受击、格挡、胜利、倒下动作，以及 v02 网格、骨骼、原始 UV 和材质。

动画先按原角色骨骼路径重映射，再按 FBX 实际坐标轴消除水平根位移；保留垂直重心变化。运行时将接近、原地出招和后退分开，依据角色的手脚轨迹设置命中时间和距离，并按自定义尺寸缩放。暂停动作会取消未完成出招并回位。一个已判分答案仍只触发一个表现事件，动画不参与竞技评分。
