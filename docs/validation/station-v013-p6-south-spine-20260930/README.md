# v013 南侧主轴、咖啡连廊与窗边休息湾

2026-09-30。本节点在原 v013 场景中接通南侧建筑围护：公共核心到南外环、生态花园到咖啡厅，并把原有两处空停留平台补成有顶棚、有四个可用座位的休息湾。保持银白型材、浅石地面、中性玻璃与克制的线性照明。

新增100块独立玻璃构件（另含两组接口模型内的斜顶玻璃）、35盏烘焙面光、13个Custom反射探针、192个采光点；新装配660个Renderer、333个Collider。四个座位复用 `StationGardenSeat`，StableId为 `v013-south-pause-seat-01`～`04`；没有新增运行时脚本。

材料和造型沿用已实装的 v013 模块；两段降高接口用Blender按实际净空制作，FBX由Unity原生导入。继续参考已查看的 [Norm Chancery House](https://normcph.com/project/chancery-house/) 建筑照片的安静材料关系与疏密节奏；[本地参考54](../../黑洞空间站升级方案/v013/references/norm-chancery-54.jpg)、[参考10](../../黑洞空间站升级方案/v013/references/norm-chancery-10.jpg)为摄影参考，未用作游戏贴图。没有新增采购或Meshy生成消费，复用两份现有60k盆栽。
