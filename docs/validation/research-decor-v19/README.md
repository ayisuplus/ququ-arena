# 科考站装饰 v19 验证

日期：2026-09-21。基于 v18 原生工作台版本。Windows 最终构建：`build-02.log`，运行目录 `QuQuArena3D/BuildResearchV19`。双击项目根目录 `Start-Game-v19.cmd`。

## 画面变化

- 移除 6 束摇头扫射光与 4 盏变色舞台灯。
- 外壳和看台的彩色发光装饰改为金属收边与柔和设备标识。
- 原有三圈彩虹灯带改为单条嵌入式分段数据通道，配合离散金属测量刻度。
- 地屏待机移除彩虹波纹，使用低亮度网格和缓慢流动的数据刻度；保留原有胜利配色及结算触发。
- 两侧增加带实体投影底座的半透明虚拟屏：比赛状态和轨道示意。外围增加四组光学观测设备、散热片与接收天线。

设计参考及源码位置见 `production/research-decor-v19/README.md`。本轮没有新 Meshy 任务或费用，也未改动后端、比赛规则、用户配置或旧发行版本。

## 实机证据

`windows-02/research.json`：全部断言通过。使用隔离数据目录和已保存比赛事件，不进行模型调用，不产生新成绩存入用户数据。

- 已在 Windows 独立程序中查看比赛画面。
- 运行时确认没有彩虹灯带/扫射光束材质，没有新增装饰照明灯，两个虚拟屏材质支持正常。
- 动效设置关闭时，数据屏、地面数据流和共用展示时钟停止。
- 左侧状态条与当前场上真实显示的生命值一致；比赛完成后胜者地屏仍正确展示。
- 首页、比赛主镜头、设备近景、实验站及胜利截图均保留。新增装饰不加入角色与题幕的自动取景范围。

## 保留与边界

v18 主程序集 SHA-256 与此前发行清单一致；用户角色偏好 SHA-256 与修改前一致。原默认入口、v17、v18 均保留。本轮源码备份在 `production/research-decor-v19/source-before/`。

继承 v18 已有功能与验收限制：Docker 启动故障相关的真实工程任务与扩展容器执行未在本次装饰调整中解决，网页默认关闭门槛未提前启用。
