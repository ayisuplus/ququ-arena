## 交互及兼容性

`StationCafeMoment.UseSeatFacing` 仅在v013开启，使入座相机顺着座位朝向；原共享观景目标与空目标旧回退行为继续由默认false保留。[旧行为验证](legacy-facing-validation.json)分别检查指定目标和旧回退目标，均通过。咖啡存档结构未改，原四座和咖啡StableId继续保留。

Player探针只对v013期待10座，v012仍期待4座。新增六座从实际通道逐段走到座位并按原路返回；原四座复用原有就座接近点。没有用瞬移冒充新增卡座的通行验证。

初版圆桌使用胶囊碰撞体，虽然通行通过，但[尺寸复核](table-capsule-diagnostic.json)发现Unity把矮胶囊撑成直径1.48m的球形。改用24边凸圆柱碰撞，实际高度0.78m、直径1.48m，加入高度断言并重建复验。[模型、碰撞与观景检查](model-and-window-validation.json)通过，新组团共55,304渲染三角面；三条1.6m眼高射线穿过保留玻璃，已查看左右侧移图确认中央遮挡消除。射线采样不等于完整压力边界证明。
