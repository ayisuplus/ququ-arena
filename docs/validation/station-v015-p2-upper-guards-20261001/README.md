压力测试使用真实角色、正常旋转，每个测试位置先独立放置，持续向边界外推动1.1秒。检查初始无穿透、到达护栏附近、无法达到外侧目标、逐帧有高位地板承托、无明显掉层和正确圆环跟随。每次最终坐标与目标、最高/最低高度均在 `pressures` 中记录。沿凹角滑到相邻安全地板可以发生，不以单一平面投影错误地判断坠落。

完整往返沿用现有公共入口、坡道和目的地；看台和外环观景路线分别从各自公共路起点开始，不将它们冒充一次连续跨环旅程。
