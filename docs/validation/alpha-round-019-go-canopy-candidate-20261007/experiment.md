# 下一轮唯一临时实验：122⅓–128°单开口

这是协调者依据独立审查修正的实验条件，不改写Alpha原答复。候选尚未创建、执行或采用。

1. **冻结实际基线。** 重查保存V019/Unity身份/非Play，取当前MeshFilter与MeshCollider真实资产、材质slots、GUID、UV、变换、场景dirty及内容hash。使用R18记录的相机世界/投影矩阵、1600×1000和环identity。先确认旧采样结果可以作为该状态的基线，不能只用源码eye代替矩阵或把它称为R16 Player。
2. **只试一个候选。** 既有下边界124°改为精确`115+22/3`，128°端和其余区域保留。不用四舍五入122.333常数制造缝隙，不重提第二开口。基于当前UV派生渲染网格生成独立临时网格，保持旧UV/材质slot、0.24m厚度，补齐新边界顶底与侧封口。禁止执行旧安装脚本覆盖资产或修改共享原件。
3. **测完整支撑接触。** 核对122°和130°两侧内外分枝的实际端帽全足迹、屋面接触/间隙与新切边净距，不能以中心轴端点/柱中心代替。记录原始几何和容差；不制造无承托碎片或开口非闭合面。如果这一步不满足，候选失败，不继续推进为可安装方案。
4. **固定目标比较。** 从R18原始rows选出原最近opaque为檐口、角度<124°的61条crown射线，保存其(x,y)、ray和target身份/位置。对候选全部网格及新封口重新求交，计算仍由候选檐口挡住、被其他opaque挡住、未检出opaque以及不确定的数目。改善主判据是这61条中被檐口挡住的数目真实减少；不能使用“<122⅓°命中归零”，因为未改基线已通过。新封口恰在边界也必须参与。
5. **报告回退与其余区域。** 同时复核其余146条原结构目标；出现新增opaque遮挡、目标丢失/移动或不确定材质必须报告并评估，不能从表中删除。不得以61条的改善推导像素可见率或完整行走。取得同状态一张临时对照图；图和采样只说明编辑态候选。
6. **恢复并封存。** 仅可临时替换渲染MeshFilter；碰撞保持基线，明确此轮未验证候选碰撞。用finally恢复原引用和渲染状态，清理所有临时对象，核对场景dirty/文件hash/GUID与原值。意外dirty时不得保存或全工作区回退；保留证据并只处理可归属临时变化。

成功也只意味着具备进一步采用依据。若进入永久采用，必须另建渲染与碰撞派生网格、保持身份/UV/材质、验证实际几何一致与碰撞/通行，重建正常窗口Player作同配置对照，并完成独立审查。Alpha原提132角度×5半径与路线0/97只是建议，须核对现有入口和实际覆盖，不能自动当作全部回归契约。
