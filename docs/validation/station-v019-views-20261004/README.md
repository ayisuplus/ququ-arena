## 方法与边界

- 当前黑洞是 `V014-HorizonSun.mat` 的全景天空，非可查找的世界球体。以同一玩家URP配置、仅关闭物体渲染的[当前天空校准](native-v001/sky-calibration.png)确认黑洞位于世界+X方向、仰角约20.56°。不是按历史生成器的原始+Z坐标直接推定。
- 7个固定观察点沿用基线位置，只把方向转向黑洞或赛场。科研点是六类必要点之外的补充。摄影机1600×1000、FOV65，完整复制玩家URP AdditionalCameraData；未改曝光、全局照明或天空。
- R2/R3各以5°步长独立组合，共5184组/观察点。科研用不透明BoxCollider近似，玻璃排除；四区用实心退台近似。每个目标取中心及4条邻近射线。**既有遮挡未纳入初筛，射线命中仅为找问题，不能当成可见面积比例、实际运行时间轴或视觉通过。** `possibleBlockers`是该相位两类目标的并集，不代表每个名字都挡住当前目标。
- 原生对照的baseline仅隐藏科研新增组与临时体量，旧科研的材料替换仍保留；不是完整v018复刻。两张图使用相同眼点、相位、目标和渲染配置。实际逐张查看第一组17张图片，并查看后续咖啡、抵达修订图。
- `native-v001`：v003地块、初筛v001的8组有命中机位，共16张对照+天空校准。`native-v002`：v004地块，重拍同样8组相位。`native-v003`：v004地块，按重新扫描v002找到的8组相位重拍（咖啡最不利R2从55°变为110°）。输入地块、每个眼点、角度和URP配置见各自JSON。
