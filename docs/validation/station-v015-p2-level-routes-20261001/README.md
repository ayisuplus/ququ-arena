# v015 两处观景区同层接入与座位归属修正

2026-10-01，基线提交 `77aa3bc2`。对象为 `BlackHoleStationThreeRingBuildingsV015` 独立候选；v014 原场景、原存档与历史落位方案保留。

## 修正内容

现状调查发现两处原低层观景区已在三环迁址时从 -3m 抬到主甲板高度，但对应旧坡道还随组团保留，形成约 0→3m 的悬空上端。科研区的两处座位交互点则错误跟随科研主楼，落在甲板下方；原长椅已正确归入观景湾。

- 将两处科研座位点移回原长椅前，纳入科研观景湾运动包，保留稳定 ID、原朝向及 Walker 引用。
- 将科研和咖啡观景区各一条旧坡道及两侧护栏（共六件）迁入历史停用组，恢复源坐标保存；两区改从连续主甲板同层进入。没有删除源对象，也没有新增地面开口。
- [八对象变更记录](ownership-correction.json)记录候选 ID、前后归属与坐标。[明确落位修正表](../../../production/black-hole-station/v015/p2/placement-corrections.json)覆盖原迁址表中的八条；原 `real-building-plan.json` 不改写。保存性审计在原计划上应用这份覆盖表。

## 验证范围

`StationRingLevelProbe` 使用现有 CharacterController 和 `MoveOnGround`，正常 R2 反向慢速转动，逐帧检查所在环、路径碰撞、目标到达及高度，并检查停留时随环运动。

1. 科研观景湾：R2 外缘公共路 → 入口 → 两处长椅前 → 两个座位点的交互距离内 → 原路返回。
2. 咖啡观景区：R2 外缘公共路 → 原通道 → 观景平台及侧面窗前 → 原路返回。

两条路线分别从自己的公共路起点放置角色，随后连续步行往返；不声称这约 264 米是一次跨环完整日常行程。座位行为仍待 P3 适配，本轮只验证点位归属与实际可接近性，没有宣称坐下/起身功能已经恢复。
