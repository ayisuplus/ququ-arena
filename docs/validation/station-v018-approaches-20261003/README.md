# v018 四馆入口与公共环街连接

2026-10-03。延续 v015 步行优先和 v016 入口接组团道路的已批准方向，在 `BlackHoleStationAnnexInteriorsV018` 候选中补齐四馆的地面引导铺装。原甲板本来可走；本次解决的是门前空白甲板缺少连续入口表达的问题，不把既有地面的通行能力算作新建能力。

## 实际改动

| 附馆 | 接入关系 | 铺装 |
| --- | --- | --- |
| B01 月帆会客馆 | 两门前庭汇入 R2 外侧环街 | 共享前庭及 2.8m 支路，浅蓝瓷面 |

新增四个网格、四个渲染器，共12个三角面；共享既有环街材质和4m铺装纹理尺度。铺装属对应环的公共景观节点，随环运动，地面仍由原连续甲板承托；无新增碰撞、灯、屋顶或种植。建筑包络、门、坡道、家具、原功能与稳定身份保留。主公园继续无屋顶。

- 正常可见 Player 另行采集四处人视入口；隐藏功能路线与可见画面分别记录。当前施工候选的技术验证不等于整站完成或用户视觉认可。
