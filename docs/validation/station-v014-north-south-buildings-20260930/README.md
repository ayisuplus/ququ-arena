## 布局与复用

北楼中心 `(90,0,160)`，朝向0°；南楼 `(-90,0,-160)`，朝向180°。单栋主体32×26m，屋顶34×28m、高6.18m，中央4m通廊和2.4m房门保留。使用09a12e85与b0ed8404已完成并验证的建筑壳体、阅读家具和资料说明，通过Unity原生API复制与重新接入，不拉伸模型或重做已有资产。

最初实测 `(±30,±166)` 会压到候舱／花园主体，`(±66,±170)` 会压到原树岛和坐席，均未安装；最终位置的38×32m碰撞退让包围盒、34×28m视觉包围盒检查没有命中旧构件。读数见site-survey.json；包围盒筛选不替代后续真实控制器通行。

两楼服务北侧抵达后的阅读、会客及南侧公共阅读、讨论。已有书墙、圆桌、软座、窗边书桌、资料墙随完整房屋一起接入。书册是装饰，房间未引入会议预约、住宿、办公模拟或新居民系统。新座位采用v014-northsouth-*独立ID；原Walker引用保留，未复制居民身份、存档主体或比赛权威。

## 验证与边界

Editor Play通过81条路线、1037段约12.59km控制器行走，涵盖旧路、两栋新楼走廊／房间／窗边座位及旧前庭至新入口；56个座位、档案台和已有资料墙共58项检查通过。逐条路线显式放置起点，内部连续CharacterController.Move，居民交通隔离；交互API检查不代表真人键鼠测试。Editor原存档按文件哈希备份还原，测试存档不入Git。

本轮保护核验要求全部旧对象ID及原Transform、碰撞、Behaviour保持，新增原生审计检查30个屋顶净空点、20个新座位ID、材质和GI。最终结果见audit.json、runtime/walk.json、runtime/interactions.json、preservation.json。全站光照和50个自定义反射探针更新后才同步Win64构建，当前源输入匹配见artifact-check.json。

技术验证、视觉自检及用户认可分开记录；这轮补南北建筑数量与可用空间，整站最终美术、真实设备和30分钟性能尚未完成。独立Player此前启动被自动审批以blocked by policy拒绝，本轮未换方式启动。

最终审计为8组GI贴图、50个反射探针、零缺失脚本；保留29,981个原对象ID及12,917个原Transform／碰撞／Behaviour数据块。Win64构建0错误、1条既有RuntimePipelineConfig缺省警告，782,085,235字节，2,498项当前输入哈希一致。Console增量1条，详见console-errors.json，不宣称Console零错误。
