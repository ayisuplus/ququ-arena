## 实装变化与来源

- 四层阅读空间的后墙新增28块薄饰板，采用约1.8m分格、36mm拼缝与厚度、较柔和的靛蓝表面。单个合并网格，336三角面；没有新增碰撞体。深蓝原墙在缝内可见，形成板块厚度，保留柱、窗框与银色细部的不同反光。
- 原建筑木饰面每米3×2.2次重复改为每2m一次，减轻染色强度并接回已有粗糙度转换图。六张圆桌使用独立的圆桌木纹材质，不再和建筑大面共用重复尺度。
- 木纹来自已入库的Poly Haven **Oak Veneer 05**，作者Jenelle van Heerden，CC0；沿用[来源与许可清单](../../../production/black-hole-station/vendor/polyhaven-oak-veneer-05/source-manifest.json)。本轮实际查看了原始漫反射纹理，并核对GUID指向该资源。`Research walnut`是历史材质名，当前实用的是染色橡木纹理，并非新增胡桃木扫描素材。新增下载、Meshy调用和付费均为0。
- 旧科研馆仅四个渲染器换用本区派生材料：蓝色墙板、白瓷门头、银色收口、齐平门槛。位置、网格和共享源材质均未改；具体旧新GUID与对象ID见[替换清单](original-material-substitutions.json)。
