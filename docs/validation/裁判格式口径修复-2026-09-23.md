## 一句话结论

**「exact 裁判把格式不合规当答错」确认属实且面很宽：75 罐里 67 罐含 `exact`/`contains`/`regex` 判分**，其中 62 罐未停战。本轮以**纯增量**方式修复——给 `exact` 加一个 **opt-in 的 `lenient` 开关**（默认关闭，既有 exact 语义零变化），只接受「**答案语义正确、只是多说了话**」这一种作答（T-007 真实案例「戊是老实人」→「老实人」）。已在 **truth-lie** 罐启用为样板并**实证：7/9 纯格式失败由「判错」转「判对」，2/9 真错/不完整仍判错**。其余罐的启用清单交主理人拍板。

> 为什么选这个最小口径：用户要的是「**不能在画面上把答对的判成答错**」（诚实），不是「放宽判分」。`lenient` **单调更宽松**（只会把 0 变 1，永不把 1 变 0），且规则紧到**宁可维持严格误杀、也不放过真错**（否定式/异主语/超长前缀一律拒绝）。

### 1.2 分类清单（按「答案形态」分三类）

> 分类是启发式（目标长度 + 分隔符），下表的**归属经人工复核**。列 `arena.judge` 为罐级判分；`med/max` 为参考答案字符长度中位/最大；`STOP` = 停战。

#### 第 1 类 · 答案即固定短串（exact **合理**；误杀形态 = **多余前后缀**）—— 55 罐（`lenient` 可修）

答案本身就是一个固定 token：是/否、选项字母、数字、单字、固定词或固定短句。`exact` 用在这里**原则正确**，但真模型常多吐「主语/导语」（「戊是老实人」），这才是 T-007 的分差主因。

| 罐 | 参考样例（max） | 罐级 judge |
|---|---|---|
| anagram-check / palindrome-cn / conditional-logic / syllogism | `是`/`否`（1） | `exact` |
| analogy-pair / definition-judge / poem-match / reading-mini / word-blank | `A`（1） | `exact` |
| arith-word / data-analysis / stroke-count / zodiac-year / idiom-blank / measure-word / mini-sudoku / zebra-mini | 数字/单字（≤4） | `exact` |
| base-convert / roman-num / t9-encode / unit-convert | `44`/`XLIV`/`43`（≤9） | `exact` |
| element-symbol / province-plate / reference-cn / logical-deduction / odd-one-out / temporal-seq / star-sign | 短词（≤3） | `exact` |
| emoji-grid / navigate / stroop-test / shuffle-track / math24-judge / judge-shield / verify-claim | 方位/是否/颜色/代号（≤8） | `exact` |
| idiom-fix / tongjia-typo / cipher-decode / xiehouyu / childhood-song / couplet-chain / pattern-grid / emoji-quiz(STOP) / digit-slang(STOP) | 固定词/诗句/歇后语（≤13） | `exact` |
| honesty-trap / date-reason / session-shift / soup-lateral(STOP) | 数字/日期/短答（≤10） | `exact` |
| **truth-lie** | `老实人`/`骗子`（3） | `exact`（**本轮启用 lenient**） |
| tongjia-pinyin | 整句「北京是中国的首都」（13） | `exact`（**边界**：还原句子本就是任务，见 §1.3） |

#### 第 2 类 · 答案是「串」（内部标点/分隔符/顺序敏感）—— 7 罐（`lenient` **不覆盖**）

答案是带分隔符/顺序/格式的串。`exact` 合理，但口径脆弱：分隔符换 `、`/`，`/`,`、日期补零、大小写都可能误杀。**建议走 `alternatives`（等价写法）或 `contains`，而非 `lenient`。**

| 罐 | 参考样例 | 罐级 judge | 备注 |
|---|---|---|---|
| case-extract | `B,A,D,C` | `exact` + 逐题 `contains`×12 | 逗号分隔的顺序串 |
| event-order(STOP) / sentence-order(STOP) | `35412` | `exact` | 数字顺序串 |
| word-sort-pinyin | `地铁、轮船、葡萄、西瓜` | `exact` | `、` 连接 |
| experience-replay | `18/06/2025` | `exact` | 日期格式 |
| navigate | 坐标 / `是否` | `exact` | 混两类 |
| session-shift | `不需要` | `exact` | 短串 |

#### 第 3 类 · 开放作答却用精确判分（真·**误杀高危**；`lenient` 不够）—— 少量（≤5）

目标含括号别名 / 整句 / 英文词条，语义等价写法多。**建议走 `llm` 裁判**（与 T-008 同路）。

| kb-fringe | `资源不存在（Not Found）`（max 45） | `exact` + 逐题 `exact`×20 | 词条含括号/别名，措辞一变即误判 |

| 方案 | 做法 | 影响面 | 风险 | 本轮处置 |

### 推荐 & 理由

1. **主推 A（已落地为 opt-in）**：直接命中 T-007 主线（纯格式失败），且**单调更宽松**——不可能把已判对的判错，改动风险可控；缺省关闭，**不动 75 罐既有战绩口径、不砸契约测试**。
2. **B 免开发**：`alternatives` 已存在，第 2 类（串式）直接用它列等价分隔符写法即可，无需动 schema。
3. **C 作为紧接的下一步**：本轮已把「纯格式失败」的判定构件（严格 vs lenient 的差集）做出来了，报告层分列只是消费它。
4. **D 仅用于第 3 类**：真正开放作答（kb-fringe / tongjia-pinyin / voxel-craft）用 `llm`，别硬套规则裁判。

**接受 / 拒绝规则（写进代码注释，可立即执行的一页规则）**

- **接受**：
  - **R1 前置冗余**：`a = <短前缀><答案>`，前缀以**系动词/冒号收尾**（`是`/`为`/`等于`/`就是`/`＝`/`=`/`：`/`:`）**或整段是导语**（`答案`/`答`/`结果`/`结论`/`所以`/`因此`/`故选`/`选`/`应该`/`我认为`/`我觉得`/`我想`），**且前缀 ≤ 4 字、不含否定词（不没非未无别莫否）**。例：「戊是老实人」「答案是老实人」「答案：老实人」「所以老实人」。
  - **R2 首句即答案**：`a` 以答案开头、其后紧跟句读（`。！？!?；;，,.`），视为后续是解释。例：「老实人。因为乙说真话」。
- **拒绝（宁严勿纵）**：「戊不是老实人」（前缀含否定）·「我认为戊是老实人」（前缀 5 字超长）·「所有人都说他是老实人」（前缀超长）·「老实人吗？」（疑问非作答）·「骗子」对「老实人」（真错）。

**已知不覆盖（诚实边界）**：英文导语（`The answer is panda`）不修——仅认中文系动词/冒号；逗号分隔串、等价改写仍不认（那是第 2/3 类，走 `alternatives`/`llm`）。

## 未验证与边界（诚实清单）

1. **`lenient` 的真实收益只在 truth-lie 单罐实测**：其余 61 罐尚未逐罐做「真模型答错样本」的宽松口径复算——本轮**无真实模型调用**，只有 truth-lie 有 T-007 现成的 9 条真实作答样本可对。
2. **`lenient` 可能引入假阳性（本方案的主要风险）**：规则**故意**只接「薄包裹」，但**仍可能**把「异主语但答案字面吻合」的作答放过（例：问「戊」、模型答「甲是骗子」——前缀「甲是」合法）。该风险 **T-007 的人工宽松口径同样存在**（其复算也是「剥主语前缀」），本轮**沿用同一口径**、不额外放大，并已用「宁严勿纵」回归测试钉住边界。**这是 A 方案的固有代价，需主理人知悉。**
3. **英文 / 分隔符 / 等价改写不覆盖**：`The answer is panda`、`B,A,D,C`↔`B、A、D、C`、`雨`↔`雨水` 一律不修——分属第 2/3 类，应走 `alternatives`/`llm`。
4. **`LENIENT_MAX_LEAD=4` 是经验阈值**：4 字能覆盖 T-007 全部样本（「戊是」=2、「答案是」=3）。放大会吃进「我认为戊是」（5 字）这类**语义正确**的作答，但同时放大假阳性；本轮**取保守值**。
