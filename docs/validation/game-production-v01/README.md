# 正式资产迭代验证

日期：2026-09-18，Windows / Unity 6000.3.24f1 / RTX 5090。可运行目录为 `QuQuArena3D/BuildProduction`，项目根目录 `Start-Arena3D.ps1` 优先启动该版本。早期 `Build` 和原型验证记录保留。

## 已进入游戏的资源

- Meshy 玉甲拳手：22,975 三角形、24 根骨骼；待机、直拳、受击、格挡、胜利、倒地六个动作。Blender 整理动作轨道和导出，原始 GLB、可编辑 `.blend`、任务 ID、散列与消费记录在 `production`。
- Blender 场馆：8 个网格组，97,560 三角形，直径 28 米。
- ComfyUI 主菜单图：本机 Z-Image Turbo 工作流，采用第二版；原图和工作流已保留。
- 《青铜回路》：本机 MiniMax Music 3 生成，处理为 33.435 秒循环。WAV 内置到游戏，打击、格挡与结算音效由代码合成。播放与技术数据通过；不把技术检查说成用户听感认可。
- Noto Emoji：1487 个字形预烘焙，符号无需依赖目标电脑字体。中文和 Emoji 字体的 OFL 许可随源文件提供。

Meshy 共使用 61 积分，余额从 3426 到 3365；其中包括未采用为待机的 Boxing Practice。预估 30 只覆盖初始角色生成。未购买或充值。ComfyUI 使用本机 GPU，无 API 积分消费。Meshy 绑定输出只有颜色贴图，当前角色未声称保留完整 PBR 通道。

## 真实模型联通的边界

隔离后端 8186 读取现有模型配置，结果写入独立临时目录，不复制密钥，不写入用户原有战绩。Ling 免费模型实际成功作答；Liquid 和 Gemma 免费节点返回 HTTP 429，重试后按原引擎规则退赛，失败保持 `hasScore=false`。原始事件分别在 `real-model-partial.json` 与 `real-model-second.json`。这证明成功答案与服务失败的联通处理，不能代替两个远端模型均成功完成整场比赛的验证。本轮未发起收费模型调用。
