# R3六户组团：归属盘点与收紧试摆

2026-10-04｜已保存场景基线 `7026dfb8`｜本批是原生临时试摆，尚未安装。

[当前原生盘点](survey.json)包括9个组、284个MeshRenderer、6个房间身份和6条居民路线。三户独立住宅与另三户合用楼、共享休息厅及三层共享楼构成当前六户范围。门廊柱、住宅基座与饰面、公共铺装、共用弧形廊檐分属不同对象组；不能只移动住宅根节点。

## 两版比较

用同一24个Transform整体沿R3移动：三户住宅根、六根门廊柱、十二组住宅饰面、共用廊檐根、共享青绿庭院与内街接入面。三户间相对关系与半径保持；共享楼、另一组三户、环街和其他功能不动。试摆连接带随之缩短，原网格与碰撞在结束后恢复。

## 安装前必须同步的内容

- 原三户居民路线使用R3坐标而非住宅根局部坐标。迁位时旋转各条从房间到主环街的前缀节点，原目的地、环间路径、半径、房间和居民ID保持；检查往返及初始化朝向，不能只移动居民初始对象。
- 三户共用廊檐、门廊柱和十二组饰面一起刚性移动，保持碰撞绑定。住宅庭院及内街接入仍接连续环街，连接共享休息厅的弧形铺装从63–76°缩为73–76°；实际板面、UV和碰撞需单独检查。
- 核对移动包络与环街座位、其他附属件；新位置和旧址的甲板、表面重叠、前庭归属一起审阅。旧场景／旧档保留，旧世界坐标存档迁移不能假定兼容。
- 安装后验证六户门口、共享楼上下层／座位、六居民日常路线、两个相位及正常Player新旧同框；完整高度、材质和全站旋转观景继续按v003验收。

[试摆报告](trials-v001/report.json)记载24个目标Transform和两版机位／包络。试摆结束时原位、原材质及原网格恢复，未进入Play模式；随后重载已保存候选以清除浮点回写影响，见[恢复记录](restored.json)。本批无新增美术资产或消费，不能把这些试摆图片当作已安装Player效果。
