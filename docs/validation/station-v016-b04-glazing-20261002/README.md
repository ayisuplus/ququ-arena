# B04 前后透视玻璃与四馆旋转反射范围

2026-10-02；施工基线 `0246484c`，独立 v016 候选场景。技术验证与用户视觉认可分开；本批新增 Meshy 消费为 **0**。

## 本批变化

五个原错层舱块的前窗改用浅绿透明玻璃，后窗同步切开真实墙洞、补四边棕色窗套。五组玻璃对应十个前后窗，能看见原楼板、顶板和对侧窗。中央核仍封闭，其玻璃饰面保持不透明；房间目前没有家具，内部与露台尚不可进入。原建筑、住户/房间身份、楼层位置、地块和碰撞保持。

`refined-v002` 为原草模整理后的新版本，v001和原Meshy输出保留。GLB 35,908三角面、5材质、25网格；Unity只替换10个墙/窗套网格引用，最终混用资产为35,716渲染面，原碰撞3,664面。尺寸25.400×15.430×14.890m。GLB里的材质仍是建模阶段材质；透明效果来自Unity派生材质，不能把GLB直接宣称为同效果成品。

## 旋转反射修正

扩大玻璃覆盖检查后，发现原实现只随建筑旋转反射中心，反射盒尺寸仍沿世界轴保持不变。B03在45°/97°的部分端窗、门和玻璃失去自身反射区，失败报告保留在 [修正前记录](runtime-reflection-before-size-fix.json)。

`StationReflectionVolume` 增加局部尺寸，按旋转后的三个轴计算世界轴包围盒；未配置尺寸的旧组件保持既有行为。只配置四个新增馆的源反射区及其运行副本，B03包含当前坡道包络。原26区和刷新器源码未改。B04重烘焙到新EXR，旧贴图保留。
