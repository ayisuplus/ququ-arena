## 施工内容

科研主馆原有五段窗下墙补蓝色瓷面，按原柱网分缝；增加银色窗台、连续白色窗楣及四米入口的侧框和蓝色门楣。53 个小构件合并为三个原生 Mesh，分别配合匹配的 MeshCollider，均在原研究馆包内随 R2 旋转。复用项目已有三种材质，没有导入新资源或修改全局光照。

原玻璃、柱网、屋顶、地面、仪器、档案桌和功能对象保留。场景序列化差异只新增 17 个对象/组件块，并在研究馆原父级的子节点列表追加一个引用；无原有块删除，其它原有块没有变化。见 [scene-diff.json](scene-diff.json)。

造型参考在前序施工中通过内置浏览器实际查看了 [ZHA 的 KAPSARC 官方实景](https://www.zha.com/projects/architecture/king-abdullah-petroleum-studies-and-research-center)，借鉴白色构件、深色玻璃与檐下收口关系。没有下载或导入官网图片。本馆继续使用项目已选定的蓝白配色。
