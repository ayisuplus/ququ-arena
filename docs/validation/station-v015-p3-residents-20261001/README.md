## 居民子状态

- 缺省/version=0仍按原 `Route`验证旧世界位置，包括历史入站末段索引修正。候选根据旧路线从家到目的地的累计路程比例，映射到新路线上的安全中心点，保留去/回方向、活动状态、剩余等待、访问和回家计数。迁址会改变世界位置和路径点索引，不承诺保留旧站体坐标。
- version=1按新路线段索引、去/回方向和段内进度保存；position留作记录，恢复位置由当前路径参考系重建。不同环相位下仍回到对应路径段，避免把旧世界坐标投到建筑内。
- 本轮证明居民子状态兼容和跨进程读取，**完整StationWorldSave仍未启用**，不声称整站旧档迁移完成。

[真实旧档居民条目](legacy-residents.json)来自[来源及哈希记录](legacy-source.json)中的既有v014存档，原文件只读。迁移记录和异常状态拒绝、旧目的地恢复、赛事隐藏/恢复、公开答卷归属以及咖啡座位保留，见[85项Editor状态检查](state-audit.json)。其中赛事快照和选手为内存夹具，真实后端仍未连接。
