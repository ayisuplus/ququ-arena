# v019 旧阅读／活动馆屋面施工

2026-10-04｜施工前基线 `ab78128f`｜独立候选 `BlackHoleStationDistrictsV019.unity`

两座旧馆采用薄化曲面、白色边缘与有色内场，阅读馆为墨蓝，活动馆为青绿。该批降低旧顶的厚重感、减少连续大白面；原入口仍以低馆为主，完整组团的高低关系和布局任务继续未完成。

## 实际改动

- 两顶原生网格各4,352顶点、8,448三角面，保持X/Z位置，将Y按 `6.2 + (原Y - 6.2) × 0.35` 变换。最高点约8.407→6.972m，檐底保持6.200m，原室内天花仍为5.475–5.605m。未增加楼层、未更改室内净高或占地。
- 保留外侧两个原网格环作为白色边缘，内部板面使用派生墨蓝／青绿涂层；分别保留阅读木檐底和活动白檐底。复用已安装材质及纹理，新增2个网格和2个材质，无下载、Meshy任务或新增费用。
- 两座屋顶MeshCollider均改为对应新网格，避免保留高于可见屋面的旧碰撞。其他碰撞、原入口、楼层、家具、稳定身份和光照保持。
- 原轮廓配有色面、薄轮廓配有色面均做原生试样；采用后者。未采用的[原轮廓图](trials-v001/original-profile/group-overview.png)及完整试样保留。屋面范围沿原网格环收止，没有铺设额外设备或假采光天窗。

## 原入口问题的证据

![原入口仍以低馆为主](render-v001/main-arrival.png)

[保存后原生检查](saved-audit-v001.json)沿用原入口R2眼点(-29.7,1.7,92)、目标(-40,3,127)、FOV65和1.6画幅。新阅读楼所有675,387个网格顶点均在该视锥之外，顶点平均中心的水平偏角约85.27°，水平半视角约45.55°。这是取景范围检查，不能证明其他朝向无阻挡或路线已经合理；它说明继续削旧屋顶不能使新楼进入该原朝向画面。

下一步沿原到达路径补“接近—转向—入院”的平面视锥与连续人视，比较新翼接街／前庭转向关系。原机位继续保留，不能只用上面的街边同框图关闭高度任务；必要的体量调整应同时检查原门、主街、楼梯及观景包络，再进入R3六户整组。
