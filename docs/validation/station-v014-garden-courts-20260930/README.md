2026-09-30。在已确认的连续圆盘和四翼总图内，补四翼前庭至外圈步道之间的景观层次，天边银白黑洞方案保持。

## 空间和资产

八组花园位于半径211—241m范围，中心角22.5°＋45°×序号。每组两条8m深弧形种植池夹14m宽步道，中间6m穿行道连接前庭与既有环路。旧导览和跨甲板路线同样保留6m宽缓冲。约6911平方米种植区，58株树、1691株低植物；采用现有珍珠白池壁、石材、土壤和植物材质，没有新增玻璃围挡。

先实际查看 [Apple Park 官方建筑与园林照片](https://www.apple.com/newsroom/2017/02/apple-park-opens-to-employees-in-april/)中的曲线银白建筑和树群关系。仅作空间参考，未下载为项目纹理，也不将参考照片当作游戏实拍。树木和地被复用项目已接入的资产，Blender处理精确池体和派生远景网格，本轮Meshy消费0。

首轮实拍发现东、西休息亭边缘与新花坛相交，随后以原屋顶实际边界外扩3m裁切新花坛、植物和铺装，原建筑没有移动。失败候选图保留在 `attempt-01/garden-aerial.png`。第二轮实拍确认花坛退让和门前空地；两处亭侧退让通路均纳入往返测试。

![花园与休息亭的衔接](after/garden-aerial.png)

## 植物与渲染

58棵树均使用三档LOD：原近景164268、中景32853、远景6005三角形。远景由项目已有19846三角形网格派生，保留长枝干，减少叶片并适度扩大剩余叶片以维持树冠。首轮5055面版本过于稀疏，已修正；失败图保留在 `attempt-01/far-canopy.png`。25m自动档和100m强制近／远档实拍位于 `lod/`，最终远档枝干和主要树冠轮廓可辨，细叶仍比近景稀疏；这不等同于运行帧率或动态切换无感的验收。

地被分成32个组合片，按布局复用8组、每组3档网格。新增216个采光探针；48个硬景Renderer重新加入9组光照贴图，46个自定义反射探针更新。没有新增运行时脚本、材质实例或付费依赖。
