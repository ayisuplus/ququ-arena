# v019 阅读—活动馆旧立面与连接檐施工

2026-10-04；施工前提交 `9b43cde8`，仅施工独立候选 `BlackHoleStationDistrictsV019.unity`。本批按整改清单第11节推进R2旧馆：阅读馆增加厚端墙、凹窗与墨蓝窗头；活动馆保留通透门面并使用独立青绿基部；连接檐缩窄、端部退让，保留原门廊与两组支承。本批没有增加楼高，尚未关闭完整街区的布局、高度与材料目标。

## 归属、参考与实际视线

![原生测绘组团图](group-plan.png)

[原生调查](survey.json)包含418个渲染对象与相关变换。图中虚线是实际屋面顶点投影，实线是原墙柱中心连线；两者均与新增端墙区分。新阅读楼使用玻璃保守包络，不能当成整栋墙线。所属运动环为R2，沿用06/08原功能与稳定身份，不迁移两馆、楼梯、座位或住宅。

设计沿用主方案中已经查看的[Habitat 67总体参考](https://www.safdiearchitects.com/projects/habitat-67)与[挪威歌剧院外观参考](https://www.snohetta.com/projects/norwegian-national-opera-and-ballet)：转译组团主次、白色实体与凹入深玻璃的前后关系。本批复用已有屋面细涂层、墨蓝窗台与橡木檐底材质；未下载新参考资产，未调用Meshy，新增消费为0。

[平面视锥计算](plan-measurements.json)显示：原到达眼点的水平半视场约43.70°，新阅读楼玻璃包络各角相对朝向为68.30–97.46°，主要位于视野之外。它只证明该玻璃包络的平面位置，不是整楼遮挡结论。因而本批缩檐用于减少低檐占据前庭、改善两门连接层次，不声称缩檐后原朝向能直接看到新阅读楼。转向阅读楼的正常眼高机位用于复核既有中层与低馆关系，完整连续到达轴线仍待继续。

## 图像判断与后续施工

端墙有了实体厚度，阅读馆的水平深窗与活动馆的通透门面开始分开；连接檐底的木材及深边形成局部材质层次，近景端墙未再见早期条纹。原生总览仍以大面积白甲板、低屋面和较松散的旧楼群为主；门前已改善不代表布局整改完成。新增白墙的大面细节、旧新楼接街的连续性、前庭侧边与周边甲板仍需一组处理。

下一批继续R2：沿实际进入与转向路线完成新阅读楼—06—08的街边和空间主次，补对应剖面与两个日常眼点的高低关系；在完整街段上审阅墙地顶，再转R3六户门庭与共享楼。保留三环运动、固定步道、原门与座位视线、公园开敞和银白吸积盘。技术通过、图像审阅和用户最终认可分别登记，完整三项整改及P5均未关闭。
