# v014 下层入口收口与北轴通行

2026-09-30。在 `BlackHoleStationFourWingsV014` 内继续[现行方案](../../黑洞空间站升级方案/施工方案_v014.md)。本轮解决连续甲板与原下层舱的接口，未改四翼布局、室内用途或黑洞。

## 实际改动

- 咖啡区下层观景舱：两段旧通道护栏原本伸至舱内 `z=-106.25`，阻断横向通行；现止于入口 `z=-100`。
- 科研、咖啡下层舱：窗墙顶收至 `y=-0.85`，顶板位于 `y=-0.85..-0.67`，并入主甲板下方。下层地面为 `y=-3`，平顶下净高2.15m；科研坡道上方分成三段顶板，中央让开至 `x=-225.5`，保留实际站立净空。
- 科研舱原来露出新甲板的悬顶、四道门架和坡道玻璃顶停用；四根舱角饰柱收短，原玻璃地板、两座软包坐凳及身份保留。
- 两处下行口各加三段银白矮墙，仅保护实际高差边缘，不沿公共街道新增围挡。未扩大甲板开口。收口参考沿用已查看的 [Chancery House 楼梯与金属收边](../../黑洞空间站升级方案/v013/references/norm-chancery-54.jpg)，复用项目珍珠白材质。
