# v014 两栋短住舱与八套房

落实“多修房子，少种树”：在六栋公共楼之外，增加两栋可以进入、关门和坐下休息的短住舱。东侧11号位于 `(168,0,-88)`，西侧12号位于 `(-168,0,88)`，按180度旋转对应。原中央住处、居民身份与日程、四翼和六栋公共楼保留；没有新增植物。

![实装位置与平面](as-built-plan.png)

## 空间和操作

- 每栋24×20m、四套房，檐口26×22m、最高4.16m。3.4m宽通廊贯穿南北，两端均可出入；主体侧墙为实体墙，观景窗集中在房间端部。
- 八套房均配置床、床头板、衣柜、洗漱间、简易备餐柜、窗边书桌与起居座位。沿用已有Meshy软椅、书桌和圆桌，新增共享的建筑与房内模型；本轮未发起新Meshy任务，消费为0。
- 新增16个可用座位，沿用E坐下／离座及视角恢复逻辑。房号101–104、201–204只用于这些短住舱，不覆盖原居民身份。
- 房门用F开关，需靠近并朝向门。门板实际滑入侧墙，保留实体碰撞；门口有人时拒绝关闭，关门过程中有人进入则重新打开。两侧都能操作。
- 两条3.2m宽银灰步道接原咖啡／档案侧路，共约389.76㎡；末端沿既有地面继续到原门洞，不封堵下层入口。
- 床、卫浴、衣柜和备餐设备为静态陈设，本轮没有新增睡眠、洗澡、烹饪、住宿分配或持久房门状态。当前可操作的是座位和房门。

## 真实参考与资产选择

实际用内置浏览器查看了 [Norm Architects / TRUNK(HOTEL) YOYOGI PARK](https://normcph.com/project/trunkhotel-yoyogi-park/) 及其 [卧室照片23](https://normcph.com/wp-content/uploads/2024/01/Norm-Architects_TRUNK-HOTEL_2023_JBP_23-1.jpg)：采用低床、连续床头板、床边悬浮柜和柔和织物的空间关系，改为本项目银白与浅灰米色材料。照片仅作为观察参考，没有作为游戏纹理或生成输入。

检查项目现有家具后，也实际查看了 [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit) 的供应商预览与CC0说明；其块面和卡通比例与当前软椅风格不统一，本轮未导入。新增精确围护、床与洗漱陈设使用Blender制作，保留 `.blend`、FBX和脚本。已有家具、玻璃、金属及石材直接复用；织物仅派生新舱所需的两份材料。

首次画面自检发现床与洁具圆角折面明显，已增加加权法线、降低床体，并调整新舱的18盏烘焙灯。最终重新导入、烘焙及验证；没有改变旧建筑光源参数。
