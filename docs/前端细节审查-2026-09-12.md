# 桌面端前端细节审查

此文保留早期暖色方案的审查记录。后续已按确认方案重构为赛博朋克工作台，当前实现与验收见 [多模型工作台-实现与验收](多模型工作台-实现与验收.md)。

按个人使用的桌面工作台打磨，保留暖色主题。检查范围为大厅、录制台、直播/回放、总榜、档案和产物库。

| 发现的问题 | 已完成的修改 |
| --- | --- |
| 72 个蛐蛐罐纵向平铺，榜单与近期产物被压在页面末尾 | 大厅采用桌面主栏与侧栏，增加关键词搜索、计数、空态和清除操作 |
| 输入框缺少标签，重复设置挤占阅读空间 | 录制和开赛设置按需展开，补齐阵容、节拍、单位和多选说明；原生校验阻止空选提交 |
| 暗色输入框、标签、按钮状态不统一 | 统一控件底色、文字、悬停与键盘焦点，补齐主题和录制切换状态 |
| 总榜的段位、数字、成就被挤成多行 | 扩大桌面表格空间，保持数字与段位完整，长模型 ID 提供省略与悬停全文；模型名可进入档案 |
| 老实-k2 档案的 187 个维度标签严重重叠 | 多维度改为可滚动的分数条，所有维度保留；3—8 个维度继续使用雷达图 |
| 近期产物按文件名排序，文件库过长且缺少查找 | 大厅按文件修改时间选取近期产物；产物库增加分组折叠和搜索，实际文件可打开或下载 |
| 直播表头与显示的数据不对应，回放缺少标题及完整阵容 | 分阶段更新表头和状态；回放补发开场元数据，避免出现直播标题和逐个补齐阵容的情况 |
| 操作反馈不完整 | 表单提交反馈、返回页面恢复、复制失败提示、连接中断与恢复提示、进度语义 |

验证：

- `npm test`：236 项通过，0 失败，包含 TypeScript 检查。
- 回放开场信息回归断言先复现失败，修复后通过；再次运行全部测试通过。
- 内置浏览器实际查看明暗主题、桌面布局、表格与档案图表。
- 实际操作搜索与清除、空结果、录制空选校验、阵容记忆、模拟比赛、录制模式切换、终局与回放。
- 模拟比赛使用临时战绩副本；回放前后副本的 `career.json` SHA-256 相同。
- CSS 最后保留了已有服务所需的基础主题样式；未重新生成历史产物。

运行状态：

- 新版预览：`http://localhost:8182/`，使用测试数据副本，不能视为正式战绩库。

- 正式入口的页面模板需要手动重启原服务后生效。在 `arena` 目录使用原启动命令：`node src/cli.ts serve --port 8181`。
