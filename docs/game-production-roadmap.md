# AI 斗兽场 3D 完整游戏制作

用户目标：持续优化，把现有原型做成成熟、完整的 Unity Windows 游戏。核心仍是观看真实模型做题，以及它们的 3D 形象同步交手；用户可以自主更换形象、音乐与界面。按效果和整合成本优先复用成熟资源，Blender／Meshy／ComfyUI 用于适配或明确缺口，不把每轮使用某种工具当作完成目标。

2026-09-29 更新：后续所有迭代已获按需下载、安装组件的授权，优先免费或已有授权的合适资源，不安排新增付费组件采购；免费资产不合适时优先 Meshy 生成、Blender 整理补齐。当前空间站施工以 [v012：免费组件优先的视觉样板](黑洞空间站升级方案/施工方案_v012.md)为准：先完成咖啡厅—短廊—黑洞观景台，再扩展世界和深化交互。以下工具产出与完整产品标准保留为历史证据及后续目标。

## 完成标准

- [x] Meshy：生成并采用经过视觉验收的正式资产；记录任务 ID、成本、来源和导出文件。
- [x] Blender：制作/整理角色和赛场，提供源文件、分肢或骨骼动作、优化后的可运行资源；导入 Unity 后复验。
- [x] ComfyUI：实际生成并采用游戏视觉/音频或视频素材，保存可复现工作流和输出证据；不更换成网上代跑工作流。
- [ ] 美术与演出：统一的电子蛐蛐竞技场风格，角色可辨识；入场、思考、蓄力、攻击、防御、受击、失败与胜利表达完整；打击特效和镜头不遮挡做题信息。
- [ ] 完整流程：主菜单、首次引导、模型与题库配置、实时比赛、暂停/中止、结算、历史回放、再赛、自定义、退出闭环，关键错误可恢复。
- [ ] 比赛可信：现有后端仍是答案、评分、裁判、战绩与工程验收的唯一来源；离线模拟明显标注；断线、迟到事件、重试、失败不会伪造成绩。
- [ ] 高度自定义：角色/配色/模型/头像、音乐与音效、背景/字号/透明度/布局、动作强度，预览与可靠持久化；预设与素材可一起迁移，导入失败可恢复。
- [ ] 声音：原创可循环配乐和区别明确的打击/交互/结算音效，可独立调音和静音。
- [ ] 品质：Windows Player 中检验 2/4/8 人、常见窗口尺寸、长题/长答案、真实后端联通、断连恢复、素材导入、连续开赛和回放；检查帧率、内存与控制台异常。
- [ ] 交付：完整可运行 Windows 目录、便捷启动器、源码、资产源文件、许可/制作来源、操作说明、验证记录；不能以一次 mock 演示代替完整验收。

## 制作顺序

1. 当前视觉样板：审查已有资产与成熟组件，完成真实参考、最小试装和 Unity 适配；不足部分再自制，比较同机位画面并验证实际漫游、性能和涉及的行为。
2. 产品闭环：完善菜单、开赛配置、过程可读性、结算与回放、自定义工作室和便携素材预设。
3. 内容与验证：加入实际生成素材，完成模型服务与游戏边界验证、性能检查和独立构建。

## 当前证据与待办

2026-09-18 起点：已有 Unity 原型和一份经实际 EXE mock 比赛验证的 Windows Build；上一版报告在 `docs/validation/unity-3d`，仅证明原型范围。以上完整游戏标准尚未达成。

当前工具状态：Unity Editor 6000.3.24f1、Blender MCP、本地 ComfyUI 和 Meshy OAuth 均已实际连通并产出素材。玉甲拳手经 Meshy 生成、重拓扑、绑定及动作生成，再由 Blender 整理导出六个动作；Unity 使用 22,975 三角形、24 骨骼的模型。Blender 场馆为 8 个网格、97,560 三角形。本地 ComfyUI 在 RTX 5090 上生成主菜单图与《青铜回路》配乐，实际工作流及源文件在 `production`。

Meshy 使用现有积分共 61，余额 3365（本轮核对）；初始 30 的估算只含角色生成，后续重拓扑、绑定和动作已另行记账。用户允许按制作需要使用现有积分，余额不足告知，不自动购买。原始任务记录保留，未因下载中断重新付费生成。

Windows 正式资产版本输出到 `QuQuArena3D/BuildProduction`，启动器优先选择该版本。`docs/validation/game-production-v01` 记录独立 EXE 的 2/4/8 人短测、66 帧后端模拟比赛、连续换装和真实免费模型联通结果。Ling 成功回答；Liquid/Gemma 免费节点返回 429 并按原引擎规则退赛，不作为两模型成功对战的证据。

完整游戏仍需推进首次引导、结算交互、持续游玩流程、断线及暂停/回放验证、更多角色与音效细化，以及长时间性能和不同硬件测试。以上未勾选条目不因已有一份可运行 EXE 而视为完成。

每轮继续更新实际证据。一个服务暂不可用不缩减目标，先推进独立工作；完成必须逐项确认以上标准。
