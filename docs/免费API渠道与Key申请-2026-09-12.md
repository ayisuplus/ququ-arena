# 免费 API 渠道与 Key 申请

核查日期：2026-09-12。用途是本机个人竞技场的文本推理、流式对战与模型比较。以下为官方政策与入口核验，尚未注册新账号、领取权益或进行这些渠道的真实推理测试；实际配额以对应账号控制台为准。

## 优先申请

建议先申请智谱、Groq、硅基流动三家的凭证，分别补充 GLM、GPT-OSS / Qwen 和国内免费开源模型。这里的“直连”指直接向服务提供方请求；Groq、硅基流动属于推理服务商，并非它们所托管模型的原厂。

| 渠道 | 免费范围与额度 | 获取凭证 | 适合本项目的用途 |
| --- | --- | --- | --- |
| 智谱 BigModel，模型原厂 | GLM-4.7-Flash 和 GLM-4.6V-Flash 输入、输出、缓存均为免费。公开价格不等于不限并发；具体调用限制需要登录查看。[定价](https://bigmodel.cn/pricing) | 注册登录 → [API Keys](https://bigmodel.cn/usercenter/proj-mgmt/apikeys) → 新建 Key。[官方步骤](https://docs.bigmodel.cn/cn/guide/start/quick-start) | 优先使用 GLM-4.7-Flash 作为中文、推理参赛模型。该模型支持流式公开推理内容。 |
| Groq，推理服务商 | 当前 GPT-OSS 120B / 20B、Qwen 3.8 27B 免费档的公开上限均为 30 请求/分钟、1,000 请求/天、8,000 Token/分钟、200,000 Token/天；组织共享规则与个别账户例外见[限额说明](https://console.groq.com/docs/rate-limits)。 | 注册登录 → [API Keys](https://console.groq.com/keys) → Create API Key。保持 Free 档；升级 Developer 才需添加支付方式，见[账户说明](https://console.groq.com/docs/billing-faqs)。 | 请求上限高于当前 OpenRouter 50 次/天，但长题可能先触及 Token 限额。适合短题与速度比较。 |

## 额度较大的限时试用

**阿里云百炼：**华北 2（北京）新人额度通常为每模型 100 万 Token，90 天有效，不同模型与快照版本各有独立额度。它适合集中跑一批测评，但不属于每天续送。已实名认证账号应在调用前开启对应模型的“免费额度用完即停”，避免自动进入按量付费。注册和开通以控制台提示为准。[官方额度规则](https://help.aliyun.com/zh/model-studio/new-free-quota)

Key 从[百炼 API Key 页面指引](https://help.aliyun.com/zh/model-studio/get-api-key)创建，选择有免费额度的北京地域，使用通用 API Key。Base URL 与地域、业务空间匹配，从当前控制台调用示例复制。[首次调用说明](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)

**NVIDIA NIM：**有官方托管模型的试用 credits；在 [API Catalog](https://build.nvidia.com/) 注册后，从模型示例里的 Get API Key / Generate Key 获取。官方项目提到新账号最多可领 5,000 credits，但不是所有账号必得，也未证实每天补充，实际数量与限制需看账号。因此作为补充试用渠道，暂不作为持续免费主力。[NVIDIA 官方项目说明](https://github.com/NVIDIA/metropolis-nim-workflows)、[额度耗尽说明](https://docs.nvidia.com/rag/2.6.0/troubleshooting.html)

## 已核实的变化与限制

- **Cerebras：**搜索摘要仍显示旧免费档，但当前官方文档明确没有持续免费档。新账号添加验证过的支付方式后赠送 5 美元，30 天到期；未添加支付方式不能使用 API。当前试用档为 5 请求/分钟、100 万 Token/天，仍受赠款总额约束。[当前官方规则](https://inference-docs.cerebras.ai/support/rate-limits)
- **魔搭 ModelScope：**内置浏览器读取的当前文档已按魔粒兑换：轻量、主流、旗舰模型分别 0.5、1、2 魔粒/次；并发随负载调整，以单并发使用为目标。旧文章“每天 2,000 次”的数字不用于当前推荐。需绑定实名阿里云账号；凭证为 [Access Token](https://modelscope.cn/my/myaccesstoken)。[当前使用限制](https://www.modelscope.cn/docs/model-service/API-Inference/limits)、[接入与身份要求](https://www.modelscope.cn/docs/model-service/API-Inference/intro)
- **Google Gemini：**确有部分模型的免费 API 档，但官方可用地区列表未列中国大陆，准确配额以项目的 AI Studio 限额为准，不能承诺本机直接可用。满足服务地区要求时，可在 [AI Studio](https://aistudio.google.com/apikey) 创建 Key。[定价](https://ai.google.dev/gemini-api/docs/pricing)、[地区](https://ai.google.dev/gemini-api/docs/available-regions)、[限额](https://ai.google.dev/gemini-api/docs/rate-limits)

接口依据：[智谱](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash)、[Groq](https://console.groq.com/docs/openai)、[硅基流动](https://api-docs.siliconflow.cn/docs/userguide/quickstart)、[星火](https://www.xfyun.cn/doc/spark/HTTP调用文档.html)、[Mistral](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key)、[魔搭](https://www.modelscope.cn/docs/model-service/API-Inference/intro)。

建议把同一模型在不同渠道的参赛项标清“模型 + 服务商”，因为速度和缓存表现也受服务商影响。后续接入时保留各家独立的额度状态与限流队列；只有实际成功、用量字段和中止行为均验证后才标记可用。
