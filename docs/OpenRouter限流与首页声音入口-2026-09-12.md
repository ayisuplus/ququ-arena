# OpenRouter 限流与首页声音入口

2026-09-12，已在 8182 预览完成修复与验证。

## 实际原因

本次失败战绩与内置浏览器的真实接口检测均返回 `free-models-per-day`：每日免费额度剩余 **0 / 50 次**，服务端重置时间为 **2026-09-13 08:00:00（北京时间）**。这是账号共享的免费请求额度，切换免费模型不会恢复。免费目录仍有 19 个模型，但当前账号已无法调用。具体状态见[脱敏诊断](validation/router-recovery/diagnostic.json)。

首页增加“检测免费接口”，使用已保存的 Key，最多发送一次短免费请求。已知额度耗尽时直接返回当前状态，不额外请求。没有自动换用其他账号、接口或付费模型。额度规则参考 [OpenRouter 官方说明](https://openrouter.ai/docs/api_reference/limits)。

## 修复行为

- 解析 HTTP 响应头、错误元数据及 HTTP 200 流中的错误，区分每日额度、分钟限流和上游模型拥堵。
- 每日额度耗尽不再重试；临时限流按 `Retry-After` 或重置时间等待，分钟限流缺少提示时默认等待 60 秒，等待可以取消。
- 首页展示剩余额度和真实重置时间，禁用不可用的免费阵容。纯免费阵容遇到每日额度耗尽时中止剩余请求，保存已有结果与中止状态。
- 各 Key 的状态隔离。额度状态保存在服务内存中；服务重启或冷却结束后恢复“尚未检测”，下一次调用或检测重新确认，不宣称额度已恢复。
- 首页右上方常驻“开启声音”和“声音设置”。可选择六首配乐、调整音量、试听八秒配乐及开赛/胜利音效；首页不持续自动播放，试听到时停止。
