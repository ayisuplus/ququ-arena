## 验证结果

- 9/9 个模型成功流式返回「收到」，流式累积文本与最终答案一致。
- 9/9 返回 Token 用量；其中 7 个返回公开推理内容，另 2 个该次没有提供，不推测隐藏思考。
- 智谱返回缓存命中 Token；B.AI 的 MiMo-V2.5 本次返回 192 个缓存 Token / 260 个输入 Token。其它未报告缓存的接口仍显示「未提供」，不按 0 伪造。
- 短探测最多 512 个输出 Token；探测耗时只能说明本次连通情况，不作为模型能力排名。
- 公开的 `/api/models` 已检查：9 项可选，响应不含保存的任何密钥。
- 逐模型探测数据：[probes-2026-09-13.json](validation/provider-connections/probes-2026-09-13.json)。
- 内置浏览器实际操作「勾选四渠道 → 综合竞技题库 → 1 题 → 开始对战」，四路均答对 `logic-01`，正常显示比赛结算、综合分、耗时与 Token；Groq GPT-OSS-120B 获得本次单题综合分第一。真实比赛数据：[battle-2026-09-13.json](validation/provider-connections/battle-2026-09-13.json)。

## 本机配置与启动

- 密钥保存在 `arena/.local/model-settings.json`，该目录已被 Git 忽略；没有把密钥写入源码、浏览器存储或公开报告。
- 8182 预览恢复运行，战绩使用 `arena/.local/preview-results` 中的独立副本。
- 当前本机网络下，B.AI 直接连接超时、Groq 直接返回 403；使用用户已有的 HTTP/HTTPS 代理后恢复。无密钥 TLS 检查确认代理使用 CONNECT 隧道，官方证书和主机名通过 Node 内置根证书校验。
- 预览启动启用了 Node 的 `--use-env-proxy`。需要重启时，在 `arena` 目录运行 `node --use-env-proxy .local/preview-server.mjs`，先确认 8182 没有正在运行的预览进程。
