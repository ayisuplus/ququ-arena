# AI斗兽场 方法学说明

> 给审阅者的统计与评测方法自述：每个数字怎么算的、为什么这么算、边界在哪。
> 原则：**戏剧性来自真实数据，统计只放大不编造**。

## 1. 评分

| 裁判 | 语义 | 可复现性 |
|---|---|---|
| `exact` | 标准化（去空白/首尾标点/全角转半角）后精确匹配 | 完全可复现 |
| `contains` / `regex` | 关键词覆盖 / 正则命中 | 完全可复现 |
| `llm` | 裁判模型按 rubric 打 0..scale，归一化 | 同裁判同题同答案可复现（采样参数由裁判模型决定） |

多裁判（`--judge a,b[,c]`）：逐裁判给分入战绩（`votes`），总分取均值，分歧度（max−min）逐题公开。裁判间信度以逐对 Pearson r 的均值披露（`judgeAgreement`），n<3 对观测不出数——小样本相关系数是噪声放大器。

弃权（调用失败且重试耗尽）与答错严格分离：弃权不进任何分数与 Elo 计算。

## 2. 排行榜统计

- **均分 CI**：以题为重采样单元的 bootstrap 95% CI（B=2000，固定种子 42——战报可复现的前提）。逐条记录重采样会破坏"同题对比"的相关结构，故按题。
- **冠亚军分差**：paired bootstrap（按 taskId 内连接对齐，一方弃权题双方同剔）。CI 含 0 ⇒ 解说判"神仙打架"、名次不足为凭；触发 `--playoff` 加赛。
- **Elo**：单场逐题 pairwise（同题高分者胜，平 0.5，K=24）；生涯 Elo = 1500 + Σ每场 delta（每场 stakes 一致，新蛐蛐不被历史压死；赛季跨季首战向 1500 收 25%）。
- **生涯 Elo 不确定区间**：elo ± 1.96·sd(δ)·√n（随机游走语义；n<2 不出数）。
- **Glicko-2**：Glickman 规范实现（τ=0.5，σ₀=0.06，量纲常数 173.7178，Illinois 迭代求 σ'）。一场 battle = 一个评分期，榜内两两对决（avg 高者胜、平 0.5）。披露 μ±2RD。与 Elo 的分工：Elo 驱动段位叙事，Glicko 是研究向的诚实评级。
- **同卷对比（diff）**：指纹不同硬拒比；只比共同题（题量不同不混口径）；逐模型配对 bootstrap CI 判定显著/噪声 + 配对效应量 Cohen's dz=mean(Δ)/sd(Δ) 回答"多大"（恒定差距 sd=0 时如实标"—"，不编造无穷大）。

## 3. 题目质量

- **难度**：跨历史场次均分（`analyze`）。
- **区分度**：point-biserial 相关——题分 ×（同场同蛐蛐其余题均分）的 Pearson r；n<8 不出 r，零方差显式标注（全对/全错题的区分度在数学上不可定义）。
- **污染自检**（`contaminate`）：completion-based membership inference——题面前 60% 让模型凭记忆逐字续写，与真实后缀的字符 bigram Jaccard ≥0.8 判疑似污染；罐级污染率 >20% 亮红灯。**边界**：只覆盖逐字记忆型污染，改写/同义题测不出。
- **题库指纹**：sha256（规范化 judge 规则 + 全部题目，题序/元信息不变则指纹不变）。战绩与战报披露指纹；`diff` 指纹不同硬拒比。

## 4. 可复现性

- mock 蛐蛐全部确定性：答题种子 = hash(蛐蛐 id + 题目 id)，mock 裁判扰动 = hash(裁判 id + 题目 id)。同罐同阵容重跑逐题一致（`diff` 会如实告诉你"确定性复现"）。
- 战绩 JSON 含可复现清单（`meta`：题库指纹/裁判列表/工具版本）；`finishedMs` 记录每条交战完成时刻（回放真实节奏的数据源）。
- 每罐带 BIG-bench 式 canary 字符串，供下游从训练语料过滤。

## 5. 已知局限（明示）

1. LLM 裁判的采样温度由裁判模型决定，未固定——多裁判均值缓解但不消除。
2. Elo 的 K=24 未经大规模校准；Glicko 的 τ=0.5 是文献常规默认值。
3. 污染自检不覆盖改写型污染；检索级方案（嵌入/联网撞库）未实现。
4. 回放按 `finishedMs` 时间轴；v0.8 前的旧战绩无时间轴，退化为存储序等速。

## 6. IRT Rasch 1PL（v1.5 起）

`analyze --irt` 把题目质量诊断升级为正式测量模型：P(蛐蛐 m 答对题 i) = σ(θ_m − b_i)。
- 交替 Newton 联合估计蛐蛐能力 θ 与题目难度 b（同一 logit 量纲，可比）；
- b 均值 0 定标（θ 平移等价，惯例）；
- L2 正则（λ=0.5）+ ±4 logit 截断处理分离问题（全对/全错在 MLE 下参数发散）；
- 连续得分在 score≥0.5 处二值化——部分给分信息损失，换取标准模型。
