此图为AI概念目标，建筑外观、数量和细节不代表当前实装；圆形看台的已建形态以上方原生画面为准。主盘候选直径508m，两条固定带各8m，详细半径及部件归属沿用[v004总平面说明](../layout-review-v004/README.md)。

跨环路线为：**本环街巷 → 边缘步道 → 固定换乘带 → 目标环边缘步道 → 目标街巷**。街巷错位时沿固定带走一段，无须等待对齐；接驳交通仅作补充。圆形看台的楼梯、坡道与环廊全部归R1，不跨越固定换乘带。

零散屋檐、柱墙、门、座位、灯具和家具归入对应建筑群，共同前庭负责连接入口；不能把附属物留在环间接缝。未知用途件保留待审，旧对象及历史版本保留。
