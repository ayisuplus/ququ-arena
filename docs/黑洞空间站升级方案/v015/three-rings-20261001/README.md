## 1. 每环放什么

| 环 | 内容与既有资产 | 空间样子 | 初步旋转意向 |
| --- | --- | --- | --- |
| 内环：赛事核心 | 中央赛场、环形看台、赛事大厅、实时题目与结果展示；保留比赛呈现、选手入口与升降功能 | 最紧凑。朝中央开敞，外侧设连续观赛环廊；大厅和看台形成完整弧段，保留几处向中心的清楚视线 | 极慢顺时针；比赛中的舞台、看台与出入口必须有明确所属运动参考系，暂不决定全部共转 |
| 中环：公共生活 | 咖啡厅、05阅览会客楼、研究馆、06研修讨论楼、08阅读活动楼、10共享工作楼 | 最有街道感。分为“咖啡会客”“科研工作”“阅读活动”三组，每组有共同前庭；宽阔环街串联，建筑之间留穿行街巷 | 慢速逆时针；建筑、家具、门、街巷随环整体移动 |
| 外环：居住与生态 | 6间原居民住处、11/12两栋短住舱的8套房、玻璃生态园及其原照料舱和6株作物、安静观景步道 | 最安静、建筑更低。常住组与短住组分开，生态园集中为完整玻璃建筑，外缘保留连续观景面；公共路从住宅组外侧经过 | 更慢顺时针；景观和住处随环，站在窗前能感到远景缓慢改变 |
| 固定抵达附属部分 | 原抵达厅、登船厅/船体、货运操作、07访客会客与09候舱阅览功能 | 在外环外侧形成紧凑入口建筑组，接固定抵达前庭；固定部分与旋转外环的交界使用同一套步行接缝原则 | 固定；抵达前庭可保持明确的站体方位 |

07、09作为固定抵达组的候舱与访客空间，可继续复用现有房间；它们不作为第四个主环。这里是功能归属建议，不要求把每栋旧楼的外壳原封不动摆入新平面，也不新增玩法。既有室内模块、座位、门和稳定身份先保留，再讨论建筑合并及外形。

原住处“保留”在此解释为保留房间内容、居民身份与存档关系，**位置建议迁入外环**；这是本稿尚待用户讨论的安排，不是已授权执行的迁移。若希望住处更接近日常公共空间，也可放在中环外缘，但会减少动静分区的清晰度。

## 2. 环内如何走

每个环都有两类路：

1. **沿圆周的连续环廊**：串起本环所有组团，也是观看另一环运动的位置。
2. **随环转动的横向街巷**：穿过建筑组之间的空隙，连接该环内、外两侧边缘步道。通道属于所在环，不能在固定世界方位上从旋转建筑中切出直线通道。

建筑入口面向本环街道和组团前庭；住宅有自己的内院入口，公共穿行路线不经过房间。门口、广告牌、灯具和散件也归所属建筑包，避免形成一边走一边遇到漂移小物件的画面。

各环接近换乘带的边缘必须连续、平齐且留出空带。柱子、楼梯起点、门扇、花床、家具和固定护栏不能伸入相对运动的交界。屋顶可以高低错落，**主要步行交界保持同高**；局部观景台的楼梯留在各自环内。

## 3. 环与环之间如何通过

### 主方案：旋转步道 → 固定换乘带 → 另一环旋转步道

内环与中环、中环与外环之间各设一条完整的固定窄环廊，暂以6–8m净宽作为原型讨论值，最终按人流、尺度与玩家体验调整。它们是交通设施，视觉上表现为窄的连接带，主要建筑轮廓仍读作三个环。

完整的换乘带在任何角度都有可承托的地面，因此相邻两环街巷不需要面对面。人从本环街巷到达边缘、跨过平齐接缝，沿固定带走一小段，再进入目标环当时所在的街巷。全程保留第一人称步行，不等班次、不等整圈转回、不以瞬移代替跨越。

交界采用低矮、可辨认的边缘收口与滑接盖板概念，主路连续铺实，不把环间做成需要跳跃的大裂谷。旋转环侧的开口与固定带之间应始终有连续开放的步行界面，不能再用一组只在某个角度对齐的固定门或窄桥代替。

**这是科幻游戏的空间与交互方案，尚未验证旋转接缝的工程或游戏可用性。** 固定带解决的是“无需等入口对齐”；它本身不消除移动地面交界、角色带随、碰撞和相机舒适性问题。必须在候选原型中验证跨缝、斜走、停留与返回，不能只把地板画成相连就宣布通过。

旋转速度按交界处的线速度检查，不能只看每秒转几度。相同角速度下，越大的环边缘移动越快。原型先以接缝两侧相对固定带约0.05–0.10m/s作为探索区间，不是已验证的安全或舒适阈值。以半径100m为例，该区间对应一圈约105–209分钟；任何加速演示都需要标明倍率，不把演示转速当成实机参数。

### 固定入口如何接外环

抵达厅与船坞先作为固定设施。固定前庭贴着外环连续边缘步道设置宽阔接入段；旋转建筑退到外环内部，避免扫过固定前庭。到站后可直接步行进入外环，再经换乘带进入中环、内环。跨界原理与前述相同，也需要原型验证。

### 接驳交通的角色

步行连通先完成。若实测全站步行距离偏长，再考虑沿环的小型接驳车或观景交通；当前不把新载具系统列为必须施工项，更不让住处到咖啡厅、生态园或赛场的路线依赖候车。

## 4. 三条日常路线

- **观赛**：固定抵达厅 → 外环入口步道 → 换乘带B → 中环咖啡/会客 → 换乘带A → 内环大厅与看台。
- **居民日常**：外环住处 → 住宅组公共环廊 → 换乘带B → 中环咖啡厅/研究馆 → 原路返回；不用穿过赛场或别人房间。
- **安静漫游**：外环住处或短住舱 → 玻璃生态园 → 外缘观景步道 → 短住会客；大部分过程留在同一环，减少无意义换环。

具体进入哪个街巷由当时环的位置决定。长期导览用“内环·赛场”“中环·咖啡街”“外环·生态园”等稳定地点名；不把旋转中的咖啡厅永久称作“东区”。固定抵达厅仍可拥有稳定的北向方位。导览需给出目的地相对当前环的位置，而不是沿用旧世界坐标箭头。

## 5. 零件整理与迁移原则

每个对象先归入：内环、中环、外环、固定换乘设施、固定抵达设施或待审历史对象之一。同一栋建筑的屋面、柱墙、玻璃、家具、灯具和交互归同一运动包；跨环构件不能一端绑定内环、一端绑定中环。

旧方形上层步道、四角观景节点、连廊和屋面按用途分别重接，不能把整个旧框架藏进圆壳。仍有作用的上下层路线必须先设计替代路径，再讨论停用。旧v014场景、旧路线、旧存档、模型源文件与GUID保留。

实施时，居民路线、座位锚点、门、导航目标和保存的位置需要记录所在环与环内关系；房间/居民/交互稳定ID和后端赛事权威保持。当前存档方案并未证明支持旋转世界，不能通过整体旋转根节点就默认迁移完成。

## 7. 先验证什么

下一步先做一个独立候选原型：两个相反方向缓慢运动的环形步道，中间一条固定换乘带，以及环内横向街巷。验证人能够随时走过去、站住、折返；随环站立与相机视线稳定；接缝无卡住、跌落或错误带随；重载存档不会出现在移动墙体内。通过后再接第三环和现有建筑。
