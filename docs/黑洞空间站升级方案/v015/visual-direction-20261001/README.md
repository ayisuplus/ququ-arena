## 鸟瞰：三环与组团

![三环鸟瞰效果图v002](birdseye-v002.png)

中心为圆形赛事组团；中环组织咖啡会客、科研工作、阅读活动三群建筑；外环组织常住、短住与玻璃生态园。上方抵达组为固定附属设施；两条细环表达固定换乘带。中央方形外框撤出新方向，主要地面连续，植物集中在右侧玻璃生态园内。

图像检查：三个主要建筑层次可辨、无方形核心、中央井可见、抵达组在外缘、玻璃园集中、未见明显室外树木或暖黄泛光。图中细环带偏暗，**施工不能照图挖成沟槽或加拦截护栏**；通行地面以建设方案的平齐连续要求为准。部分地面被生成成玻璃采光窗，不是新增贯通井，也不是本版必做构件。

## 人视：跨环连续步行

![固定换乘带步行效果图v002](pedestrian-v002.png)

浅蓝侧为中环边缘，中央白色带为固定步道，浅绿侧为外环边缘。两个平齐银色接缝将三段承托地面分开；接缝没有门、围栏、楼梯或大裂隙。家具退在建筑内部，植物位于玻璃罩中。站在固定带上可以沿圆周走到另一环当时所在的街巷，不要求两侧门对齐。

图像检查：平齐地面、两条接缝、无等待接驳设施、冷白窗光及罩内绿化均已表达。地面仍偏光滑，后续材质需在Unity检查粗糙度、高光与运动中的舒适性；图中住宅采用三层概念外壳，与鸟瞰低矮模块不是同一套精确模型。本图是局部通行气氛研究，不冻结楼层、房间数量、罩体尺寸或相机坐标。两图不应直接用来反推一套米制模型。
