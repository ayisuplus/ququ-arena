## 每个环放什么

| 区域 | 内容及建筑群 | 边界与旋转 |
| --- | --- | --- |
| R1 内环 | 圆形赛事核心：赛场、看台、大厅、选手入口和升降机构 | 全部围绕保留的中央贯通井；从上方看顺时针慢转 |
| R2 中环 | 咖啡＋阅览会客、研究＋共享工作、研修＋阅读活动，共三组 | 每组一个共同前庭，组间留横向街巷；逆时针慢转 |
| R3 外环 | 原六户常住、八套短住、完整玻璃生态园及观景步道 | 常住、短住、生态分组，公共路不穿住宅；顺时针慢转 |
| F-A / F-B | 内中环、中外环之间的两条连续换乘步道 | 固定、平齐、铺实，接缝附近不放柱子、家具或门 |
| F-P | 抵达、候舱、访客、货运与船坞 | 外缘固定组，直接接外环；不是第四主环 |

## 环之间怎样走

**本环街巷 → 本环边缘步道 → 固定换乘带 → 目标环边缘步道 → 目标街巷。** 街巷错位时沿固定带走一段即可，无须等入口对齐。两条固定带连续成环，主步行地面同高，中央赛场井是唯一大型贯通开口。

![随时步行的人视概念，沿用v003](../layout-review-v003/pedestrian-v003.png)

人视图沿用v003：左侧浅蓝为中环边缘，中间瓷白为固定带，右侧浅绿为外环边缘；两条银线表示平齐接缝。建筑、横巷、屋檐及附属物随本环运动，固定径向桥不得穿越运动建筑。接驳只作补充，主路线不依赖候车。
