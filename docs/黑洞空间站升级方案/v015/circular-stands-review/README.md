## 看台形态

平面采用正圆，围绕原中央贯通井布置同心圆梯级。台面、座位排、后方环廊和屋檐共用圆心；透视图中的椭圆是视角效果，不将平面改为椭圆跑道。借鉴罗马竞技场的环绕观赛、层层升高和放射通道组织，建筑材料延续瓷白、蓝色座面、透明玻璃与银色收边。

沿用已有候选的九级台面、八个弧形座席区、四条放射楼梯和四条外侧坡道。人流从R1外侧环街进入大厅或外侧坡道，经后方连续环廊分流，再沿放射楼梯到达座位排；上层保留无需走楼梯即可到达的停留位置。看台及其入口、护栏、照明和屋檐全部归R1，随内环共转。

| 归属 | 内容 | 俯视运动方向 |
| --- | --- | --- |
| R1内环 | 圆形赛场、梯级看台、赛事大厅与相关机构 | 极慢顺时针 |
| R2中环 | 咖啡会客、科研工作、阅读活动三组公共建筑 | 极慢逆时针 |
