## 三个环里放什么

| 部分 | 内容 | 如何收紧 |
| --- | --- | --- |
| 内环 R1 | 赛事大厅、赛场、看台、选手入口与升降机构 | 围绕保留的中央贯通井形成圆形赛事核心，撤出旧方形核心定位 |
| 中环 R2 | 咖啡会客、科研工作、阅读活动三组公共建筑 | 每组一个共同前庭；组间留横向街巷；入口、屋檐、家具和灯具归所属建筑包 |
| 外环 R3 | 六户常住、八套短住、完整玻璃生态园与观景步道 | 常住、短住、生态园各自成群；公共路不穿住宅；植物全部罩内集中 |
| 固定抵达组 F-P | 抵达、候舱、访客、货运、登船与船坞 | 贴在外缘，前庭直接接外环步道；不构成第四主环 |

从上方看：R1顺时针、R2逆时针、R3顺时针缓慢转动。功能名称不随方位改变。效果图的左、右、前、后只表达一个展示相位。

![更新鸟瞰概念效果图](birdseye-v003.png)

鸟瞰更新重点：中央圆形核心、三组中环公共建筑、分开的居住组与玻璃生态园；两条换乘带改为铺实的浅色地面，清理额外地面玻璃窗和罩外植物。宽阔前庭与连续步道用于组织现有内容，不增加人口、房间或玩法。

## 环之间如何走

**本环街巷 → 本环连续边缘步道 → 平齐接缝 → 固定换乘带 → 平齐接缝 → 目标环边缘步道 → 目标街巷。**

固定带绕圆周连续铺设。两边街巷错位时，先沿固定带走一段，再进入目标环；不等待入口对齐。建筑和街巷随本环转，固定带不转，固定桥不得横穿旋转建筑。家具、柱子、门扇和楼梯都退出接缝及运动扫掠范围。

![更新步行概念效果图](pedestrian-v003.png)

浅蓝侧表示中环边缘，白色中央带表示固定换乘步道，浅绿侧表示外环边缘。地面同高，两条细银色线表达接缝；图中色彩用于读懂归属，不强制全站用同样铺装。日常交通以步行为主，接驳仅作实测距离后的补充。

## 位置与边界如何落实

- 当前技术候选径向边界：中央井半径25m，赛事环至84m，固定带84–92m，中环92–176m，固定带176–184m，外环184–254m；主盘直径508m。图像不能用于量取这些尺寸。
- 每个建筑包记录完整屋檐、台阶、门口、家具与交互包络；按所属环检查全周扫掠。造型再圆，也不能跨占相邻运动环。
- 六间原常住房、八套短住房、座位、居民与交互按原身份映射。未明用途的散件保留在待审清单，不凭外观删除。
- 外缘与井口设置坠落防护，内部换乘带保持开放。赛场升降、运板与井口受控开口是独立施工事项；本图不宣称这些机构已联动通过。

完整建筑群对应表已写入[建设方案第1.1节](../../施工方案_v015.md#11-建筑群边界的具体含义)。
