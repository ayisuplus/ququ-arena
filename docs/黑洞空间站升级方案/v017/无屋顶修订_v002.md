# v017 无屋顶修订

2026-10-03。用户在施工中追加：“把顶棚拆了，太丑了，不要屋顶”。主公园改为开放景观，植物、水岸与天空构成空间，不再用大玻璃拱壳和照料舱顶盖界定公园。

- 范围为当前主公园：拆除玻璃拱顶、上部银色拱架、中央照料舱顶盖、原门上透明顶棚及入口雨棚。四向入口、门的交互对象、照料台、六株作物及其稳定身份保留。
- 景观仍集中原主园地块，沿R3运动。外缘玻璃墙和低边界暂保留，完整主环路与照料捷径保留；植物不会分散到环街和其它地块。
- 原悬吊园艺灯停用，日光样板改为地面支撑灯具。中性柔光与局部暖白的方向不变，玩家相机、曝光和银白吸积盘保持原设置。
- 不再将主园称为密闭温室或已验证的压力舱。原门交互逻辑保留，开放园的环境设定与气压叙事留待整体空间设计统一处理，不追加模拟系统。
- 水池、浅滩和低喷泉仍有实体池底，不穿透连续甲板。P01/P02/P03/W01分工及自然绿量占主导的规则继续适用。
