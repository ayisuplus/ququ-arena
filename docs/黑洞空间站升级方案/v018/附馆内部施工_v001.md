# v018：把三座附馆接成可使用的空间

2026-10-03。沿用已获施工授权的v016四馆方案，继续建设空间站；以保存的v017开放公园场景为本轮基线，独立另存候选。主公园无屋顶、植物集中与中性柔光／局部暖白继续适用。

实际核对：B01的两片曲壳内已有地面与空腔；B02有三个晶体空腔及封闭黑色核心；B04五舱块有实体地板和屋面，但中央核与旧碰撞代理阻断通行。三馆都有空室，不能把透视窗称为可进入室内。

## 施工与验证

1. **入口和内部交通**：B01两室各开一处前窗入口；B02打开现有核心入口，接两侧阅览湾及上部阅览廊；B04打开中央入口，建内部折返楼梯，连接五舱及可到达的露台。只在门洞和核心内部制作派生几何，原网格及旧候选保留。验证真实胶囊的进出、上下楼和门的启闭。
2. **使用空间**：复用现有Meshy软椅、圆桌、窗边长座、书架和书桌。会客馆以围桌交流和安静阅读为主；档案亭以阅读及陈列为主；休憩馆安排窗边停留。新增落座点使用独立稳定ID，不复制居民、房间或赛事对象。验证坐下、旋转随动及起身。
3. **照明和交付**：保留v017全站光环境，以局部柔和暖白补室内。复制玩家完整URP设置拍同机位前后图；验证两种旋转相位、原日常路线及B03，运行Win64构建并记录新增资源和实测结果。技术通过、画面审阅和用户认可分别记录。

实测修订：B02阅览廊位于6.23m层，两组折返楼梯连接；较高的11.90m试排与原晶体内部构件交叠，已否决。上层平台在后方中间转弯处留出净空，左侧开口接座位区。两侧门槛裁清原有地板，台阶仍按原角色踏步范围验证。座位从已实走的路线锚点连续接近，再用正常E输入选择最近座位；独立锚点重置与整馆连续路线分别记录。

本轮不接入新的核心玩法、居民或完整世界存档。公园、B03、旧房间、原档案台及咖啡设施保留原身份与使用关系。B04顶层屋面不因护栏存在就被称作已开放的公共露台。
