## 后续落地顺序

1. 先讨论罩体比例和室内感觉；这一稿把绿化收束为一栋低矮建筑，不额外扩展室外种植。
2. 在独立候选场景搭建银白结构和玻璃罩，验证现有入口、四个座位、作物照料及下层路线；玻璃透明排序和黑洞视野都需实机检查。
3. 植物先选真实优质预览和已有可用资源，缺口再用 Meshy／Blender。树形、叶片材质与密度单独验收；本轮未调用 Meshy、未消耗其积分。
4. 实测路通、碰撞、存档和性能后再纳入正式场景。概念图不等于用户认可或最终视觉验收。
