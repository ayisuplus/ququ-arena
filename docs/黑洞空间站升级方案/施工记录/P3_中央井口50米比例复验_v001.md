# P3 中央井口 50 米比例复验 v001

日期：2026-09-28。状态：已写入独立空间站候选世界，未切换默认发行场馆。

用户明确目标是以[最初空间站总览](../08_概念图/IMG-001_空间站总览_v001.png)为核心的小规模开放世界，且此前指出中心显小。原 72 米外径环台只把 44／20 米旧网格整体放大，中央开口因此仅约 32.73 米。现有俯视和主席位视角中，粗环面弱化了概念图的大井口。概念图有透视，不从像素反推精确米数；本轮以 50 米开口做独立灰盒对照，外径 72 米和整站拓扑不变。

施工脚本从已保存的候选世界复制研究场景，依据原碰撞网格改动 576 个内沿顶点，保存一个新的 Unity 网格资产，渲染与碰撞共用此资产。研究场景通过几何、机械与同机位画面对照后，才把网格引用写回 `BlackHoleStationObservatory.unity`；施工脚本和研究场景保留。外围地板内缘、升降环外沿、左右电梯、平台停靠点、看台、居民与咖啡路径均保持原位。

[原始验证与对比画面](../../validation/station-bore-study-2026-09-28/README.md)显示：50 米井口中心射线贯通，环面仍可踩；固定时间步机械夹具完成普通返航、冠军撤板坠落与复位；独立 Windows 构建成功，原世界、居民、咖啡 Player 回归均退出码 0。新开口约占环台外径 69%，此前约 45%，相同机位下洞口更醒目。

这次只验证灰盒比例和机械路径，未证明正式比赛、美术质感或开放世界完成。下一轮仍要检查所有观众座位视线、井边防护、正式后端赛事、真实游玩速度与持续状态；现有东侧客厅座位被楼板挡住的黑洞视线没有随井口扩大而消失。正式环台可编辑源仍需跟随新比例重制。
