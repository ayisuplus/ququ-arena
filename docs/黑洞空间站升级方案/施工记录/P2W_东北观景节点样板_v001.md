# P2W 东北观景节点样板 v001

日期：2026-09-28。接续[世界连通灰盒](P2W_世界连通灰盒验证_v001.md)与[东侧公共绕行](P2W_东侧公共绕行验证_v001.md)。场景 `BlackHoleStationObservatory.unity` 是新的独立候选，原 `BlackHoleStationLive` 和 `BlackHoleStationWorldConnectivity` 未被覆盖。

## 目的与施工

- 最初 [IMG-001 总览](../08_概念图/IMG-001_空间站总览_v001.png) 的四角圆形玻璃节点属于外方框识别骨架。先在东北角做一处约 24 m 外径的可走样板，占 240 m 核心方框宽度约 10%；其余三角尚未施工。
- 节点接通东侧、北侧上层公共步道。分段外窗、结构肋、浅天窗与工作台复用现有灰盒材质；没有引入第三方图像或模型。现实参考是 [NASA Cupola 内景与工作台](https://www.nasa.gov/image-article/interior-view-from-international-space-station-cupola/) 和 [ESA Cupola 的多窗观测用途](https://www.esa.int/Science_Exploration/Human_and_Robotic_Exploration/International_Space_Station/Cupola)。本项目 24 m 节点为概念图下的游戏设计，不是国际空间站部件复刻。
- 地面控制台读取现有 `ArenaStationLiveMatch.Status`。按 `E` 切换到节点屋顶约 31 m 高的光学镜头，画面包含中央环台与贯通洞口；观测时锁定角色移动并隐藏观战 HUD，退出后恢复。镜头来源在场景中有细杆定位。赛事计分仍由现有服务端负责。
- 初版在地面人眼高度直望中央时，洞口被前方结构遮挡；这是镜头升高的实机依据。光学镜头是可操作设施，不能冒充玩家亲自登上的屋顶平台。

## 验证

| 检查 | 结果 |
| --- | --- |
| 从磁盘重开 | 24 m 地板、23 段外窗、工作台、屋顶镜头引用和中心净空通过。圆柱默认碰撞体曾高出地板并堵住入口，已改为网格碰撞体后重测。 |
| 实际角色碰撞移动 | 东侧步道→节点→北侧步道 62.1 m、250 次 `CharacterController.Move`，逐段检查地面与横向偏差。 |
| 交互 | 远处操作无效；近处开／关后相机、移动、第三人称切换、观战 HUD 与镜头组件恢复；赛事状态显示“等待赛事”。 |
| 世界路线回归 | 在新场景复跑十条 P2W 路线：上层整圈 864 m、下层整圈 680 m、东侧公共绕行 410.2 m、舱室经多层到北接驳区连续 1877.2 m 等均通过。 |
| 画面 | [角部节点](../../validation/station-observatory-2026-09-28/P2W-observatory-corner.png)和[屋顶观测画面](../../validation/station-observatory-2026-09-28/P2W-observatory-optics.png)经 Editor 截图目视核查。中央洞口可见；空间材质、黑洞景观与室内细节仍为灰盒。 |

重建顺序：`production/black-hole-station/create_observatory_candidate.cs` → `build_observatory_node.cs` → `add_observatory_optics.cs`。回归：`verify_observatory_saved.cs`、`verify_observatory_visit.cs`、`walk_p2w_routes.cs`。这些都是 Unity Editor 验证，尚未检查 Windows Player 性能、手柄／实际玩家体验或完整赛事时的此节点画面。

下一轮先比较其他三角与中央环台的真实视线，选择能步行抵达的高位观景路线；再给东侧长廊加入导览和生活目的地。完整小规模开放世界仍需四角、多层活动区与站外内容，不以这一节点代替整张地图。
