# P2W 世界连通灰盒验证 v001

日期：2026-09-28。施工依据：[方案 v008](../施工方案_v008.md)、[连通基线](P2W_世界连通基线_v001.md)、[最初总览图](../08_概念图/IMG-001_空间站总览_v001.png)。本轮是独立候选场景中的空间和控制验证，不是完整开放世界或美术验收。

## 本轮建成

- 保留 `BlackHoleStationLive.unity`，复制为 `BlackHoleStationWorldConnectivity.unity`。从磁盘重开候选场景后，确认新根节点已保存、场景无未保存修改。
- 沿原外方框加 Y=14 m 上层方形观景步道和东西两条公共坡道；在 Y=-12 m 加避开中心井的下层方形观测回廊及东西两条公共下行坡道；从北侧公共入口接出有地板、侧墙和顶棚的灰盒走廊与接驳平台，延伸至 Z=220 m。没有占用选手电梯和移动平台。
- 候选场景启用可见胶囊角色的第三人称步行，`V` 切第一人称；保留 `F8` 自由镜头、`F9` 擂台近景、`R` 返回与观众席入座。原 Live 场景未启用新视角。
- 总览截图仍能辨认外方框、内菱形、中央环及贯通空洞；新增北侧支路是可抵达的灰盒空间，不把它当成最初概念图已经确定的船坞造型。

## 尚未过门槛

- 这是灰盒：接驳区只有货物占位块，尚无舰船、活动、气闸交互和正式压力密封；上／下层也缺观景设施和日常内容。它验证了连续空间网络，尚未形成有探索回报的小型开放世界。
- 2149 m 是绕行上、下层后的行走长度，不是地图直径或内容规模；候选灰盒仍围绕原 240 m 核心，接驳区只向北延伸至 Z=220 m。玩家此前觉得整体小的判断尚未被本轮消除。
- 现有东侧居住压力窗隔断了东侧外环直达北口的路径；已验证路线经南侧和西侧公共环道绕行。不能以穿过私人房间作为公共捷径，下一轮需决定专门的东侧公共绕行或明确导览。
- 这轮没有 Windows Player、正式付费模型、帧率／内存、全部坐席视线和气密性验收；也没有冻结最终地图边界。第三人称胶囊只是碰撞和镜头占位，不是角色美术。
- 原始总览图中的黑洞环境与日常区气氛尚未在本候选场景表现；概念图轮廓核查不等于视觉质量达标。

下一轮按方案 v008：先让三个已开放目的地各有明确景观或交互，再检查公共路径导览、压力分区、第三人称实际游玩感与性能，之后确定小规模开放世界的可玩边界和内容密度。
