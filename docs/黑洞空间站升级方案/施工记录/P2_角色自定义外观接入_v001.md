# P2：角色自定义外观接入 v001

日期：2026-09-27。仅修改独立空间站赛事客户端 `ArenaStationLiveMatch`。角色仍按稳定模型 ID 读取既有 `ArenaPreferences`；标准／Q 版模式、颜色、预设、本地 GLB 和头像图片都沿用原场馆资源与 `ArenaMedia` 加载规则，没有建立第二套外观档案。服务端仍决定比赛结果。

## 施工

- 新场景创建选手时读取既有外观设置。标准模式下本地 GLB 交给原 `ArenaMedia.LoadAvatar`，头像图片交给原 `ArenaMedia.Face`；Q 版沿用 `ArenaFighter.ApplyLook` 的预制体选择。选手清场时显式取消异步导入并释放导入器。
- `duel-start` 事件在外观加载任务完成后才开始双电梯入场，避免角色在途中从基础形象切换为 GLB。已进行中的赛事快照仍先恢复演出状态，再异步补齐自定义外观。
