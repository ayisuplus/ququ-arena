# P2：观战镜头切换 v001

日期：2026-09-27。仅为独立空间站 `BlackHoleStationLive` 的玩家相机增加镜头状态，保留原步行和主席位 `E` 入座／起身。一次性装配脚本为 [attach_station_camera.cs](../../../production/station-camera/attach_station_camera.cs)。镜头不改变 `BattleEngine` 结果、选手位置或平台演出。

## 施工

- F9 在原视角与擂台近景间切换。近景使用 Play 画面对比过的 `(0, 16.5, 16)`、42° 视场，朝向中央比赛高度；F8 复用现有 `ArenaFreeCamera` 的右键转向、WASD／Q E 移动、滚轮调速；R 返回进入镜头前的准确视角。
- 进入近景／自由镜头时暂停步行控制和座椅按键；返回时恢复原相机局部位置、旋转、视场和入座状态。已有主席位交互仍可在返回后使用。
