## 范围和未完成项

这些比赛使用免费 mock 选手，但**协议、题目、判分、胜负、事件轮询都走现有真实后端**；没有调用付费或用户自选大模型，因此不能称为“真实大模型实战验收”。当前是独立 Unity 编辑器场景，尚未列入发行 BuildSettings，也没有迁移旧场馆的 104 座、完整 HUD／大屏、角色自定义 GLB／音乐／镜头配置。灰盒只提供赛事 ID 观看入口和状态提示；新站内仍缺观众视线优化、完整人行入口、日常互动和正式美术。旧可玩版继续使用原场景，中心仍为实心地面，不与新环台叠加。
