# P2：独立预览启动链 v001

日期：2026-09-27。对现有启动职责的核查：根目录 `Start-Game.cmd` 选择 V29 等旧版程序，`EditorBuildSettings` 和 `ArenaReleaseBuild` 的默认场景仍为 `QuQuArena.unity`；旧场馆由 `ArenaDesktopRuntime` 管理自带后端和开赛大厅。独立空间站 `BlackHoleStationLive` 只通过 `ArenaStationLiveMatch` 观看既有赛事，尚无开赛大厅和自带后端生命周期，因此本轮提供显式预览入口，不切换默认发行。

## 施工

- 新增根目录 `Start-Station-Preview.cmd`，只启动 `QuQuArena3D/Builds/BlackHoleStationStartupPreviewV2/BlackHoleStation.exe`，并把用户给出的参数传给 Player；预览包缺失时报告错误并返回非零状态。
- 新空间站读取与旧版相同的 `--arena-backend` 参数；未给参数时继续使用保存的本机地址。地址仍由 `ArenaConnection.SetEndpoint` 校验为无凭据的本机 HTTP，非法地址不会触发观看请求。
- 在 `QuQuArena3D/README.md` 写明预览须先有本机 `GameCompetitions` 服务及赛事 ID。
- 新增[空间站专用构建入口](../../../QuQuArena3D/Assets/Editor/StationPreviewBuild.cs)：构建前确认 `ArenaStationLiveMatch.cs` 的 `MonoScript.GetClass()` 指向实际类型，且场景中的赛事组件存在；否则直接失败。它只构建独立空间站场景，不调用旧版 `ArenaBuild.Prepare()` 改动默认场景。
