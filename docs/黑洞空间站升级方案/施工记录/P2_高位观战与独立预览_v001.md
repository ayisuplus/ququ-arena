# P2：高位观战与独立 Windows 预览 v001

日期：2026-09-27。施工对象是独立场景 `Assets/Station/Scenes/BlackHoleStationLive.unity`；原发行场景、`Start-Game.cmd` 和 `BuildV29` 未切换。本轮继续使用已经搭建的 240 × 240 m 主站和真实赛事事件接口。

## 已完成

- 固定观众席抬到环台北侧，座位顶面约 18.02 m。玩家从个人舱沿地板、70 m 水平长的实体坡道、17 m 高的平行步道和北侧横廊步行到座位；坡道与上层步道分开，避免头顶碰撞。中心黑洞井仍无地板碰撞。
- 接近座位按 `E` 入座，再按 `E` 起身。入座时镜头对准升起的中央擂台并切为 40° 视角，起身恢复先前位置、朝向和视角。北侧席位与左右选手的连线近似垂直，能同时看清两人和两块独立地板。
- 赛事 HUD 直接显示本机比赛服务包中的双方名称、当前血量、题目、胜者、阶段和同步序号。伤害、判胜、普通返航及冠军坠落仍由既有后端事件决定；HUD 不另算分。
- 独立 Windows 预览包：`QuQuArena3D/Builds/BlackHoleStationP1/BlackHoleStation.exe`，完整目录 191 个文件、约 330.6 MiB，附四份素材许可。此包只包含新空间站场景，未替换现有发行包。看现有比赛仍需本机 8181 端口服务，并在 HUD 输入赛事 ID。
