# P2W 南侧贴壳下行闭环 v001

日期：2026-09-28。状态：独立候选世界中的第三处公共下层入口；仍为结构灰盒。

## 施工依据与位置

[方案 v008](../施工方案_v008.md)要求从南侧温室边缘进入下层，并让西侧科研区→下层观测→南侧温室→西侧科研区形成可返回的步行闭环。最初[空间站总览图](../08_概念图/IMG-001_空间站总览_v001.png)限定外方、内菱形连桥、中央环和贯通井的主轮廓。主层地板不能直接穿越，因此从温室东侧 x≈42 的后门穿出南外壳，在外壳边缘 z≈-124 沿 x 方向下降，再从 x≈-18、z≈-85 接入既有下层南回廊。下降段水平约 60 m、高差 12 m；最南边缘约 z=-130，比原外方 z=-120 外伸约 10 m。没有改动中央井、选手平台或内菱形步道。

第一次候选把坡道向南延伸到 z≈-188，碰撞验证通过，但[总览对比](../../validation/station-south-descent-2026-09-28/overview-rejected-spur.png)出现偏东长尾。该候选保留为[可恢复场景快照](../../validation/station-south-descent-2026-09-28/rejected-spur-scene.zip)，没有采用。改成贴南外壳横向下降后，[同机位总览](../../validation/station-south-descent-2026-09-28/overview-hull-aligned.png)仍以方框、菱形和环台为主体。总览是几何关系核查，不是概念图画质验收。

## 实施与验证

`add_south_keel_descent.cs` 通过运行中的 Unity Editor 改候选场景：保留原温室后墙、南外壳、下层南外墙对象并关闭其连续墙段，增补各自的开口墙段；新建 6 m 宽、有地板、侧墙、顶棚及转角压力窗的下行通道。临时碰撞体和磁盘重开检查通过。[场景结构比对](../../validation/station-south-descent-2026-09-28/scene-structure-diff.txt)为新增 127 个 Unity YAML 对象、删除 0 个旧对象；4 个旧对象发生变化，分别是三段墙的激活状态与场景根列表。两盏灯被 Unity 自动补入的无关组件已从 Editor 移除。

[最终 Win64 Player 证据](../../validation/station-south-descent-2026-09-28/README.md)：从居住舱经温室、新坡道到下层南回廊实走 340.2 m／1365 步，逐步检查地板与碰撞并写入安全位置；退出后另开 Player 在下层恢复，再经原西侧坡道回到温室，实走 496.8 m／1988 步。南侧闭环、原温室照料存档、北侧双门与货运工单回归均通过。验证使用脚本驱动 `CharacterController.Move`，未把真实键盘操作或持续性能算作已验收。

## 后续

下层南回廊已有可辨的中央井视线，但新坡道、转角窗和温室仍是简单材质与胶囊角色；缺导览、照明节奏、正式气密门、维护活动及居民日程。当前可走网络比上一轮增加了从温室下行的独立选择，整个空间站仍不是可交付的 3A 小规模开放世界。下一步应把南侧公共温室与下层观测做成有停留理由的区域，而非继续延长空走廊。
