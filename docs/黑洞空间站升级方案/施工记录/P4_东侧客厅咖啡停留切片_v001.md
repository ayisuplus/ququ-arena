# P4 东侧客厅咖啡停留切片 v001

日期：2026-09-28。状态：独立候选世界中一处可从居住舱步行抵达的日常停留点；尚非完整咖啡厅或 P4 的 20 分钟循环。

## 位置与依据

[施工方案 v008](../施工方案_v008.md)把 LOC-09 东侧公共客厅放在居民街区与竞技回廊之间，要求可取饮、入座和观景。最初[空间站总览图](../08_概念图/IMG-001_空间站总览_v001.png)继续约束外方框、内菱形、中央环与黑洞井的整体关系；[生活区概念图](../08_概念图/IMG-003_生活区与观景咖啡厅_v001.png)给出局部气氛方向。本轮复用已建吧台、四把椅子和东侧客厅，不扩建外框、不改变中央比赛结构，也不新增未经核看的杯具美术。

## 实施

- `StationCafeMoment` 以稳定 ID `east-lounge-cafe-01` 管理吧台取饮、近椅入座、饮用和离座。玩家通过同一 E 键按所处状态操作；远处拒绝。入座临时关闭步行与自由镜头控制，把第一人称相机放到椅子位置；离座恢复原控制和角色显示。
- 取饮、饮用次数和是否持有饮品进入现有版本 1 候选世界存档；旧版无 `cafe` 字段的 v1 文件按初始状态载入。坐姿位置是临时镜头状态，不作为存档出生点；恢复的是椅旁安全步行点。
- 构建入口核查组件、吧台、四个座位、稳定 ID 和存档引用。原默认发行场景未切换。

## 验证与下一步

[Win64 Player 证据](../../validation/station-cafe-2026-09-28/README.md)：从玩家舱沿 65.2 m 连续碰撞路线抵达客厅，327 次 `CharacterController.Move` 逐步检查地板和阻挡；完成取饮、入座、饮用、离座。分进程重启后饮用计数和椅旁位置恢复；无咖啡字段的旧版 v1 存档载入并补写新字段。Editor 游戏视图截图验证了椅旁窗景和桌面构图。

探针直接调用 `Use()`，未验证真人按 E 键操作。现在只有状态与相机变化，没有杯具、拿杯或坐姿动画；NPC 尚无椅子占用协调。现有窗外能看站内结构和星空，但中央黑洞被结构遮挡，和局部概念图的观景效果仍有差距。下一轮应优先核对 LOC-09 的视线与中央井空间关系，再补实际键鼠漫游、NPC 相遇和日程，不把这块灰盒称作完整开放世界。
