# P2W 连续世界单次 Player 漫游 v001

日期：2026-09-28。状态：独立候选世界路线验证通过；默认发行场馆未切换。

按[施工方案 v008](../施工方案_v008.md)的多层连通与站外往返方向，在同一 Win64 Player 进程中从玩家舱出发，完成东侧咖啡→上层完整环路→西侧研究台→下层完整环路→南侧温室→西侧研究台→北侧停靠舱／停靠舰→返回玩家舱。每段从角色上一个真实位置继续，气闸和舱门按顺序开关，没有菜单传送或中途重置角色位置。

[原始证据](../../validation/station-continuous-2026-09-28/README.md)记录 4,239.8 m／16,978 次碰撞体移动、每步地板与阻挡检查、东／南／西三区行为、世界存档和本机免费 mock 赛事。比赛在玩家前往站外时由原赛事后端结算；玩家在停靠舱内等到冠军演出完全结束，返舱后赛事 ID、冠军和回合数仍一致。后端保持唯一评分与胜负来源。

失败路线也保留：西坡道下方不能沿坡道轴线走进地面科研区，西侧科研庭院必须走东侧公共门。最终验证路线遵循这两个实际空间边界，没有挪动场景墙体。

这轮证明现有灰盒有一条可连续穿越的多区、多层路线；累计距离来自重复环行，不代表世界面积或内容量。方案指定的两条从主层出发并返回主层的路线，仍须分别按实际键鼠路径验收。最初概念图的外方框、内菱形、中央环与北侧抵达轴未改动，但当前灰盒总览仍有大面积平板、瘦弱外缘和单薄目的地，观看感受仍可能像场馆。下一轮先从同机位比较概念图与当前场景，结合项目已有真实参考研究空间体量与层次，再做真人键鼠 20 分钟路线、区域导览与性能验证。
