# P2W 停靠舱远端赛事持续与待续显示 v001

日期：2026-09-28。按[施工方案 v008](../施工方案_v008.md)检验玩家离开中央赛场后，空间站世界中的赛事是否继续。测试点是北侧可进入的停靠舱，距核心约 245 m；场景仍为独立候选 `BlackHoleStationObservatory.unity`，发行入口没有切换。

隔离本机后端的四人 mock 赛在玩家位于舱内时从已记录的序号 102 推进至 199；服务端因平局进入 `waiting`，并未产生冠军。它揭示 Unity 在平台已停靠时漏显示 `pending`，重连 `waiting` 快照也误写成“等待下一场赛事”。现已只修改 `ArenaStationLiveMatch` 的状态文案，两条路径均显示待续与原因。随后两人 mock 赛在玩家仍位于舱内时完成 76 个事件、一次掌击接触和一次冠军颁奖；两场均在返回赛场的 263.8 m 实走后保持同一赛事 ID 和状态。过程及原始结果见[验证记录](../../validation/station-vessel-live-2026-09-28/README.md)。

本轮把“远处比赛仍在运行”从早期接驳区边缘推进到了实际停靠舱，并发现与修复了待续状态的客户端显示缺口。服务端继续负责判分与冠军；相机没有因远端赛事强制转入近景。仍需在独立 Windows Player、真实模型对局、区域装载和长时间漫游中复验；居住、科研、生态等区的活动密度和导览继续施工，不能把这一条网络测试当作开放世界完成证据。
