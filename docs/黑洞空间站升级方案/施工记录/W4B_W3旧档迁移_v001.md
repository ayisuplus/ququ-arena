# v010 W4B：W3V2 旧档安全进入 W4A

2026-09-28。W4A 已将旧玩家舱交给 DeepSeek、西侧展厅分成模型住宅，访客从东北港区抵达。旧 W3V2 存档此前按场景隔离，直接启动 W4A 会从空进度开始；若只改场景 ID，又可能把玩家恢复在模型房间。本轮在 `StationWorldSave` 中加入一次性、只读源文件的 W3V2 → W4A 导入：仅目标主档及备份均不存在时执行，旧档保持不变。当前 W4A 主档／备份继续优先。

落点规则见[验证记录](../../validation/station-model-homes-w4b/README.md)：旧玩家舱到东北港区、西侧旧公共展厅到共享廊、东侧两间模型房到各自公共廊；其他仍通过 W4A 安全检查的位置保持不动。货运、温室、咖啡继续用既有稳定 ID 恢复。原赛事分数、结算与模型自定义不通过这份候选世界存档处理。

隔离 Win64 Player 以合成进度档完成九种迁移／拒绝／优先级／重启情形，原文件哈希在每次启动后不变；另将本轮 W3V2 Player 真实写出的档导入 W4A，得到场景独立的新档。改动存档组件后，W3V2 自己的双进程保存与恢复也重新通过。验证不包含真实用户历史档，也不覆盖 W3V2 以外的旧场景；因此 W4 的“完整旧档迁移和发行候选”仍未过门槛。
