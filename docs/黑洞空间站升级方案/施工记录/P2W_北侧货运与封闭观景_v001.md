# P2W 北侧货运与封闭观景 v001

日期：2026-09-28。状态：独立候选场景的可操作世界切片；正式任务、存档和美术待做。

## 和原概念图的关系

延续[空间站总览](../08_概念图/IMG-001_空间站总览_v003.png)北侧抵达轴线、外方框和上层连桥的空间关系。接驳厅仍由下层双门进入；上层从既有北侧观景步道接出一条封闭支路，终点隔着实体压力窗俯看同一接驳厅。两条路线服务同一可见目的地，没有创建独立小场馆或菜单传送。

货运设备位沿用上轮对 [NASA Harmony 模块化内部](https://www.nasa.gov/image-article/harmony/)的结构研究；控制台复用项目自有 Prefab。货箱和轨道仍是游戏灰盒，不主张模拟真实航天器货运流程。

## 施工

- 接驳厅左右两台控制台各控制一只货箱。玩家走到控制台按 `E`，货箱沿侧轨从泊位移动 12 m 至检修位；再次操作后送回。玩家离开该处，运动仍在同一场景中继续。
- 货箱前进方向被玩家占据时暂停，离开后恢复；另一侧控制台不能从远处触发。两台控制台共用一个小组件，各自持有自己的货箱引用。
- 既有上层北侧压力窗只在桥宽内分段，桥体有实体地板、两侧围护和顶棚；桥尽头的观察窗有碰撞，不能由上层绕开下层双门进入货运厅。
- 隔离 Win64 构建前检查两台货运控制台、桥与观察窗引用；Player QA 增加货箱去返、占道暂停及上层视角。

## 验证

- Unity Editor 从磁盘重开场景：两台货箱与控制台链接、中央井净空、东北角高台和赛事呈现对象仍存在。
- 原十条世界路线和新增上层北侧观景往返全部通过；新增路线 `147.8 m / 592` 步。单独的角色控制器检查也证实观察窗阻挡通行。
- Editor 中左货箱到检修位后，玩家移动到远处，货箱仍完成返程；右货箱拒绝远距离操作，近距离操作后到达检修位。
- Git `ac09988` 的隔离 `StandaloneWindows64` 构建成功。1280×720 Player QA 退出码 `0`：`dockOverlookFloorFound`、`dockWindowSealed`、`cargoMovedWhileIdle`、`cargoPausesForPlayer`、`cargoTransferRoundTrip` 均为 `true`。[原始报告与截图](../../validation/station-dock-service-2026-09-28/README.md)。
