# P2W 北侧接驳双门样板 v001

日期：2026-09-28。状态：独立空间站候选场景的可玩灰盒，未经美术批准。

## 意图与边界

沿最初总览图的北侧抵达轴线，把既有外侧支路做成一处能从核心区步行抵达、进入、返回的目的地。当前 `240 × 240 m` 是核心区灰盒；北侧支路延伸到 `Z=220 m`，不把这段长度称为最终世界规模。双门、封闭接驳端板均在现有 `BlackHoleStationObservatory` 独立候选场景内，默认发行场馆没有切换。

[NASA Quest 气闸](https://www.nasa.gov/international-space-station/quest-airlock/)的相邻舱段和舱门关系用于功能参考；[ESA 接驳环机制介绍](https://www.esa.int/Science_Exploration/Human_and_Robotic_Exploration/One_docking_ring_to_rule_them_all)用于末端接口的结构参考。现有方盒、环板只是路线和交互灰模，不复制真实航天器尺寸，也不宣称已完成压力、供氧或舰船接驳模拟。概念图仍决定空间站的外方框、内菱形、中央环和北侧抵达方向。

## 本轮施工

- 北向通道设站内、接驳两道实体舱门；玩家在门旁按 `E` 切换。另一道门开启时不能开启当前门；玩家位于门板平面附近时不能关门压住角色。
- 末端保留密封边界，在墙上加入分段接口环与对位标记，提供可辨认的到达点；此处尚无舰船和站外活动。
- 在既有路线回归脚本中加入开关门操作，确保新门没有把上层、下层或原外侧路线变成死路。
- 独立 Win64 构建前检查脚本导入、场景对象和门/玩家引用；Player QA 检查互锁、两门复位、地板支撑并截取末端视角。

## 验证

- Unity Editor 编译无错误；场景从磁盘重开，舱门引用存在，中央井保持贯通，原有节点和坡道数量不变。
- 第三人称角色控制器从接驳入口穿过双门到末端并返回，`278.0 m / 1112` 步；尝试同时开门被拒绝。
- 原十条世界路线全部通过；其中舱室→上层→下层→东侧公共绕行→接驳末端的连续路线为 `1877.2 m / 7513` 步。
- 从 Git `bfff839` 的隔离英文路径工程用 Unity `6000.3.24f1` 构建 `StandaloneWindows64` 成功。Player QA 退出码 `0`，`dockInterlocked`、`dockDoorsClosed`、`dockFloorFound` 均为 `true`；见[截图与原始结果](../../validation/station-dock-2026-09-28/README.md)。

## 实机画面判断与下轮

1280×720 Player 截图中，接驳室仍是大片空墙与空地，末端接口显得小，缺少停留和探索理由。这个结果只支持“路线和交互成立”，不支持“已有 3A 感或小规模开放世界完成”。下一轮先按总览图和真实空间站参考确定抵达大厅、货运/维修活动、外侧观景关系，再在候选区做一块有尺度对照的视觉与交互样板；保留中央空洞和跨层闭环。中文 HUD 字形、实体键鼠完整漫游、长时间性能、远离赛场时的正式服务端赛事和正式美术均另行验收。
