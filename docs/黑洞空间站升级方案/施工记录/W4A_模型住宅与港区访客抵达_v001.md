# v010 W4A：模型住宅与东北港区访客抵达

2026-09-28。用户明确“家”是大模型的家，并选择玩家从东北港区抵达、旧玩家舱交给大模型；之后还可能扩建。本轮在 W3V2 上复制出独立的 `BlackHoleStationModelHomesW4A.unity`，没有覆盖旧场景或切换发行入口。[当前总方案](../施工方案_v010.md)保持 240 m 核心、十字四区、外围环路和黑洞下方关系，720 m 外径仍是可改候选。

| 当前对象 | W4A 处理 |
| --- | --- |
| 玩家／访客 | 第一人称从东北港区公共点 `(210, 0.06, 180)` 进入；不创建玩家住房或玩家房间 ID |
| ChatGPT、Claude | 保留已有各自房间、居民行为和共享起居联系 |

| 后续模型扩建 | 西侧留 7 × 6 m 未分配室内位 `(-90.5, 0, 55)` 和朝西的封闭支廊边界 `(-96, 0, 55)`；标记无房间组件，不虚构第七位居民 |

房间用 `room/resident/<model-id>`、居民用 `resident/<model-id>` 关联。未来添加模型时，先从已核对的新模型 ID 生成房间与日程，再在西侧未分配位或扩出的住宅支廊安置；共享廊与十字公共路保持通行，不能侵入中央擂台与井口。朝西墙当前仍是压力边界，真正接新舱时必须重新设计气密连接、疏散、结构和可走回路，不能只删墙接一块地板。这样扩建住宅时无需重排中央赛事机构、四区边界或既有六位模型的稳定 ID。

[验证记录](../../validation/station-model-homes-w4a/README.md)含港区到核心、三间西侧住房往返、新居民日程、预留位净空与外墙检查。隔离 Win64 构建的两个独立 Player 进程又确认六位住房身份、访客首次港区出生与从主存档恢复，均以 0 退出。W4A 没有完成东北到核心沿途的游逛密度、四区压力围护、旧场景存档迁移、完整下船入口、真人键鼠和视觉审查。灰盒仅沿用项目已有材质与外壳，没有凭空冻结新的美术样式；正式美术继续以 v010 所列建成空间与 NASA 真实参考为研究起点，并需要实图目视与素材许可核查。
