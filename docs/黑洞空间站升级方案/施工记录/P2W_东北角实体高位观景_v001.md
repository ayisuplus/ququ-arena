# P2W 东北角实体高位观景 v001

日期：2026-09-28。接续[东北观景节点样板](P2W_东北观景节点样板_v001.md)。上一轮的屋顶光学镜头能看见中央井，但不构成玩家亲自登上的观景路线；本轮在同一独立候选场景 `BlackHoleStationObservatory.unity` 中补实体坡道和高台。上一轮版本可由 Git `219a1a1` 恢复。

## 施工与概念图关系

- 沿 [IMG-001 最初总览](../08_概念图/IMG-001_空间站总览_v001.png) 的东北圆形角部节点施工，维持约 24 m 直径，不把新平台延伸成第二个中心场馆。外方框、菱形和 72 m 中央环台的位置保持不变。
- 节点内设 45 段连续弧形坡道，地面 Y≈14.06 m 到观景台地板 Y≈21.4 m；玻璃顶抬至 Y≈26.85 m，仍位于约 Y=28 m 的上部主框架内。坡道两侧为实体防护，观景台前沿为现有压力窗材质的透明围护。原地面控制台和 Y≈31 m 屋顶光学镜头保留。
- 顶层可用角色自身第一人称视角看到中央环台、贯通洞口和相邻廊桥；第三人称仍是默认漫游视角，可用 `V` 切换。这里是可站立、可走回地面的真实区域，不是摄影自由镜头或传送点。

## 实测与修正

| 检查 | 结果 |
| --- | --- |
| 第一次上坡 | 6 m 观景台边缘比坡道高约半米，角色在入口碰撞受阻；缩到节点内部的 4 m 台面并移动接坡位置后重测通过。 |
| 自然移动 | `CharacterController.Move` 只输入水平路线位移与向下重力，不人工给角色上升高度；上坡→下坡→再上坡共 **147.3 m / 698 次移动**，逐步检查水平／高度误差和脚下碰撞。 |
| 防护与视线 | 两侧实体栏杆加入后仍能上下；首次把观景台前沿也做成实体栏板，第一人称画面被遮挡，改为透明围护后[最终画面](../../validation/station-ne-gallery-2026-09-28/P2W-walkable-gallery-view.png)可见中央井。[遮挡版本](../../validation/station-ne-gallery-2026-09-28/P2W-opaque-rail-rejected.png)保留作为未采用证据。 |
| 原路线回归 | 东侧→节点→北侧 **62.1 m / 250 次移动**，地面控制台开／关及状态恢复通过；原十条 P2W 世界路线全部通过，包括上层 864 m、下层 680 m 两个闭环及到北接驳区的两条不同路线。 |
| 磁盘与净空 | 从磁盘重开后，23 段外窗、45 段坡道、透明围护、光学镜头与中央竖井净空检查通过。[场景总览](../../validation/station-ne-gallery-2026-09-28/P2W-walkable-gallery-overview.png)显示新坡道仍在东北角核心轮廓内。 |

重建顺序：上一轮的 `create_observatory_candidate.cs` → `build_observatory_node.cs` → `add_observatory_optics.cs`，再执行 `add_ne_walkable_gallery.cs` → `add_ne_gallery_guardrails.cs`。验证：`verify_observatory_saved.cs`、`verify_ne_walkable_gallery.cs`、`verify_observatory_visit.cs`、`walk_p2w_routes.cs`，均在 `production/black-hole-station/`。本轮是 Unity Editor 灰盒与自动角色移动验证，未做 Windows Player 性能、手柄操作、长时间漫游、正式压力围护或成品美术验收。当前站内前景仍单调，真正的黑洞景观也未制作。

下一轮沿四角与上下层路线继续增加可辨认的目的地，并用玩家视角验证导览和生活活动；不能只复制这段坡道或延长空走廊来充当小规模开放世界。
