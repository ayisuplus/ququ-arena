# P2W 世界连通基线 v001

日期：2026-09-28。范围：对已提交场景和建造脚本做静态核查，确定下一轮独立灰盒的连接任务。本记录没有宣称新世界区域已建成，也没有用自由镜头代替角色漫游验证。

## 目标与概念图边界

用户最终目标是以最初空间站总览为核心的连续小规模开放世界。最初 [IMG-001 v001](../08_概念图/IMG-001_空间站总览_v001.png) 的外方框、四角节点、斜向连桥、中央环和黑洞轴线必须仍能从总览视角读出；[IMG-001 v003](../08_概念图/IMG-001_空间站总览_v003.png) 已将两侧三角区填成科研庭院和居民客厅。上／下层与站外设施属于从这些结构延伸的候选施工，不把概念图未画出的细节当作用户已批准造型。

## 下一轮施工包与验收

1. 在独立候选场景标定主层通向上层、下层和外侧的公共连接点；先检查外墙／房间／观众廊碰撞、中心井和移动机构包络。输出带坐标与占用边界的连接表。**验收：**每个入口不会穿房间、压住座位或占选手路线。
2. 依照原方框与四角节点，在上层、下层各做一条有实体地面和围护的可返回闭环；从外方框接出一条经气闸到外侧接驳设施的支路。**验收：**角色从主层实际走完两条闭环与站外往返，任意路径可回核心区，中央坠落探针仍无碰撞。
3. 接入可见角色的第三人称灰盒镜头，保留观赛近景、自由镜头和第一人称读屏入口。**验收：**门、转角、上下层转换、座位与站外返回时镜头不穿墙，控制权可正确恢复。
4. 将现有赛事事件消费者保持在稳定根节点，验证玩家离开核心区后的比赛持续、跨区返回和场景加载。**验收：**结果、赛题和角色状态一致，不重复播放冠军演出。
5. 同机位对照最初总览与新增灰盒，检查外方框、四角节点、内菱形、中央环与黑洞仍是第一眼主体。**验收：**新增设施可到达且不反客为主；失败候选保留截图与原因。

地图最终外延、精装数量与帧率目标在上述连通灰盒实走后再冻结。当前只是静态施工基线；P2W 的 Play、Player、性能和真实后端验证均待执行。
