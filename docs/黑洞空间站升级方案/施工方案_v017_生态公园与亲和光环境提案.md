## 3. 一个主公园，两个互补空间

主公园暂名“澄湾生态公园”，设于 **R3 原主生态园的完整地块内**，最新方向为露天公园。拆除原玻璃拱顶、上部拱架、中央照料舱顶盖及入口雨棚；保留四入口、原门交互、六株功能作物及其身份，优先整合装饰花床和种植，原件与旧版本保留。原门交互继续保留，不将拆顶后的空间描述为经过验证的密闭温室。B03“潮汐种子舱”继续独立，承担少量珍稀形态展示与安静近观，不复制第二套喷泉公园。两者以既有R3环街串联，馆间环街保持清晰铺装，不散种树木、不新增跨环廊桥。

主园的路线是**一条完整回游环线＋原照料功能捷径**。保留四向进出和照料通路，以主入口抵达顺序组织以下景段；景段是相邻关系，不是未经测量的坐标。

| 景段 | 空间与植物组织 | 水与停留 |
| --- | --- | --- |
| 林荫入口 | 两侧疏密不同的自然树冠，地被连成片，入口正前方留清晰视线 | 先看见池面或主景树，不把门口做成花盆陈列 |
| 静水花湾 | 小组睡莲、少量大浮叶和开敞水面；后方中层阔叶作背景 | 一处主池与靠岸停留点，水面至少约一半保持开敞，比例为构图试摆目标 |
| 湿生浅滩 | 岸上蕨类/苔藓，岸边细叶挺水植物，浅水沉水丛，过渡连续 | 局部低跌水制造轻微动态；不把每段岸线都包成同高白边 |
| 林下奇植 | 一株有辨识度的 Meshy 主景，周边以自然植物衬托 | 不与喷泉并排争抢入口焦点；奇植是少量视觉重音 |
| 休憩庭 | 疏林下的瓷白座缘、局部木色接触面，保留视野 | 小型雕塑喷泉与座位形成独立停留点，再接回主环路 |
| 原照料区 | 中央舱、六株原作物和原交互完整保留 | 入口至照料点保留直接干燥通路，浇灌/照料操作不会被公园路线挤走 |

**先测后定尺寸。** v015记录的旧生态园包络约49.35×45.35m只作调查线索；B03原38×26m地块也不是本轮可任意填满的面积。先扣除门袋、气闸、中央舱、作物操作区、既有座位和路线，再冻结水池及种植边界。

新主回游路暂以2.4–3m净宽试摆，停留口袋退出通行线；既有较宽主通路不缩窄，B03已验证的2.5m中央路和1.8m环路保留。所有探索宽度以角色完整胶囊、会车/停留与多相位实走复核。若放不下，先缩池与减少景段占地，不挤走原功能、不扩大地块、不擅占住宅地块。

## 4. 植物层次：先补类型，再决定株数

自然形态应占主要可见绿量，探索比例约80–90%；奇异主景占10–20%，按玩家视野构图判断，不按实例数机械凑比。每个景段选择2–3种主导形态，沿路线重复形成节奏，避免把所有品种均匀混在每一床。全园首轮目标为约10–12种可辨认形态，不能把同一树的放大/换色算新品种。

| 层次 | 类型候选 | 构图规则与来源 |
| --- | --- | --- |
| 上层树冠 | 原Pachira＋一类舒展自然冠形 | 原资源保留；新自然树优先已有/免费成熟资产，冠下留透视空隙 |
| 中层 | 小型树蕨、丛生阔叶、优雅奇植 | 补目前树与地被之间的断层；高低沿回游线变化，保留入口视线 |
| 低层 | 原Anthurium、蕨丛、细叶草状丛、少量花叶 | 成片而非均匀点阵；用宽叶与细叶、亮绿与深绿区分 |
| 地表 | 苔藓、小叶地被、局部可见土壤 | 减少大块裸土，但保留植株落地关系；纹理/薄层优先，避免无数独立小网格 |
| 水岸 | 挺水细叶、低矮湿生蕨丛 | 岸高渐变，组团有间隙，不围成遮水的芦苇墙 |
| 水内/水面 | 沉水丛、睡莲、一类特色卷缘浮叶 | 能看到水下层、岸边层与水面层；浮叶不铺满全池 |

枝干、根与叶片必须有合理连接。禁止大面积荧光、金属树、塑料亮叶、悬空植株；自然绿色是主体，可在新叶/花穗/叶缘少量使用柔和奶白与淡粉。拟定类型是游戏视觉资产分类，不宣称真实物种可共生或生态闭环成立。

## 5. 水景与水生态表达

采用**一处主池、一段浅滩/短溪、一座低喷泉**，全部为有实体池底的园区景观，不挖穿空间站甲板、不形成新的大型贯通开口。水体、喷泉、岸线和种植归同一R3建筑包，不能跨固定带或运动接缝。

主池表现静水和水生植物，低跌水表现轻缓流动；喷泉采用瓷白托盘或卷叶形雕塑，细水束/薄水膜以接近坐姿观看为目标，不做冲顶水柱、巨型瀑布或彩灯表演。喷泉水效与睡莲安静水面分区，避免水花持续覆盖浮叶。

叙事上的循环为“主池收水 → 岸边湿生种植槽 → 隐藏过滤/回水设施 → 低跌水回主池”；喷泉可有独立支路。管线和检修盖纳入完整包络，普通游览时以植物与水景为主。此轮规划只要求可读的水循环景观、轻微水面运动及局部水声，不追加真实水质模拟、鱼类AI、繁育或资源生产系统。

已复用 `Assets/Station/AudioV013/GardenWater.wav` 为局部循环水声，听感尚未人工审阅。经现有资源和成熟URP水面方案比较，采用本项目URP接口的轻微波纹材质、现有反射组件和原生粒子，不引入SSR/流体模拟。Meshy仅制作实体雕塑。岸缘用可见池壁/连续挡边防误入，观水点局部降低视觉遮挡，碰撞与通路在候选中验证。

## 6. 光环境：整站变得亲切，公园先做样板

此次修订涉及整站照明方向，**不局限于给公园加几盏暖灯**。公园作为首个可控样板，后续依次验证咖啡/公共停留区、居住入口、环街及工作区。整体仍安静、清晰、有高科幻感，但不再让人视环境长期偏蓝青。

以下色温仅是美术调试起点，不是当前Unity读数、物理照度设计或验收值：

| 光层 | 提案方向 | 判断依据 |
| --- | --- | --- |
| 全站公共基础光 | 中性偏暖白，约4000–4500K起试；检查原天空/环境补光的蓝青贡献 | 白墙仍能读作珍珠白，人物与棕色接触面自然，阴影不脏蓝 |
| 公园冠层主光 | 柔和日光感，约4500–5000K起试，形成宽缓的明暗过渡 | 叶脉与绿色色相清楚，背光叶不黑成片，林下有层次 |
| 公园/咖啡/住宅停留光 | 局部3000–3500K暖白，重点在座椅、入口和接触面 | 有亲和力，局部暖意不过度染黄整栋白墙；灯具不直刺视线 |
| 环街与工作照明 | 中性白为主；少量冰蓝只作导向、设备或轮廓 | 走路和识别门口自然，蓝色不覆盖全部地面与皮肤 |
| 水景光 | 白光的轻微反射与局部波光，优先复用环境光 | 水体可读、能看到岸与植物，不成为过亮发光池 |

减少硬阴影和大面积过冷环境光的影响，通过主光、补光及材质协同处理。太空天空和银白吸积盘维持原设计，可在园区灯具中表达人工日光；不假设空间站存在真实地球日照，也不因此新增昼夜系统。施工v001中偏暖基础光使白墙泛黄，已否决；当前基础主光5600K、园区补光5300K，停留光3500K，曝光与玩家URP配置保持原值。这是实际美术参数，不是物理照度验收。

试样时先记录曝光、白平衡、灯强度、环境光、反射和玩家URP设置。先锁相机做灯光A/B，再分别处理叶片颜色空间、粗糙度与反射；如确需更改曝光/白平衡，单独记录成新的对照条件。不用统一暖色滤镜代替空间照明，不用整体抬曝光救暗叶，不用整体压暗解决白地刺眼。真实参考中的自然日光只提供观感依据，不能证明上述色温数值已验证。
