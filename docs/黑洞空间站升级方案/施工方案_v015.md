## 2. 总图尺寸的定案方法

现状依据为[只读调查及对象清单](v014/layout-organization-20261001/README.md)，原始数据见[inventory.json](v014/layout-organization-20261001/inventory.json)。该调查记录 113 项主要组团/对象、148 个座位及原六间居民住处；施工前重查当前版本，逐项核对，不能将历史快照数量当作永久硬编码。

1. 保留中央约 50m 贯通井作为核对起点，赛场和看台的有效包络先量实。旧 240×240m 方形核心不能简单切成半径 120m 圆盘：原住处会被切到；用外接圆包住旧方块也不满足“收紧”。先迁移外围内容，再重组圆形外壳。
2. 各环宽度由“现有房间/生态园包络＋入口前庭＋连续环街＋接缝退让”推导。生态园原约49.35×45.35m包络需要实际装入外环后检验，不能在总图中压扁罩体或移走内部交互来凑尺寸。
3. 固定换乘带暂以 **6–8m净宽**作为原型探索值；P2候选01取两条8m固定带，径向分界为25/84/92/176/184/254m，主圆盘直径508m，详见页首P2证据。候选尺寸、楼高与角位须经完整归属和动态路线验证后再冻结；原示意图的绘图坐标不等于米制工程尺寸。
4. 为每个建筑群提交环内扇区、完整屋檐包络、门口/街巷与运动扫掠范围。检查全周旋转时与固定抵达组、相邻环、上层连廊、灯具均不相撞；不能只看初始相位。

## 3. 环内与跨环步行

![跨环步行概念效果图v003](v015/layout-review-v003/pedestrian-v003.png)

图中的浅蓝侧为公共生活环边缘、白色带为固定换乘步道、浅绿侧为外环边缘。图示的是连续步行关系；材质光泽、建筑外形和接缝盖板需另做实机验证。

主路线为：**本环横向街巷 → 本环连续边缘步道 → 平齐接缝 → 固定换乘带 → 平齐接缝 → 目标环边缘步道 → 当时所在的目标街巷**。走路不等待门对齐，不跳缝，不强制瞬移。固定带在任何角度都有地面，但到达目的地街巷仍可能需要沿圆周走一段。

环街、横向街巷、建筑及其门前家具随所属环一起转。不得用一条固定径向桥穿过所有旋转建筑；即使演示截图中几条街巷恰好对齐，也不视为永久主轴。连续边缘步道必须无障碍，建筑、门扇、柱、台阶、长椅和灯具均退出接缝与运动扫掠带。高低错落留给各环内部屋面与观景台，跨界主地面保持同高。

固定抵达前庭通过一个宽接入段接外环的连续边缘步道。它不跨到中环，不使用会随时间撞进房屋的固定通廊。植物全部置于玻璃生态园内；内部同层公共步道减少玻璃围挡，外缘及井口按实际坠落边界设置保护。

当前外缘防护沿主圆盘、港区前庭与船坞延伸甲板的合并外轮廓固定布置；R3至固定港区的连接口保持敞开，不让转动栏杆扫过入口。井口防护跟随升降赛场；井口运板、固定赛场外缘、升降外缘及入口升降孔现已按平台实际承托设置受控通道，并通过页首原机构测试选手流程。真实后端赛事、异常重连及完整功能集成继续在P3验收，不能将机构测试视为整站赛事完成。

拟采用平齐滑接盖板表达科幻机械接缝；这只是概念。固定换乘带解决街巷错位，不自动解决移动地面带随、碰撞、边界抖动与相机舒适性。

| 日常路线 | 必须保持的体验 |
| --- | --- |
| 固定抵达厅 → 外环 → 中环咖啡/会客 → 内环观赛 | 不等对接班次；路径可被地点名与导览识别 |
| 外环住处 → 中环研究/咖啡 → 返回原住处 | 不穿赛场和他人房间；移动后的入口仍能找到 |

## 4. 旋转、赛事与存档边界

- 从上方看，暂按内环顺时针、中环逆时针、外环顺时针组织，具体速度分别验证。先按接缝相对固定地面的线速度约 **0.05–0.10m/s**探索；该区间不是舒适或安全合格值。同一环内外缘速度不同，以其较快边缘核对，不给两侧随意指定互不一致的速度。
- `v = |ω|r`，`T = 2πr/v`；半径100m时，上述范围对应约105–209分钟一圈。演示加速必须标倍率，实际步行在正常速度下验收；不可为了鸟瞰转得明显而直接提高正式速度。
- 运动参考系先明确，再接比赛表现：参赛者、升降台、看台、观众入口不能分别沿用互相矛盾的世界坐标。后端赛事与结算权威保持，旋转不改变真实题目/答案/比分事件。
- 每栋建筑的门、家具、座位锚点、居民目标点、交互及灯具归同一环。导航需处理动态目的地与跨环路径；不能默认静态 NavMesh 在转动后仍然成立。
- 保存位置需包含所属参考系及环内位置/朝向，明确重载时环相位恢复规则。冻结后再实现版本化迁移，旧世界坐标不可直接解释成环内坐标；房间/居民/交互稳定 ID 不变。
- 门槛、接缝、移动墙体附近的位置使用经验证的安全落点规则；旧档只读导入，迁移结果另存，新候选用独立测试存档目录。保留旧场景、旧路线及原存档哈希作为回归依据。
- 转动后的碰撞、烘焙光照、反射、音源和居民行为都要在候选中实际检查。整组挂到旋转根节点不是完成标准。

## 5. 零散部件整理规则

施工清单逐条记：原稳定 ID/GlobalObjectId、原路径、目标环/固定组、目标建筑包、动作（复用/迁移/重接/历史停用）、依赖、回退位置与验收证据。先整理归属，再移动；不得按当前根节点批量旋转，因为历史根节点混有多个功能区。

| 对象 | 归属/处理 |
| --- | --- |
| 屋顶、柱墙、玻璃、入口、家具、门、座位、灯、标牌 | 随所属建筑包；独立屋顶不得留在原世界坐标 |
| 环街、环内横向街巷、观景台与楼梯 | 随所属环；楼梯、平台全部包络不得跨接两个运动环 |

| 未确认用途的旧散件 | 放入待审清单，保留源对象记录；不直接删除或用圆形外壳遮盖 |

原六间常住房与八套短住房、148座位基线、咖啡/科研/生态/货运等交互均需映射。若整合建筑减少重复视觉壳体，不顺带删掉独立交互或房间。供应商来源、版本、许可、原始目录及 GUID 保留；通过项目侧派生材质/Prefab Variant适配。

## 6. 视觉落地标准

延续高科幻、安静、精细的白色空间站。珍珠白和瓷白为主体，浅蓝、浅绿、棕色、黑色按建筑功能区别使用；银色金属具有真实反光。瓷面、玻璃、金属和织物的粗糙度不同，不把全站调成单一灰白或镜面地板。照明按2026-10-03用户最新要求改为中性柔光为底、停留空间局部暖白，冷白/冰蓝仅作少量功能和轮廓强调，具体见[v017](施工方案_v017_生态公园与亲和光环境提案.md)；高光清晰但不刺眼，不靠整体曝光抬升或压暗代替材质处理，不把白墙与银白吸积盘整体染黄。

内环以完整圆形檐口建立赛事中心，中环三组公共建筑以屋面和前庭形成差异，外环保持低层、安静和视野。生态园是独立玻璃建筑，室外不散放植物。黑洞保留在东侧天空，银白吸积盘尺度远大于全站；不在脚下另放黑洞。

参见[v004标注效果图、建设摘要与生成记录](v015/layout-review-v004/README.md)，[v003无标注效果图](v015/layout-review-v003/README.md)和[v002历史效果图](v015/visual-direction-20261001/README.md)保留。概念图中的表现只用于视觉目标，不自动新增模型采购、楼层、人口或玩法；外观细化遵循先落位和边界、再造型的顺序。
