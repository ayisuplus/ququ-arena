## 单图生成与资产拆分

1. 选定一栋，使用该栋的原始 PNG。白底、单建筑、无遮挡轮廓有利于明确输入范围；不要使用本页截图、四图拼贴或含网页标题的图作为输入。
2. 第一轮建议仅生成几何，输出 GLB 作为可检视草模。先验证轮廓和体量，再决定是否值得继续整理；无需同时提交四个付费任务。
3. 图像中的建筑并非按比例绘制的技术图。统一单位、外包络、入口宽高和主甲板标高须在 Blender/Unity 中重新建立，不依靠生成器自动猜尺寸。
4. Blender 拆成 `Shell`（外壳）、`Glazing`（玻璃）、`Entry`（门与过渡）、`Walkable`（可走地板/楼梯，若启用内部）、`Collision`（简化碰撞）几类；这些是交接分工，不预先强制工程目录架构。能复用的门窗、座椅和灯具使用项目已有资源。
5. 保留生成原始文件和任务快照。后续修正版另存；将输入图哈希、生成资源类型、任务ID、实际积分、尺寸、材质、面数和预览记录回资产清单。此时再核验 Unity 6000.3.24f1 / URP 17.3.0 中的实际效果。

Meshy官方当前支持PNG单图输入及跳过纹理阶段，详见 [Image to 3D](https://docs.meshy.ai/en/api/image-to-3d)（2026-10-02 查阅）。本轮只准备资产，不锁定账号尚未确认的模型权限，也不提供未经实时核验的积分报价。真正生成时沿用指定 Meshy 服务，通过已安装 CLI 完成余额、版本和能力检查；不可访问时报告实际障碍。
