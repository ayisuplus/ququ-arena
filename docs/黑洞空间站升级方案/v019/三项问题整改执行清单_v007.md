本版承接[主方案](../施工方案_v019_街区秩序与立体层次.md)及[v006](三项问题整改执行清单_v006.md)，是当前设计与施工顺序入口。针对用户再次指出的布局散乱、Y轴低平、色彩过浅，把交付范围从单栋修饰推进到**完整街区及其相邻街段**。既有成果按证据复用，历史进度不重写；本文件不增加任何场景、构建或视觉通过项。

## 1. 现状、参考与选择

已核对R3[首轮整组记录](../../validation/station-v019-r3-review-20261004/README.md)，本轮实际查看其中的[总体图](../../validation/station-v019-r3-review-20261004/final-group/overview.png)及[公共街边人视](../../validation/station-v019-r3-review-20261004/final-group/shared-street.png)。这些已归档画面显示深青屋面与白墙已有区别，但该机位仍有大面积浅色甲板，街边以低檐为主；近端高度关系通过不能替代跨区或整环效果。此判断只覆盖所看画面，不宣称完成全站现场复测。

本轮通过内置浏览器实际查看[Safdie Architects 的 Habitat 67 官方总体照片](https://www.safdiearchitects.com/projects/habitat-67)：采用体量聚合、峰谷交替、退台与组间开口的方法；不照搬混凝土色、住宅密度或屋顶种植。材料实际查看项目中已入库的 White Stucco 基色纹理，并核对[来源和CC0登记](../../../production/black-hole-station/vendor/polyhaven-white-stucco/README.md)。参考照片仅用于设计分析，不作为游戏资产；细颗粒纹理只负责近景表面，不能代替体块、厚度和反射设计。

比较三种路径：仅加深颜色工作量小，但不能解决散乱；普遍加层能抬高轮廓，但会增加遮景、通行和性能成本；本版采用**整组收拢与接街 → 显露已有中层 → 缺口处补有用途的体量 → 墙顶地联合材料**。原六户、四馆、连续甲板、圆周梯级赛场、三运动环及固定抵达组保留；公园继续露天集中种植，银白吸积盘与中性柔光／局部暖白继续沿用。

工作区已有未提交的v019科研材料、审阅脚本和证据，以及其他前置修改。后续施工先核实它们与已提交基线的差异、完成状态和构建绑定，保留原件；本轮不将其计为通过，也不重复覆盖安装。

## 2. 布局：用共同空间组织建筑，以街段连接各区

每区在所属环局部坐标中冻结主楼、配楼、共同空间、主要入口、服务侧和观景开口；门廊、灯、家具、柱、基座与铺装均登记归属。对相邻组团补一张接口图：哪段供连续行走，哪段供停留，材质在哪里转换，副馆从哪里独立到达。避免新楼各自配一块彩色底板、外围仍留无用途空场。

| 街区 | 建筑与空地的组织方式 | 形成区分度的主要动作 |
| --- | --- | --- |
| R1赛事 | 梯级座席围中心井，放射楼梯接后方连续环廊 | 环形层叠轮廓；入口、后勤沿既有通道组织，保留看台身份 |
| R2科研 | 竖向主翼、低馆与内院构成紧凑组团 | 竖向实体、深凹入口、窄窗；设备集中服务侧，院边接真实建筑端部 |
| R2阅读／活动 | 两座原低馆在前，中层阅读楼在共同前庭后侧 | 厚端墙、水平窗带与退台；保持两馆入口和穿院线，独立副馆各自接街 |
| R2咖啡 | 开放低檐面向街道，中层露台向后退 | 木檐、开放柱廊和露台；桌椅聚在停留侧，穿行路线保持完整 |
| R3常住 | 六户小门庭接公共步道，旧厅与共享楼围合共同生活节点 | 小尺度入口序列、公共／私密过渡和内向庭院；复用已完成收紧位置 |
| R3短住／B04 | 以共用到达点组织服务和住宿，观景面错层展开 | 到达侧紧凑、观景侧开敞；形成露台序列，避免复制常住小院 |
| R3公园／B03 | 水岸、林下与开敞场地形成连续园地 | 以绿量、水面和天空形成轮廓低谷；附属设施归园界，不向街外散植 |
| 固定抵达组 | 长向候舱、集中服务与明确换乘前庭 | 长向秩序与清晰入口；候留家具避开运动环接口和换乘通路 |

**施工判据：** 每一件可见散件有建筑、公共街道或景观归属；每片保留空地有通行、停留、服务或观景用途。隐藏名称后，相邻两区至少在空间开合、轮廓高低、窗墙节奏三项中的两项明显不同。归属完整只算技术登记，是否整齐、是否可辨仍须人视审阅。

## 3. 高度：建立低入口、中层主体与局部高点的连续关系

| 层级 | 相对所属环完成地面的探索范围 | 施工作用 |
| --- | --- | --- |
| 低层 | 约3–5m；既有低馆可保留原高 | 门廊、户门、配楼和近景停留，衬托后方中层 |
| 中层 | 约8–14m | 街区主体，以真实楼层、凹入、退台和可达露台建立厚度 |
| 局部高点 | 约16–22m | 科研及合适既有附馆的少量峰值，与公园、观景空隙交替 |

上述是选型范围，不能直接当作施工尺寸。保留已记录的科研17.88m、阅读11.9m、咖啡11.8m与共享楼12m；B02/B04按原生包络复核，暂不新增24–30m塔楼。不整体拉伸旧楼、家具或空壳，不将各区做成相同高度的三层白框楼。

先沿实际到达路线画平面视锥与穿过遮挡物的剖面，再判断是入口朝向、前后距离、旧楼还是檐口遮住中层。只处理真正遮挡的部分；已有两层以上主体仍不足以形成层次时，再提出有使用目的的新楼翼。完整低中高展开要覆盖配楼、屋顶和树冠，不能只画最高点。

每区固定“接近、转向、庭院停留”三个正常玩家机位，至少两个能同时看见低层与中高实体，并辨认中间楼层或退台；只露出屋顶不通过。连续步行中还要记录高低变化，不能挑一个特殊仰角代表整区。新增可达上层须同步楼梯、平台、护栏、楼板碰撞和返回路线；公园以低谷和植物层次验收，不强行配高楼。

## 4. 色彩与质感：分区大面定主次，细部表现材质

保留银白基调，增强成片中深色实体和凹入面。每区制作包含旧楼、新楼、院地和邻接甲板的材料样板；旧顶、背面、檐底纳入同一轮，不只调整新楼门头。白色约50%、中深色约20–35%可作建筑样板的起点，其余分配给木、玻璃与银色；不以全画面像素比例作为验收指标。

| 分区 | 成片材料分配 | 避免的趋同 |
| --- | --- | --- |
| 科研 | 瓷白结构、靛蓝实体／凹入面，银色精细收口 | 深色仅剩细描边，或满墙透明白框 |
| 阅读 | 珍珠白厚墙、墨蓝水平面，局部木檐 | 照搬科研竖肋；背面成为整片无细节黑板 |
| 咖啡 | 白色结构、木棕檐底与触面、中蓝庭院局部 | 全部刷蓝；木色只用纯色且没有方向和尺度 |
| 常住／短住 | 常住用深青内衬与木触面；短住用青绿壳体内场、银色露台边 | 两区只靠换色识别；把全部地面染深 |
| 公园／抵达／赛事 | 公园自然绿与深池壁；抵达深蓝入口和银色构件；赛事白梯级配深蓝凹入面 | 全站共享同一浅蓝浅绿底色，失去功能主次 |

按三个尺度处理：远景看明暗体块与轮廓；中景看墙厚、倒角、凹窗、板缝；近景看米制纹理、法线、粗糙度和反射。细颗粒贴图不能关闭远景过浅问题。银色保持清晰反光，瓷面柔和，木和织物低光泽；白材自然阴影允许，工业灰大面不采用。

甲板按“公共主街—区域前庭—门前过渡”建立连续材料关系。各自保持适当明度和板材尺度，边界落在真实门口、墙端、巷口或板缝上；保留结构连续性与运动缝，不能用零散彩片代替收边。样板至少延伸至相邻区域的真实接口，避免只改善一张近景。

同一轮前后对照锁定玩家相机、URP附加数据、曝光、白平衡、光照与旋转相位。检查亮面不过曝、深色不堵黑、玻璃排序与反射可信、纹理不拉伸、接缝不闪烁；材质和局部照明分别定位，不通过整体压暗或增亮掩盖问题。

每批只交一套可复核结果：同版本归属总图与接口图、实际到达剖面、固定机位前后图、对象—表面—材料覆盖表、受影响路线／身份回归、问题及版本清单。平面包围盒投影注明“包络”，高度散点注明“展开”，不能冒充墙线平面或真实剖面。

覆盖表至少区分“本批调整、复用已验、仍未审”。所有Renderer列入清单不等于每个隐藏面已看过；局部Player路线通过不等于完整运动周期或旧坐标存档恢复通过。保留历史场景、稳定ID、原玩法实现与存档语义；核心赛事接入和完整存档工作继续按原范围暂缓。

## 6. 问题关闭规则

对八类区域分别登记布局、Y轴层次、材料质感的“通过／返修／未审”，另列技术验证与用户认可；不得用单个总勾覆盖所有区域。公园按其低谷角色检查。出现返修时记录机位、对象、具体问题和预期改善，再修改对应范围。

本版完成条件为方案、当前入口与执行顺序一致，文档链接有效，提交仅包含本轮文档。施工后的目标仍是玩家在正常行走中能辨认街区、感知高低关系、看清材料差异；本次文档更新不宣称这三个目标已经实现。
