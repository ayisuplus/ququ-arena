## 3. Y轴层次：低入口—中层主体—少量高点

高度相对所属环完成地面计量。以下为设计探索区间，不是对旧楼强制缩放的标准；既有合适体量优先保留。

| 层级 | 探索范围 | 本轮使用方式 |
| --- | --- | --- |
| 低层前景 | 3–5m | 门廊、入口配楼和生活接触面；既有低馆不为凑数削低 |
| 中层主体 | 8–14m | 阅读、咖啡后翼、常住共享楼、短住叠台；形成有厚度且可辨认的楼层关系 |
| 少量高点 | 16–22m | 优先复用科研等既有主楼；在环展开中控制分布，不给每区各建一座塔 |

暂不新增24–30m高点，此项优先于主方案早期探索表。公园、住宅入口和关键观景方向保留低谷。各区无需机械凑齐三档；建筑多的街区仍须有主楼和配楼之分，不连成绕环等高墙。

每组提交沿实际到达线的剖面与三个正常眼高机位：环街接近、入口转向、前庭停留。至少两个位置能同时看见低处与中高实体；若高楼只出现在鸟瞰或特意仰视中，该组高度整改仍未完成。优先改组团位置、朝向和前后距离，再处理遮挡视线的旧檐，最后才判断是否缺少新体量。

新增开放层须有用途、楼板厚度、支承、楼梯、平台、护栏及回地面路线。封闭上层明确无入口，不放引导玩家到达的门或座位。禁止整体Y轴拉伸建筑和家具，也不能用抬屋顶、高墙皮或装饰天线充当新增楼层。

对新增或迁位体量做跨环观景扫描，找出最不利相位并实机复核。遮住原主要黑洞／赛场视线时先退让、分段或取消；两相位路线通过不等于全相位观景通过。

## 4. 色彩与质感：让中深色成为建筑材料

白色仍是主体材料之一。建筑表面选样以白色约50%、区域中深色20–35%为起点，其余由木棕、银色等组成；这是样板设计参考，不是必须凑满的全站像素指标。植物、天空、水面与受光阴影不用于计算材料占比。公园人工构件不机械套用住宅比例。

### 4.1 先解决整片浅色，再精修表面

- 中深色用于完整侧墙、凹入内衬、交通体或檐底，在中景能读出面积；不只给白楼加一条细色边。
- 旧住宅与新共享楼同批处理。常住旧屋顶保留浅色边缘时，内场、檐底与墙面须有层次；不把所有白顶一律涂黑。
- 前庭与主街通过板材尺度、适度明度差和真实接缝区分。浅墙、浅顶、浅地不能全部用同一材质；不能靠把整块地坪涂深来代替立面整改。
- 深色背光仍需看得出蓝／绿／棕色相，通道不能被读成洞。保留白色自然阴影，不用增加曝光消灭阴影。

### 4.2 每区交付一套墙—顶—地材料样板

| 材料 | 必须可读的质感 | 返修现象 |
| --- | --- | --- |
| 白色瓷面 | 板厚、倒角、克制分缝、柔和宽高光 | 大白面融合，靠描边或发光区分 |
| 蓝／青釉面或涂层 | 清晰色相与适度反射，服从完整体块 | 平涂塑料感，或背光堵黑 |
| 银色金属 | 窄而清晰的反射，尺度合适的表面细节 | 哑光灰冒充金属，或满屏镜面闪光 |
| 木材／织物 | 木纹方向跟随构件，织物低光泽 | 棕色塑料、纹理拉伸、椅垫像金属 |
| 玻璃 | 框体、内部和环境反射可同时辨认 | 不透明蓝墙、叠层发黑、刺眼亮点 |
| 石材地面 | 真实尺度分缝和适度粗糙度 | 纯色格子、大面积重复纹理、湿镜面感 |

样板同时包含原墙、新墙、屋面、檐底、前庭与相邻甲板，比较两个完整组合后保留一套。先修几何厚度、倒角、UV尺度及材质引用，再校准反射和微表面。锁定玩家相机及URP附加配置、曝光与白平衡；材料比较期间不改全局照明。中性柔光与局部暖白单列检查，不能通过整体压暗或有色灯光制造质感。
