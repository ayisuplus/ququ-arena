## 1. 设计判断与参考

本轮实际复看已提交的[阅读原入口人视](../../validation/station-v019-reading-roofs-20261004/render-v001/main-arrival.png)和[常住共享楼街侧人视](../../validation/station-v019-homes-life-20261004/render-homes/homes-street.png)。前者仍以低馆和宽铺装为主，后者已有中层但大白面、独立楼体与周边街边关系仍需联合处理。这是两个历史机位的观察，不代表全站最新实测。工作区中的阅读迁址试验尚未纳入本次文档的完成结论。

通过内置浏览器重新打开并实际查看[Habitat 67 官方实景照片](https://www.safdiearchitects.com/projects/habitat-67)：取其高低体块聚合、错层退台与组团间留空的方法，不采用其混凝土底色，也不照搬住宅密度。照片只作设计参考，不作为游戏贴图或已获授权的模型素材。

采用“**先组织街区，再调整体量，最后联合完成材料**”的路线。单纯加深颜色不能解决散乱，普遍拔高会遮挡黑洞和赛场；优先让已有楼层参与街区构图，再按缺口增加真实可用楼层。方案中的高度和配比均为试摆、选样目标，需经场景测绘和正常玩家视角验证。

## 2. 布局：每区一个中心、一套清楚的建筑关系

每个施工单元必须同时包括原楼、新翼、前庭、相邻环街及附属设施。先交付有对象编号的局部总图，再调整建筑；总图标出主楼、配楼、入口、停留空间、服务侧、观景开口和散件归属。不得用添加彩带、灯柱、家具或散树代替建筑围合。

| 分区 | 建筑与公共空间的组织 | 从相邻街区辨认的主要依据 |
| --- | --- | --- |
| R1赛事 | 圆周梯级看台围绕赛场，放射楼梯接连续后廊 | 向中央逐层下降的完整圆形核心 |
| R2科研 | 主楼与低馆组成紧凑院落，服务设施收至侧后 | 竖向深窗、较高实体、收拢的院口 |
| R2阅读／活动 | 原06、08与阅读楼形成共同前庭，原门和新门均朝可理解的到达路径 | 低馆在前、中层参与围合；厚墙、水平窗与阅读露台 |
| R2咖啡会客 | 前庭向环街打开，停留区偏向建筑一侧，穿行线留在街侧 | 低木檐、通透底层、后退上层 |
| R3常住 | 六户小门庭接公共步道，共享楼对着公共停留空间 | 私密低入口、凹窗和侧后中层；公共路线不穿户门前庭 |
| R3短住／B04 | 共用到达前庭接错层观景设施 | 连续公共叠台与观景窗，区别于常住小门庭 |
| R3公园／B03 | 连续林下、水岸及低喷泉，园地边界清楚 | 露天低谷与集中自然绿量，B03作为少量奇异主景 |
| 固定抵达组 | 候舱、服务、换乘路线围绕同一个到达前庭 | 长向候舱和单一明确的入口节点 |

每块空地明确属于通行、停留、服务或观景。无用途的大空场先收拢建筑组合；需要观景的留白保留并标注。区界落在楼端、街巷、院口或真实铺装接缝，不能用跨过空场的巨型色块充当街区边界。

## 3. Y轴：从低平单层变成有节奏的街区轮廓

高度相对所属环完成地面计算。先复用科研、阅读、咖啡及共享楼已有层次，不重复建造已存在的楼层。

| 高度层级 | 设计探索范围 | 落点与要求 |
| --- | --- | --- |
| 低层前景 | 3–5m | 门廊、街边配楼、私密入口；旧馆不为凑数强行降到此范围 |
| 中层主体 | 8–14m | 阅读、咖啡后翼、共享楼和短住叠台；用真实层板、退台、窗洞建立体积 |
| 少量高点 | 16–22m | 科研等少数主楼；位置和数量由全环展开与遮景扫描决定 |

不要求每区机械凑齐三档。公园与户门附近保持低谷；暂不新增24–30m高点。每个建筑组团需提交沿真实到达方向的剖面，以及“接近—转向—入院”连续人视，至少两个采样位置同时能读出低处与中高实体。建筑在视野外时先改朝向和组团关系，被旧檐遮挡时再处理檐线。

增建必须有用途、支承、楼板厚度及明确的开放边界。开放上层接连续楼梯、平台、护栏和回地面路线；封闭体量不放误导玩家的门或座位。禁止整体Y轴拉伸旧楼、家具，或只竖高墙、抬屋顶制造假楼层。

## 4. 色彩与质感：为各区建立完整材料组合

白色继续承担主体，但每区让中深色成为真实墙面、内衬或建筑体块。白色约50%、有色中深面20–35%沿用为建筑表面选样起点，其余用银色、木棕等协调；不作为全站屏幕像素硬指标，也不靠大面积蓝地达标。

| 区域 | 有色主体及接触面 | 重点表现 |
| --- | --- | --- |
| 科研 | 靛蓝实体、瓷白、拉丝银 | 竖向体块、深窗阴影、清晰金属边缘 |
| 阅读／活动 | 墨蓝水平实体、木檐；活动馆局部青绿 | 厚墙和凹窗、柔和白边、水平层次 |
| 咖啡 | 中蓝、胡桃棕、珍珠白 | 通透底层与有温度的木色触面 |
| 常住 | 暖棕、局部深青、珍珠白 | 实墙凹窗、门庭私密感、低光泽生活材料 |
| 短住／公园 | 青绿整面、木触面；自然深浅绿 | 叠台与水岸，避免整区同一浅绿 |
| 赛事／抵达 | 深蓝座席或入口内衬、瓷白、少量银 | 明确入口与核心层级，不使用全站发光描边 |

每次材料选样同时包含旧墙、新楼、屋顶、檐底、前庭和邻接甲板。白墙与白地靠明度、粗糙度和构造边界分开；深色在背光下仍有色相，不能调成黑洞。瓷面用柔和宽高光，银色用清晰窄反射，石材有适当粗糙度和真实尺度板缝，木纹服从构件方向，织物保持低光泽，玻璃有可读的框体、内部及反射。

先处理厚度、倒角、洞口和材料面积，再调整微表面。锁定玩家相机、URP渲染配置、曝光及白平衡选样；局部中性柔光、暖白另作一项比较。不得通过整体加曝光、压暗或有色灯光掩盖材料问题，不把白色自然阴影改成纯白。

## 5. 施工顺序与停止返工的条件

| 批次 | 具体交付 | 可转入下一批的条件 |
| --- | --- | --- |
| A 阅读组团 | 复用已薄化屋顶和背立面；核对新楼接街／迁址候选，收齐共同前庭和旧址归属，交付同版本总图、剖面与连续到达图 | 原门和上层可达；正常到达可见高低关系；低馆与新楼共同围合。已通过且未受影响的屋面、高窗不重复修改 |
| B 六户常住组团 | 六户门庭、共享楼与公共停留点一张总图；共同调整旧屋顶、墙面和前庭地面 | 户门身份保留；公共／私密路线清楚；低住宅与中层共享楼同框有主次 |
| C 其余分区 | 科研院落与咖啡开放街边成对对照；依次处理短住、公园边界和抵达组 | 每区独立通过布局、高度和材料审阅，区界与相邻街道连续 |
| D 全站 | 同版本全景、各环展开、连续漫游、旋转不利相位与受影响路线／性能回归 | 三项问题逐区有结论，遗漏区继续修订；技术通过与视觉认可分别记录 |

每批先比较至多两种明确针对问题的试摆／材料组合，记录采用理由和未采用版本。若两种都不能满足判据，回到总图或体量定位问题；不无限微调无关细节，不把额外装饰算作进度。某区局部成立后可推进下一组，同时将全站旋转遮景等未完项留在D批；不能借此宣称该区或全站已最终验收。

## 6. 三项独立验收与交付边界

| 问题 | 必备证据 | 返修条件 |
| --- | --- | --- |
| 布局散乱／区分不足 | 对象归属总图、隐藏区名的人视、相邻区接口 | 只能靠标牌或颜色认区；主楼与前庭分离；散件无归属 |
| Y轴低平 | 环展开、到达剖面、正常眼高连续画面及上层路线 | 只有鸟瞰看见高度；孤立高楼未参与组团；假层或通路不对应 |
| 浅色／质感不足 | 同配置近中远墙地顶对照及正常Player运动画面 | 大白面融合；中深色堵黑；瓷、金属、木、玻璃表现雷同；高光刺眼 |

每项记录“通过／返修／未审”，附对应场景版本和画面，不以构建成功替代视觉结论。迁址保持稳定ID并记录新旧坐标；旧版本场景和旧档保留，但ID不变不等于旧世界坐标存档已适配，受影响的存档恢复须单列复核。核心玩法及完整世界存档仍按既有范围暂缓。
