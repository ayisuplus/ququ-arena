## 2. 布局：从散放建筑改为有中心、有边界的街区

每区先完成一张所属环局部总图：主楼、配楼、主入口、共同前庭、服务侧、观景开口、真实户门、附属件包络与公共路线均标注。每块空地明确为通行、停留、服务或观景；没有用途的断口优先通过收拢、入口转向或前庭收边解决。距离远的副馆独立接街，不能为功能同属一区而强行连成巨院。

| 区域 | 空间组织与轮廓要求 | 当前整改重点 |
| --- | --- | --- |
| R1赛事 | 圆周梯级、放射楼梯、连续后廊形成完整中心 | 清理归属和入口关系，保持贯通井与原观赛身份；不做方形看台 |
| R2科研 | 紧凑院落，竖向主翼与低配楼形成主次 | 设备收至服务侧；厚实体、窄窗和退让入口构成辨识度 |
| R2阅读／活动 | 两座低馆围前庭，中层阅读楼在后，保持水平层线 | 复核连檐对实际楼层的遮挡；院边和铺装跟随建筑转角收止 |
| R2咖啡 | 临街开放，低檐下停留，上层向后退 | 座位靠建筑侧聚合；公共穿行不从桌椅之间穿过 |
| R3常住 | 户门小门庭—公共步道—共享庭院—中层共享楼 | 保留已收紧位置，明确私密门前与公共停留；改变长檐一条线压低整区的读感 |
| R3短住／B04 | 共用到达点与面向观景的错层叠台 | 公共露台和观景窗形成横向层叠，区别于常住小院；先查真实包络与相邻关系 |
| R3公园／B03 | 露天林下、水岸和集中植物形成低谷 | 园地边缘接街；自然绿量与少量奇异主景集中，不散种到各区 |
| 固定抵达组 | 长向候舱、服务点和换乘集中到达 | 服务与停留避开换乘线，主入口清楚；保持固定组与运动环边界 |

相邻区至少在**空间开合、轮廓高低、窗墙节奏**中有两项差异。隐藏区域文字后仍应能辨别两区；不能把相同白框玻璃楼换成不同颜色作为分区成果。

### 街边与附属件的具体处理

1. 长檐按真实入口、结构支承和组团转折分段编号，分别标明保留、退短、开口或调整轮廓的候选。不能先删柱后看是否有悬空檐；不为了显高破坏户门遮蔽和原入口。
2. 庭院边界接实际墙端、楼梯侧或檐端。公共开口对准通路，家具退到停留区；不用跨空地的孤立矮墙充当区界。
3. 铺装在入口、街巷或整板接缝处换材质，清理重复叠面和无功能尖角；连续甲板保持，不通过挖沟分区。
4. 门廊、柱、饰面、灯、椅、基座逐件归属。迁位同步路线与原地恢复；原房间、住户和交互ID保持，旧版本保留。

## 3. Y轴：让高度进入玩家日常视野

高度均相对所属环完成地面；以下不是强制改楼尺寸。

| 层级 | 探索区间 | 使用方式 |
| --- | --- | --- |
| 低入口与配楼 | 3–5m | 保持门口与生活尺度，既有低馆不为凑数削低 |
| 中层主体 | 8–14m | 利用阅读、咖啡、共享楼等已有体量，必要时补真实楼翼和退台 |
| 局部高点 | 16–22m | 优先复用科研及既有附馆，分段分布；各区不必都有高点 |

暂不新增24–30m塔楼。公园与重要观景方向保留低谷，不能把整环堆成等高墙。R3优先检查旧长檐、住宅后侧和共享楼之间的前后关系；不是所有住宅都需要升层。

每区必须交付一张沿真实到达路线的剖面，以及环街接近、入口转向、庭院停留三个正常玩家眼高视图。至少两个位置同时读到低处与中高实体，并可辨认中层的楼层或退台，而不是仅见一小截屋顶。未满足时按以下顺序处理：

1. 核实主楼是否在日常到达方向、前后距离是否过大。
2. 对照视线调整遮挡的檐段、前景体块或入口方向；保留受影响支承与功能。
3. 如果仍只有低平轮廓，再提出中层楼翼方案；新增部分需明确用途、支承与可达性，不加空壳高墙凑数。

开放上层必须有楼板、楼梯、平台、护栏和回地面路线；封闭上层不得放可达暗示。禁止整体拉伸建筑、门窗或家具。新增／迁位体量须核对最不利旋转相位下的黑洞、赛场和既有观景点；两相位通行通过不能代替全相位视线检查。

## 4. 色彩和质感：一并改墙、顶、檐底、庭院与街面

保留银白高科幻基调，以中深色实体、凹入面和自然木触面形成明暗主次。材料不能只停留在细色条或入口贴片。

| 区域 | 主材料关系 | 需要避免 |
| --- | --- | --- |
| 科研 | 瓷白＋成片靛蓝实体＋清晰银色收口 | 通体玻璃白框、用灰色代替金属 |
| 阅读 | 珍珠白厚端墙＋墨蓝水平面＋木檐 | 全深色背墙无开合、窗带与真实层高脱节 |
| 咖啡 | 白色结构＋自然木檐与触面＋中蓝局部 | 橙棕大面过重，桌椅与建筑光泽相同 |
| 常住 | 珍珠白墙和屋面边缘＋深青内场／内衬＋自然木接触面 | 旧顶仍全白、只给新楼上色、所有屋顶一律涂黑 |
| 短住／公园／抵达 | 分别采用青绿叠台、自然绿与深池壁、深蓝入口配白壳 | 三者照搬同一套颜色面积和构件组合 |

白色约50%、中深色20–35%继续作为建筑样板参考，其余由木、银等构成；不作为全画面像素指标，也不拿天空、植物和阴影凑比例。前庭与主街要有明度和板材尺度差异，但不能把全部地面涂深替代立面整改。

每批填写**覆盖清单**：旧主墙、新主墙、背面、屋顶内场、屋顶边缘、檐底、柱、庭院、相邻甲板。每项记录对象与派生材质，未改项说明原因；只有新楼或门头做了材料不算整组完成。

质感以实际几何厚度、倒角、米制UV、板缝、粗糙度和反射共同建立。瓷面宽而柔的高光、金属清晰反射、木纹方向、织物低光泽、玻璃通透各自可辨；深色背光保留色相，近景无纹理拉伸、悬浮饰板、共面闪烁或刺眼亮点。

优先复用已有合法资源，包括[White Stucco来源与转换记录](../../../production/black-hole-station/vendor/polyhaven-white-stucco/README.md)和[Oak Veneer来源清单](../../../production/black-hole-station/vendor/polyhaven-oak-veneer-05/source-manifest.json)。供应商材质仅是表面来源，不能替代本站效果验收；缺项先实际查看供应商预览再选材。

样板保留两个完整组合，选定后针对具体缺陷修正。当前已有R3材料候选，先核实其保存版本、覆盖范围与Player证据，不重新从零制作两套。对比锁定玩家相机、URP附加配置、曝光和白平衡；照明延续中性柔光与局部暖白，不用全局增亮、压暗或染色补偿材料问题。
