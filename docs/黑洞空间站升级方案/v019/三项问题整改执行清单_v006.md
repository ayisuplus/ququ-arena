施工动作：

1. 建筑按共同空间聚合。先通过入口转向、局部迁位和附属件整组归位缩短无用途空场；远离主组团的副馆独立接街，不强接巨型庭院。
2. 每块空地只登记实际用途：通行、停留、服务或观景。没有用途的残余空地调整边界；需要观景留白的位置不硬塞建筑。
3. 门廊、柱、灯、座椅、饰面与基座随所属建筑处理。每件记录原归属、拟归属和受影响路线，不能只移主体。
4. 院边接墙端、楼梯侧或檐端；铺装在入口、街巷或板缝处换材质。连续甲板保留，清除新增方案中的碎片、叠面和悬空收口。

## 3. Y轴整改：形成连续可感知的高低关系

高度相对所属环完成地面，以下为选型范围，最终尺寸需在包络、视线、结构和路线检查后确定。

| 层级 | 探索高度 | 作用 |
| --- | --- | --- |
| 低层 | 3–5m | 户门、门廊、配楼和近景停留，保留亲近尺度；既有低馆不为凑数削低 |
| 中层 | 8–14m | 承担街区主体，通过真实楼层、退台和凹入立面形成层次 |
| 局部高点 | 16–22m | 在科研及适合的既有附馆形成少量峰值，与公园、观景开口交替 |

暂不新增24–30m塔楼，不将整环做成等高墙。既有12m共享楼、11.9m阅读楼及17.88m科研主翼继续使用；先解决其与近景低楼的关系。

每区提交局部总图、沿日常到达路线的剖面和环展开立面。选取接近、入口转向、庭院停留三个正常玩家眼高机位，至少两个能同时读到低处和中高实体，并辨认中层楼层或退台；仅露屋顶不通过。远处步道不要求看全所有楼层，不能用极端仰角或鸟瞰代替日常视野。

处理顺序：核对前后距离及入口方向 → 调整真正遮挡的体块或檐段 → 仍然低平时再增加有用途的中层楼翼。长檐逐段编号，列出保留、退短、开口或轮廓调整，支承同步处理。开放上层须有楼板、楼梯、平台、护栏及返回地面的路线；封闭体量不得误导为可达空间。

## 4. 材料整改：降低大面积浅色融合，建立表面差异

保持白色主基调，但让中深色承担成片实体、凹入内衬和屋顶内场，木材承担檐底与接触面，银色承担少量清晰收口。建筑样板可从白色约50%、中深色20–35%起步，其余为木、银等；比例是试样参考，不是整幅画面像素指标。

每区同时处理旧主墙、新主墙、背面、屋顶内场、屋顶边缘、檐底、柱、庭院和相邻甲板，填写对象—材料—理由覆盖表。材料施工必须覆盖完整组团，不能只给新楼、门头或细线条换色。

| 表面 | 本轮要求 | 人视检查 |
| --- | --- | --- |
| 白色墙／结构 | 保留体积厚度、倒角与柔和高光，避免墙地同亮度融合 | 正常曝光能读清边缘、转角和凹入阴影 |
| 中深色实体 | 保留蓝／青等明确色相和适量反射，不涂成无细节黑块 | 背光面仍有材质细节，远景有主次 |
| 银色金属 | 反射清晰，构件厚度与接缝合理 | 不呈哑光工业灰，不刺眼 |
| 木／织物 | 米制纹理、方向正确；织物低光泽 | 近景纹理不拉伸，木檐与白梁光泽可辨 |
| 玻璃 | 通透、边界可读，反射与室内关系协调 | 不用整片镜面遮掉内部，也无明显排序错误 |
| 庭院／街面 | 明度、板材尺度与边界共同区分，接真实入口 | 不出现几块悬散色片，不把所有地面刷深 |

锁定玩家相机和URP附加配置、曝光、白平衡做前后比较。照明只在确有局部照明问题时调整；不以全局增亮、压暗或染色代替材料修订。近景、中景、远景和移动观察分别检查。
