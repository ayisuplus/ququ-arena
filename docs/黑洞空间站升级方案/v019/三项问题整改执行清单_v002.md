## 1. 修订依据与选择

用户要求解决布局散乱、区域相似、建筑低平、颜色过浅和缺乏质感。本次按“保留银白科幻方向、重组现有街区”的假设修订，不改变三环与原功能身份。对比三种处理方式：仅换色/抬屋顶成本低但解决不了空间关系；全站高层化会增加遮景和迁移负担；采用**完整街区组织＋低中高体量＋墙地顶联合材料**，优先复用已建楼层。

## 2. 布局：每个街区都要形成完整空间

施工单位为“原楼＋新增楼翼＋共同前庭＋相邻环街”，不再以单栋好看作为本区完成条件。每区先出所属环局部坐标总图，标记主入口、次入口、主楼、低配楼、公共停留、服务侧、观景留白和散件归属；实际尺寸从场景测绘后冻结。

空地逐块归入通行、停留、服务、观景四类，未能解释用途的余地先调整建筑组合及边界。连续环街保持通畅；公共穿行绕开户门，设施归属本区，植物仍集中主园及B03。边界可由楼翼、凹入口、短墙、檐线和铺地共同形成，但不能只靠地面描边；也不能用围墙把整区封死。

### 2.1 从散楼变成街区的施工顺序

先在同版本总图上给每件建筑、檐架、家具和设施标明所属街区与功能，再定主楼、配楼和共同前庭。附属件优先收至建筑服务侧或停留边，不继续占据没有归属的空场。以既有主街和原门为固定连接点，调整新翼、低连接和前庭侧边；需要移动原功能对象时单列身份及存档迁移，不把搬家混在美术整理中。

每区保留一个清楚的公共中心，区界落在建筑端部、街巷、院落口或观景开口上。相邻区用共同街道过渡，有色铺装在实际门前、停留边或整板缝处收止，避免把区界画成切过空场的巨大色块。宽阔余地若没有通行、活动或观景用途，优先通过配楼及院落关系收拢；不能靠铺满家具、灯柱或散树补空。

## 3. 高度：形成日常行走中可见的低中高关系

以所属环完成地面为Y=0，沿用**3–5m低入口、8–14m中层、16–22m少量高点**的设计探索范围。既有科研17.88m、阅读11.9m、咖啡11.8m、常住12m来自已提交记录，本轮未复测。24–30m高点不列当前必建项；公园、私密门庭保持低谷，不要求每区机械地凑齐三档。

1. 先出各环展开立面和每个样板的到达剖面，标明原低顶、新楼层、退台、支承和观景方向，找出低平连续段与孤立高楼之间的断层。
2. 对阅读原路线记录“接近—转向—入院”三段正常玩家人视。至少两个位置能同时读到低前景与中／高实体；区分建筑在视野之外还是被旧檐遮挡，分别比较调整接街朝向、局部檐线退让和侧后体量关系。
3. 先让已有楼层形成有效关系；若仍不足，再在已冻结组团内试摆有实际用途的中层楼翼，比较增建前后包络、视线与通行。不能只拉高屋顶、整体缩放家具或立一张高墙。
4. 拟开放高层必须有地板厚度、支承、楼梯落点、护栏及连续回地面路线；封闭体量明确用途，不放误导玩家可达的门或座位。
5. 旋转环用相位扫描找不利遮景，检查黑洞、中央赛场与跨环换乘；两个方便相位的通行通过不能替代遮景结论。保持连续甲板与中央唯一大型贯通井。

## 4. 色彩与质感：把有色实体做出厚度

保留主方案分区比例作为选样起点：多数建筑组约50%白色、20–35%有色中深面，其余由木棕、银色等组成；具体分区仍按主方案5.1执行。比例不是现状统计，不按屏幕像素硬凑，更不能通过把甲板全涂蓝、白墙调灰或深墙调黑来达标。

- **大面明暗：** 有色重心落实到真实侧墙、交通核、入口内衬、檐底和适量地坪。主墙与地面拉开明度，深蓝／青绿在背光下仍有可辨色相；银白吸积盘保持。
- **构造厚度：** 公共路线可见的整块背墙先核对楼层、书架、座位和封闭功能。适合采光的墙段比较真实凹窗；需封闭的墙段用有厚度的分段、退入面和转角处理。窗必须与室内对应，不能贴黑矩形冒充开口；不向所有墙复制同一套玻璃幕墙。
- **白顶与檐：** 白顶保留白色，通过边缘厚度、合理板缝、檐底材质和局部退让体现层次；先处理远景体块，再处理近景细表面。不得为增加纹理堆放无用途屋顶设备。
- **表面差异：** 瓷面为柔和清晰高光，石材为较粗反射和米制板缝，银色为窄而清楚的反射，木纹按实际尺度与构件方向，织物保留低光泽，玻璃核对室内外与反射。参数由同场景样板选定，不能用一套平滑度包办。
- **光照：** 材料比较固定玩家相机、URP、曝光与光照。先调材料，之后再单列局部中性柔光／暖白调整；冷白冰蓝仅作少量强调。禁止以全局增亮掩盖灰闷或全局压暗处理刺眼。

首批联合样板必须包含旧墙、新楼正面与背面、白顶、木檐、前庭和邻接甲板。近景能读表面，中景能读体块，远景能读街区；三种距离同时审阅。

### 4.1 两座旧馆屋面与浅色大面的具体处理

旧阅读馆和活动馆优先保留白色外缘，比较“原轮廓＋分层檐口”和“薄化上部曲面＋退入屋面”两种候选。测清室内天花、屋面最低点、支承及碰撞后才决定厚度；室内净高、门口和支承关系保持。若只改变渲染网格，也必须检查物理屋面是否留下不可见凸起。屋顶修改不能代替接街方向调整。

阅读馆以白色边缘、墨蓝退入面和木檐底形成水平层次；活动馆以白色边缘、青绿局部和开放门面形成区别。有色屋面只在具备真实板面边界的区域试样，先查看主街人视和鸟瞰，再决定面积；不把两座屋顶直接整块染成两种颜色，不假造与室内不通的采光天窗。

邻接甲板与前庭同批选样：白色建筑对照有明确色相的中明度地面，深色墙对照较亮的边缘和入口内衬。材质近景须包含转角、板缝及受光/背光两面；色差成立后再调整粗糙度和反射。若表面仍像单色塑料，返修纹理尺度、倒角和收口，不继续增加发光条。
