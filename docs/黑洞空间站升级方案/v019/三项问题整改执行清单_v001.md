## 4. 高度验收从“最高多少米”改为“剖面是否有层次”

每个R2/R3建筑街区交付至少一条从主街穿过前庭、低入口、中层和后部高点的剖面；同时给出该环的展开立面。临街3–5m、中层8–14m、局部16–22m沿用主方案探索范围，24–30m仍为可取消研究项，不是必建任务。

- 每组至少出现低入口与中层两个可辨体量层级；高点可复用已有附馆，不要求每组再造一栋塔。高差必须由实体退台、屋面层线和前后遮叠共同表达，不能仅靠栏杆或尖顶。
- 新增开放上层必须有连续楼梯、平台、护栏及返回地面路线；封闭体量不能放可交互座椅或展示可走门洞。层高、板厚和净高逐项标注，不整体拉伸旧房和家具。
- 固定原到达/停留眼点，用几何扫描找不利旋转相位，再做原生画面对照及连续漫游。发生持续观景遮挡时优先退后、分段、降低或取消；不通过移动观察点掩盖问题。
- 公园与港区不执行统一中层数量要求，保留天际线中的开敞段；严禁各环变成连续等高墙。

## 5. 材料整改以大面和物性为单位

沿用主方案5.1配色起点：多数建筑区白/浅色约50%，其余由本区中深色、木棕与银色组成；数字仅为设计起点，不能当作现状测量或硬性像素达标值。先在实际玩家画面选样，避免为了凑比例把全部材料调黑。

| 表面 | 必须完成的材料工作 | 检查方法 |
| --- | --- | --- |
| 甲板、主街、前庭 | 连续物理地面保持；主街与院落采用相关但不同明度的表面，院落分区与楼边相接；清理视觉上孤立的色带时保留其通行语义 | 同一中景中能分出路、院、入口，不能把深地面看成洞；不以细密拼花填空 |
| 旧屋面和新楼板边 | 分开屋面、檐底、板边的材料；补真实厚度、合理倒角与宽窄高光 | 斜向近景检查转折，中景仍能读到层线；不把整块白屋面一律改黑 |
| 区域深色面 | 靛蓝/墨蓝/中蓝/青绿绑定完整内衬、墙段或交通核；与窗洞和结构逻辑一致 | 背光仍能辨色和细节，无随机棋盘染色；科研与阅读不只差一种蓝 |
| 瓷面、石材、木、织物 | 核对合法PBR的基色、法线、粗糙度及实际纹理尺寸；避免纯色棕板、木纹拉伸与瓷面塑料感 | 相同光照下近/中距对照；木纹方向服从构件，纹理不产生明显重复和闪烁 |
| 金属和玻璃 | 金属保留清楚局部反射；玻璃有框、有厚度、可读内外，局部反射随环更新 | 正常可见Player动态观察，不以材质球或Editor导入成功代替 |

先用现有合法资源作一块“旧墙＋新墙＋院落地面＋屋面边”的联合样板。确有缺口才检索免费资源，实际查看预览并记录许可、尺度与来源；此轮未采购、下载或生成素材。锁定玩家相机及URP附加数据、曝光、白平衡和灯光，分别比较几何、材料与必要局部补光，不全局压暗或用染色灯补材质。

### 9.2 三项整改的具体落点

**布局：收拢视觉边界，并明确不同街区的窗墙组织。** 已建低边界保留，继续核对主入口、次入口和附属设备归属。科研、阅读、咖啡先分别画一张面向主前庭的立面，标出保留窗、实体墙、内凹入口、楼板边和侧屏。科研在不挡景的侧后段形成竖向实体与窄窗组合；阅读让厚端墙、水平窗带和后退露台成为主节奏；咖啡保留通透门面和低木檐，实体集中服务侧。每次增加实墙先复核室内采光、原座位视线和运动相位，不给玻璃外面机械加一层壳。常住采用实墙凹窗与私密小院，短住采用公共前庭和观景叠台，二者单独设计。

**高度：把已建楼高转化为人视可读的前后层次。** 保留科研17.88m、阅读11.9m、咖啡11.8m和常住12m的既有施工成果；首批不再追加24–30m高塔。各组用原到达线检验“3–5m低入口—8–14m中层—既有局部高点”的探索关系，允许高点是同环独立附馆而非同一院内。对每组标出前檐、侧翼、楼板、后退上层和实际可达层；若高层被前檐遮住，先比较局部退让、入口侧向开敞或檐线分段方案，保留旧对象和必要通路，再决定改动。不得直接拆现有有用檐棚、拉伸旧楼，或以高墙封死观景来做层次。公园保持低谷。

**质感：先改大面之间的关系，再调各自表面。** 用同一灯光下的“旧墙＋新墙＋窗台＋屋面边＋院落地面”联合样板确定材料，科研大前庭、旧白顶、阅读浅绿窗台优先纳入。屋顶采用洁净细微表面，不能直接复制带大砖缝的前庭石材；白墙用较清楚的瓷面高光，地坪采用中等明度与克制反光，檐底木纹按构件方向铺设。深色用于完整内衬、墙段和层带；阴影中仍保留蓝、青、棕的色相。真实法线/粗糙度、纹理米制尺度、倒角与反射分别验证，不用全局压暗制造重量感，也不把污渍或高强度凹凸当作高级质感。

#### B. 高度：从原到达线读出低、中、高

当前科研17.88m、阅读11.9m、咖啡11.8m、常住12m均继续保留。按每组“环街入口—门廊外沿—院内停留”三个连续位置绘制人视与对应剖面，标出前檐遮挡线、真实楼板、可达层和远处高点；具体眼点从现有路线取，不为显示高层任意抬高相机。

- 先让3–5m低入口与8–14m中层在前后关系中可读，既有16–22m局部高点承担峰值；这些是组团探索范围，不是强制层高。
- 前檐遮住中层时，先比较侧向开敞、局部分段和上层退让；保留必要遮檐与通路，候选验证后再定改动。不能依赖鸟瞰或仅在檐下一个挑选角度证明层次。
- 用窗洞深度、端墙转折、楼板实体和露台退让建立阴影；已有空架不计为新增中层实体。开放层需真实上下通路、防护和使用空间，封闭段应有明确用途。

#### C. 质感：从已装样板推进到连续大面

1. **完成当前样板复核。** 屋面细微表面、科研蓝石材和阅读墨蓝窗台继续使用；白顶中远景偏平与阅读地面亮点单列问题。在相同相机/光照下定位亮点所属表面，逐项比较粗糙度、清漆、法线和反射，再改对应派生材质；此时不预判是灯光故障，不覆盖全局材质。
2. **以构造建立重量感。** 新端墙/竖向实体需可见转角和窗洞内壁；白瓷面、墨蓝釉面、拉丝银、木触面、织物各留联合近景。深色用于完整墙段与凹口；纹理按米制尺度与构件方向铺设，不能只把白框染深。
3. **补主街样段再推广。** 从已测R2平面选取两个实际相邻街区入口之间的一段连续路线，编号两端点与两侧建筑。选段须包含甲板背景、主街、前庭、浅色门前过渡四种角色；比较中等明度蓝/青候选的墙地顶关系。主街连续，前庭随区变化，深色边界不读成裂缝或深坑。通过同配置连续漫游后再推广，禁止整站一键换色。

沿用主方案配比作为选样起点，实际以近、中、远同框效果调整；不把百分比当验收测量。中性柔光、局部暖白、银白吸积盘与露天公园保持。

#### D. 提交顺序与关闭条件

1. **科研/阅读成对样板：** 交付已标窗格的两组立面、转角剖面、散件落位和三段到达人视，完成选定几何与材料；随后核对咖啡整组差异。发生几何/座位遮挡变化时，补相应路线、防护、视线及运动相位回归；旧材料通过结果不替代新几何验证。
2. **生活区整组：** 常住补陈设、反射、防护和六户关系，短住另做叠台与到达。两者各交付整组平面、低中高剖面和原门连续路线；空房实走通过不能关闭生活区。
3. **街段到全站：** 完成主街样段，再衔接公园、港区及其余甲板；提交同版本全站鸟瞰、各环展开图、连续Player漫游和受影响功能/性能检查，按P5复核。

**材料施工的具体顺序：** 先用同光照下的墙地顶联合样板确定明暗面积，再核对实际贴图、米制UV、法线与反射，最后调整粗糙度和局部灯。至少同时查看白瓷墙、深色实体、木檐和街面四类表面；深色背光能辨色相，银色保留窄高光，玻璃能读出室内外层次。不得将深色仅放在细线/小家具上，也不得用全局压暗或单纯提高饱和度宣布质感完成。参考照片仅用于设计方法，新增资产仍遵守来源与许可要求。

**R2下一样板的具体修订：**

1. 先把铺装边界落在实际建筑端部、既有前庭或环街边，保留中间通行与服务空间；转角处用整板收边。废弃本次约104m×100m矩形整片浅蓝方案，不用另一种大面积浅色代替原白色空场。边界图经现状核对后才冻结具体面积。
2. 保留白色主墙，将有色重心放在阅读深窗/实体侧面、活动青绿基部、凹入口与檐底。近黑墨蓝先恢复可辨色相，再比较平滑度；白墙与白顶分别核对细表面、板缝、倒角和厚度。纹理不能替代构造，墙、屋顶、玻璃和木檐不使用相同反光。
3. 对照现有剖面和原主入口、自然转向、次入口三段人视，判断11.9m阅读楼与约7.8m旧顶的可见关系。若中层只在专门绕行后才出现，优先调整正常进入方向和局部前景开敞；改檐或迁位须另列受影响构件及视线证据。不得只靠加深颜色宣称高低层次已完成。
