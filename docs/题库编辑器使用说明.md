# 题库编辑器

入口：对战工作台 → 浏览题库 → **编辑题库**。点击 **新建题库** 可以创建自己的题库。

1. 左侧搜索、选择或添加题目，右侧填写题目内容与参考答案。
2. 短答案使用“完整答案匹配”；有多种正确写法时，在“其他可接受答案”中每行填写一种。这里是完整匹配，不是包含某个词就算正确。
3. 新建题库可选择“开放评审”或“多轮任务”，配置维度、权重和得分条件；参考答案可以省略。多轮支持 2–5 轮材料和修订要求。旧题库的“按标准评分”仍保留原有行为。详见[开放评审与多轮任务说明](开放评审与多轮任务使用说明.md)。
4. “题库设置”可修改名称、介绍、公共说明与默认评分。“分组与补充说明”可填写同组共享材料。“预览完整题面”显示公共说明、分组材料与本题内容拼接后的实际输入。
5. 点击页顶 **保存题库**，或按 **Ctrl+S**。修改在保存后用于下一场比赛。

每道题可以暂停参与对战，也可以通过上移、下移调整出题顺序。删除需要在页内确认；保存前可以撤销最后一次删除。题库至少保留一道完整题目才能保存。

已有组合评分规则保留原样；需要改为常用评分方式时，在下拉框中切换。仅修改题目或答案不会丢失原有来源信息、公共材料或评分配置。暂停题库不会因改字自动恢复，需要明确启用。

保存时检查空题、缺少答案、重复题面和无效评分规则。规则检查不能证明题意严谨或答案事实正确，出题时仍需要人工核对。

本地保存沿用 `arena/arenas/<题库标识>/arena.json` 与 `tasks.jsonl`，可继续导出为 `.ququ.json`。修改前自动备份到 `arena/arenas/.editor-backups/<题库标识>/`；备份保留完整旧题库，可用项目现有题库导入命令恢复。多窗口编辑冲突时会保留当前页面草稿并拒绝覆盖，重新加载前会确认。

比赛已加载的题库快照与历史战绩不会被编辑器改写。新题面、答案或评分规则会产生新的题库指纹，便于区分不同版本。

验收材料：`docs/validation/question-editor/`。浏览器验收使用临时复制的题库、独立战绩目录和新的浏览器会话，未写入正式题库或调用参赛模型。
